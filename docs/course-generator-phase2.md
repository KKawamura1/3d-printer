# Issue #39 第2段階 — 設定だけで窓配置を変更できる下り坂トンネル

元の PR #34 D01-V2 を **変更せず**、新しい D02-V1（4×2×高さ3、落差19.2mm、側面の窓2個）を追加する。

- `experiments/course_windows_d02/course.json`：外形、落差、入口/出口、E31-05、窓位置と幅、刻印ID/versionを宣言。新しい専用 `design.py` 不要。
- `brickcad/course_generator_v2.py`：構成要素と窓配置を厳密に検証。開放坂、急落下、左右カーブ、北窓などの未実装組み合わせは無理に作らずエラー。
- `brickcad/course_downhill.py`：従来の `build_downhill` を呼ばず、共通の通路・窓切削プリミティブからBRepを再構築。スタッドと下面支持、E31-05を合成後、外側の非走行面へ凹刻印。窓は可変数・位置・幅を設定から切削。
- **旧版の保証**：D01-V2の3窓を同じレシピで作り直して旧 `build_downhill` との双方向BRep差分体積を比較するCADテストを追加。
- STL/STEP、meshing、33点の球干渉、下面受け、天井、窓下ガードをCADで検証。Actionsによる変更対象だけのSTLと簡易プレビュー生成。
- `scripts/cad_versions.py`：レシピから利用する**生成器の版**を解析してソース指紋に含める。旧v1ジェネレータの版・STLを変更しない。
- D02-V1のSTLは**印刷未検証**。バリ、窓、天井のサポート、嵌合、実際の転がりは確認が必要。

## #36 / #38 / #41 との関係

このPRは **下り坂・トンネル外装・窓** のみを対象とする。#36 のR16連続カーブは広い転回室ではなく案内壁を保持、#38 の急落下は密閉屋根と33°の出口ランアウトが必要、#41 はさらに方向転換と下面の輪郭切断が重要。いずれも未マージなので**版固定の取り込みは行わない**。形状が確定した時点でこの構成検証を共有する別adapterとして取り込む。

曲線／急落下／上下方向変更や、部分形状での輪郭切断型スタッド・下面支持は、ここで無理に推論して実装しない。既存の良品設計を基準とする。
