# PR56 共通CADの実機検証・採用台帳（2026-11-04）

## 方針
Issue #37の23分類/20形状について、**CAD生成コードはPR #56の共通カタログに集約**する。個別パーツPRのソースは歴史的比較元として固定SHAで参照するが、本番生成では実行しない。

**PR56のコードをmainに統合することは、カタログ全20形状が実機認定されたことを意味しない。** 実物評価は下記の印刷したID/生成SHAに限る。実物印刷後に幾何生成コードや嵌合寸法を変更した場合、合格判定を自動継承しない。

## 個別PR整理ルール
- PR56がmainに入った後、同じ20形状を別経路で実装する個別PRは**supersededとしてclose可**。個別PRのソースコード・単体テスト・STL配置先をmainへマージするわけではない。
- **個別PRのブランチは削除しない**。固定SHAの比較元と変更履歴を残す。
- 検証用プレートPR #70および別用途の新規パーツPRは同一形状の重複実装ではないため一括close対象外。
- 追試で問題が発覚したら共通カタログを直接修正し、モデルIDと実機証跡を更新する。
