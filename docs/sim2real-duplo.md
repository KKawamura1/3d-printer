# DUPLOの初回接続校正プレート

主対象はDUPLOです。印刷用は `examples/sim2real-duplo/plate.stl`。
補正違いの2×2を5個配置した1ファイルで、共通の土台・ランナーはありません。
通常レゴ用の旧試験データとは別です。DUPLO専用の16 mmピッチ・中空スタッド・裏面チューブを使います。

## 小さく・速く確認する形状

- 各試験片の本体: 31.8×31.8×6.4 mm。
- スタッド: 高さ4.5 mm、穴径6.5 mm。スタッド込み高さ10.9 mm。
- 受け側: 天井厚1.6 mm、内部深さ4.8 mm。相手の4.5 mmスタッドが入る深さを残しています。
- 配置全体: 103.8×67.8×10.9 mm。
- CAD体積: 約21.46 cm³。密度1.24 g/cm³のPLA換算で約26.6 g（パージ・サポート等は別）。
- 壁厚・チューブ径・スタッド径・ピッチはmainのDUPLO標準モデルと共通。高さだけを短くした校正用形状です。

通常高さ19.2 mmの2×2を5個作るとCAD体積換算でPLA約60.4 gになります。
まずこの低い試験片で接続寸法の候補を選び、次に通常高さの2×2または2×4を1個確認します。
**壁のしなり・保持力・長いブロックのピッチ誤差累積まで、通常高さ品と同じになる保証はありません。**
短い試験片は補正範囲を絞るためのもので、完成品の保持力試験の代わりにはしません。

## 識別と補正値

側面の短い縦溝の本数がIDです。溝は幅0.7、深さ0.2、高さ2 mm、中心高さ3.2 mm。
接続に使うスタッド・内壁・チューブ・上下面には刻印しません。
溝のある面を手前にして上から見ると、奥が4・5、手前が1・2・3です。入れ替わっても溝で識別できます。

補正は半径方向mmで、倍率変更ではありません。正なら突起を細く、受けを広くします。

| ID / 溝の本数 | 突起側補正 | 受け側補正 | スタッド外径 | 壁厚 | チューブ外径 |
|---|---:|---:|---:|---:|---:|
| 1 | −0.04 | −0.04 | 9.48 | 3.24 | 13.18 |
| 2 | 0.00 | 0.00 | 9.40 | 3.20 | 13.10 |
| 3 | ＋0.04 | ＋0.04 | 9.32 | 3.16 | 13.02 |
| 4 | ＋0.08 | ＋0.08 | 9.24 | 3.12 | 12.94 |
| 5 | ＋0.12 | ＋0.12 | 9.16 | 3.08 | 12.86 |

5候補は探索範囲です。最適値がこの中にあると断定しません。全部きつい／緩い場合も記録してください。
スタッド穴径6.5 mmと裏面チューブ内径9.4 mmは固定です。

## 印刷する

1. スライサーへmm単位・**100%**で読み込みます。既にデュプロ寸法なので200%にしません。
2. 全5個を突起上向き、底の開口を下向きにします。インポート後に全体寸法103.8×67.8×10.9 mmを確認します。
3. 本番と同じ材料・ノズル・温度・速度・層厚・フロー・XY補正で印刷します。実時間・使用量はスライサーの見積りを使います。
4. 天井下面はブリッジです。スライスプレビューで確認し、可能なら接触面に残るサポートは使わない設定にします。
5. 完全に冷めてから取り外します。象の足・初層の引っ掛かり、天井下面の垂れは別途記録してください。

機種、ノズル、材料、スライサー設定、比較に使った純正パーツを `setup.json` に記入します。

## 純正DUPLOで上下を別々に評価する

純正DUPLOの2×2または2×4の同じ4スタッド領域を比較に使います。5→4→3→2→1の順に試します。
きついものは無理に押し込みません。

| 試し方 | 選ぶ補正 | CSV欄 |
|---|---|---|
| 印刷品の上に純正DUPLO | 印刷した突起側 | genuine_on_printed |
| 純正DUPLOの上に印刷品 | 印刷した受け側 | printed_on_genuine |

「入らない／きつい／適度／ゆるい／保持しない」を記録し、着座せず隙間が残る場合も記録してください。
同じ組合せを3回程度着脱し、初回だけか、摩耗して急に緩むかも確認します。純正同士の感触を基準に比較します。
ノギスがあればスタッド径X/Y、外形X/Yを測って `measurements.csv` に記入します。

**突起はID3、受けはID4、のように別々に選べます。** 純正を相手に片側ずつ評価するので25通りの印刷は不要です。
受け側の内壁とチューブは今回連動しています。片方だけ当たる等があれば次の試験で分離します。
この試験はCADと実物の形状差、印刷誤差、材料の弾性・摩擦を合わせた実用補正を選びます。原因を個別に同定するものではありません。

## 再生成・通常高さでの確認

```sh
# 既定値はDUPLO・低い校正試験片5個
python -m brickcad.calibration

# 通常高さ19.2 mmを5個で比較したい場合（別の出力先に保存）
python -m brickcad.calibration build/sim2real-duplo-full --full-height

# 旧レゴ版は明示的に指定する
python -m brickcad.calibration build/sim2real --family lego
```

通常高さの実用品profileは次のように作ります。下記の値は説明用の未検証例で、推奨値ではありません。

```python
from dataclasses import asdict
from pathlib import Path
import json
from brickcad.calibration import specification
# 突起ID3・受けID4がよかった場合の通常高さDUPLO 2×2候補
p = specification(0.04, 0.08, nx=2, ny=2, family='duplo')
Path('profiles/duplo-measured-trial.json').write_text(json.dumps(asdict(p), indent=2))
```

```sh
python -m brickcad build --profile profiles/duplo-measured-trial.json --out build/duplo-measured-trial
```

`specification`は通常高さ19.2 mmのDUPLOを返します。低い校正形状は `coupon` で明示的に設定しています。
既存の `clearance` は0にして、スタッド半径／壁厚／チューブ外半径を個別設定するので、補正を二重に掛けません。
通常高さで保持を確認した後、2×4などの長い形へ進みます。

## 検証範囲

DUPLO専用名目モデルを参照し、上下両方向・挿入経路・ずらし・交差姿勢を計算します。通常レゴの8 mm参照は使いません。
BRep、外形、開口、中空スタッドと穴底、刻印体積、単一試験片と5個セットのSTL閉メッシュ、CADとの体積一致、STEP再読込を確認します。
負補正ID1の幾何干渉は意図した探索候補です。校正セットの `passed=true` はデータ生成の検査が通ったという意味で、全候補が無干渉という意味ではありません。
実物での嵌合・保持力は未検証のため `physical_fit_validated=false` です。印刷結果を記録して次のprofileへ戻します。
