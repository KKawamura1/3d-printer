# ボール走行の停止観察ログ（連結相性・原因切り分け）

## 目的

デュプロ互換の3Dプリント製ボールコースで、**どのパーツをどの順で接続すると、どこで、どの程度の頻度で止まるか**を蓄積する。単体不良・接続相性・設置条件を分け、特定パーツを早計に犯人扱いしない。

- **追記する一次データ:** [`measurements/ball-rolling-stop-observations.csv`](../measurements/ball-rolling-stop-observations.csv)。1行＝1つの**有向**接続（上流→下流）×条件×観察セット。別の日、固定方法、ボール、パーツ版、反転方向を変えたら**別行**にする。過去の失敗記録は消さない。
- **対策・原因仮説・作業:** [Issue #77](https://github.com/KKawamura1/3d-printer/issues/77)。CSVには確定していない原因を断定して書かない。
- `BS-YYYYMMDD-NNN` を観察IDとして採番する。回数が不明なら `attempts` / `stops` は**空欄**とし、`frequency_qualitative` に「frequent」等の定性的表現を残す。日時は報告日と観察日を混同しない（観察日未確認なら報告日だけ記録）。

## 次回からの記録ルール

追加報告は「`S02-V16 → E01-V8`、`E01-V8` 入口で停止」のような短文だけでも、その時点で分かる事実を追記する。詳細が分かるときだけ以下を併記する。

1. 上流・下流の**刻印ID＋版**、連結方向（必須。単体内の停止なら下流は空欄）。
2. **止まった場所**（上流末端／境界／下流入口／下流内部／不明）。境界の前後どちらかも分かれば記録。
3. **同条件の試行回数と停止回数**（例：10回中7回）。「よく」は定量化せず原文を残す。
4. **条件**（使用球、投入高さや速度、接続を手で固定したか、土台・傾き、印刷品の個体、バリ除去有無など）。不明は空欄のまま。
5. 改善・悪化した操作（押さえる、傾ける、パーツを交換、順番を逆にする等）。観察と推測を分ける。

### 「誰が悪いか」の比較手順

1. **同じ下流（例：`E01-V8`）**に別の上流パーツをつなぐ。どれでも入口で止まれば下流入口・据付条件の疑いが強まる。
2. **同じ上流（例：`S02-V16`）**から別の下流へつなぐ。どれでも境界で止まれば上流出口・速度条件の疑いが強まる。
3. **同じペアを固定あり／なし**で比較。固定で改善すれば段差・傾き・がたつきの寄与を疑う。
4. **各パーツ単体でも走らせる**。単体が良くても連結で止まるなら接続相性の可能性を残す。
5. できれば各条件10回、同じ球と投入条件で比較して `stops/attempts` を保存。試験していない数値は補完しない。

停止率の集計は観察数が十分にたまってから、上流ID・下流ID・ペア・設置条件それぞれで行う。**条件差を無視して停止数だけで原因を断定しない。**

| `BS-20261122-001` | `SC02-V17` 内部停止 | **ブロックに載せなくても、単体で球が噛み込むことがある**。ユーザーの体感で約10回に1回程度（正式計数なし）。一度止まると進行方向に傾けても動かず、**今回の追試では逆方向に傾けても抜けなかった**（前回の「逆方向ならすぐ抜ける」という報告は再現できず撤回）。停止後、下に付けたブロックを外しても解放しなかった。追加写真では円形開口内のボールが斜め方向（ユーザー表現：「上面左上と下面右下」）で接触しているように見える。 | **下のブロックを接続すると詰まる、という必要条件は否定的**。以前の「下面からの押圧/変形が第一仮説」は優先度を下げる。正確な接触点や内径は写真だけでは測定できない |
| `BS-20261122-002` | `SB02-V1` | 刻印を手前にしたとき左側の入口でボールが頻繁に引っかかる。 | 正確な接触箇所、V2での改善有無は未確認（[Issue #82](https://github.com/KKawamura1/3d-printer/issues/82)） |

**SC02の現在の仮説（未確定）:** **順方向・逆方向のどちらに傾けても抜けない再現例がある**。一方向だけの引っかかりという仮説は撤回し、局所的に狭い走路断面、左右/上下の同時接触による噛み込み、3Dプリントの内部バリ・垂れ、loft/走路の境界の稜線などを原因候補とする。勾配不足だけでは、停止後に大きく傾けても解放されない現象を説明しにくい。単独と搭載時の停止率差は未計数であり、押圧の影響を完全排除したわけではない。

**再現条件の補足:** 追加写真（2026-11-22）は開口から球が内部に保持された状態を示すが、幾何寸法・真の接触点は確定できない。以前は逆方向で外れた気がするとの記憶があったものの、直近の再現試験では外れなかった。両者を混同して「逆方向なら解放される」と断定しない。

**次の切り分け:** 同じ球を使い、ブロックを外したSC02単独で20〜30回程度の投入を記録（試行回数・停止回数）。止まった時の球位置が毎回同じか、前後に揺すっても抜けないか、別の同径球でも再現するかを確認。可能なら内側をライトで照らしてバリ/段差を観察する。無理に押し出さず、傷を付けない。

**CAD検証:** `brickcad/course_r48_sloped_tunnel.py` のカーブ全周を断面検査し、球径24.26mmに対する最小通路余裕、完成BRep/スライス面の局所的なくびれ、内壁の加工段差を比較。**有効な流路の幅・上側クリアランスを増やす**案と、局所的な段差を除く案を別条件で試す。候補修正版では接続口・支持・最低肉厚を維持し、入口出口に新たな引っかかる段差を作らず滑らかに遷移する。まず噛み込み解消・単体再現性を優先する。

**横断的な実物報告（2026-11-22、個体ID未特定）:** これまでにも別の3D印刷パーツで、**走路のバリが原因とみられる停止が多数あり、手でバリを除去すると正常に転がるようになった**。一方、**今回のSC02系は目に見えるバリがなさそう**との報告。これらを同一原因と決めつけず、全トンネルの通路設計に製造ばらつき・表面仕上げ余裕を持たせ、スライス・現物で検証する。個別ID、発生回数、改修前後の試行数は未記録。
