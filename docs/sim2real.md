# 通常レゴ用の初回sim-to-real接続試験

**このプレートは8 mmピッチの通常レゴ用です。DUPLO用ではありません。** デュプロ用は[docs/duplo.md](duplo.md)を参照してください。

印刷用: `examples/sim2real/plate.stl`。2×2試験片5個を離して配置した1ファイルです。
共通の土台・ランナーはありません。スライサーで単位mm、倍率100%、突起を上向き、底開口を下向きにして、5個を同じジョブで印刷してください。
配置の外接寸法は55.8×35.8×11.4 mm。各個体の本体は15.8×15.8×9.6 mm、突起高さ1.8 mmです。
CAD体積約6.24 cm³、密度1.24 g/cm³換算で約7.74 g。スライサーの充填・ブリッジ・パージで実消費量は変わります。印刷時間はスライサーの見積りを使ってください。

## なぜこの形か

2×2は、現在の2列ブロックの接続構造（4スタッド＋中央チューブ＋壁）を保つ最小サイズです。
高さ・壁・天井を薄くしてしまうと、変形やブリッジの条件が変わるので、実用品と同じ高さを維持します。
外側面にある短い縦溝の本数がIDです。溝は幅0.7、深さ0.2、高さ2 mm。接続に使う内壁・チューブ・スタッド・上下面には刻印しません。
5個の位置を入れ替えても、溝を数えれば識別できます。

## 試験片

補正は半径方向mmです。プラスは突起を細く／受けを広くします。ピッチ8 mmと外形は固定です。

| 溝の本数 / ID | 突起側補正 | 受け側補正 | 突起直径 | 壁厚 | チューブ外径 |
|---|---:|---:|---:|---:|---:|
| 1 | −0.04 | −0.04 | 4.88 | 1.54 | 6.58 |
| 2 | 0.00 | 0.00 | 4.80 | 1.50 | 6.50 |
| 3 | ＋0.04 | ＋0.04 | 4.72 | 1.46 | 6.42 |
| 4 | ＋0.08 | ＋0.08 | 4.64 | 1.42 | 6.34 |
| 5 | ＋0.12 | ＋0.12 | 4.56 | 1.38 | 6.26 |

印刷配置（上から、溝のある面を手前へ）: 奥が4・5、手前が1・2・3。
5個の上下に同じ補正値を割り当てていますが、評価・選択は独立です。純正を相手にして片側ずつ試すため、25通りの組合せは不要です。
この範囲に適切な嵌合が存在する保証はありません。全てきつい／緩い場合も、その方向へ次の探索範囲を動かす情報になります。

## 印刷条件

本番に使うノズル・材料・積層・速度・温度・フロー・XY補正を使用し、`setup.json`へ記録します。
初層・象の足補正の設定も記録してください。倍率で嵌合調整するとピッチも変わるため倍率100%を維持します。
天井下面はブリッジです。まずスライスプレビューで天井を確認し、可能なら接触面に残るサポートは使わない設定にします。
受け側が最初の数層だけ引っ掛かる、天井下面が垂れる等は、全体の補正と区別して記録してください。

## 純正を使って評価する

完全に冷めてから取り外し、同じ純正2×2か2×4の、同じ4スタッド領域を比較に使います。
最初は5→4→3→2→1の順で試し、きついものを無理に押し込みません。

1. **印刷品の上に純正**: 印刷した突起を評価します。
2. **純正の上に印刷品**: 印刷した受け側を評価します。
3. それぞれ「入らない／きつい／適度／ゆるい／保持しない」を記録します。着座せず隙間が残る場合も記録します。
4. 同じ組合せを3回程度着脱し、初回だけか、摩耗して急に緩むかを記録します。
5. ノギスがあれば、突起径をX/Yの2方向、外形をX/Yで測ります。可能なら純正同士の感触も基準として比較します。

`measurements.csv`の `genuine_on_printed` が突起側、`printed_on_genuine` が受け側の評価です。
例えば「突起はID3、受けはID5がよい」と独立して選択できます。
ただし受け側の壁とチューブは今回は連動しています。片側だけ当たる等があれば、次の試験で壁とチューブも分離します。
2×2では長いブロックのピッチ誤差累積や保持力増加までは評価できないので、次は選択値で2×4を1個確認します。

## 再生成と次のprofile

```sh
python -m brickcad.calibration
# 別の場所へ生成する場合
python -m brickcad.calibration build/my-trial
```

既存のモデル／名目profileは変更していません。独立補正を適用したprofileは以下で生成できます。
例は未検証の説明用で、推奨値ではありません。

```python
from dataclasses import asdict
import json
from pathlib import Path
from brickcad.calibration import specification
# 突起ID3、受けID5が良かった場合の2×4候補
p = specification(stud_clearance=0.04, receiver_clearance=0.12, nx=4, ny=2)
Path('profiles/measured-trial.json').write_text(json.dumps(asdict(p), indent=2))
```

```sh
python -m brickcad build --profile profiles/measured-trial.json --out build/measured-trial
```

`specification`は基準形状から突起半径、壁厚、チューブ半径を個別に設定し、既存の `clearance` は0にします。
選択IDだけでなく機種・材料・スライサー条件・実測記録も保存してください。

## 検証の意味

BRep妥当性、5つの独立ソリッド、試験片間の非干渉、寸法、刻印の除去体積、STL閉メッシュ、CADとの体積一致、STEP再読込を確認しています。
各試験片は合成名目モデルとの上下・挿入・交差姿勢も計算しています。ID1の幾何干渉は意図した探索候補であり、書出し失敗ではありません。
`passed=true`はデータ生成の検査が通ったという意味です。保持力や実物との互換性は未検証で、`physical_fit_validated=false`です。
CADと純正の形状差、印刷の寸法誤差、材料の弾性・摩擦を合わせた実用補正を選ぶ試験で、これらを単独で同定するものではありません。
