# Issue #39 — 設定駆動ボールコースの段階移行・第1段階

**これは既存のCADを壊さない再現性実験です。** 新しい形状を設計するものではありません。

- `course.json` 1ファイルの宣言から `brickcad.course_generator` を呼び、既存設計の厳密に対応する版を生成。
- `experiments/course_replay_d01`: **D01-V2**（実物良好、窓3つ、直線下りトンネル、E31-05）。
- `experiments/course_replay_t01`: **T01-V4**（丸入口／高天井の直線トンネル、E31-05；実物成立性は未確認）。
- カスタム `design.py` は不要。従来のCAD検証器・STL・STEP・プレビューをそのまま使う。
- `cad-build.json` で各宣言の版を固定し、既存の差分選択と失敗復旧を利用。
- 既存 `parts/` 内の設計・版・実験結果は一切変更しない。
- `course-manifest.json` にレシピhash、元の設計IDとSTL hash、未実物検証フラグを出力。
- **未対応の設定はエラー**：窓個数、径、出口向きなどを変えても黙って旧形状を生成しない。
