# DUPLO：CAD・実測誤差の暫定モデル（2026-10-25）

## 結論

**一律の収縮率ではなく、特徴・経路・ジョブ・方向・測定方法を分ける。** 現時点で数値化できるのは「指定条件でノギスにどう表示されたか」の偏差であり、無荷重の真の造形寸法やプリンター単体の精度ではない。

最新の通常高さ16片ジョブでは7片が測定済み。隙間インフィルの突起径はCADから平均 **−0.2375mm**、本体外寸はベッドX **−0.2043mm**／Y **−0.0671mm**。この条件付きモデルは使えるが、経路切替を跨ぐ寸法変更や他ジョブへの転用は未検証。**CADパラメータや名目基準は変更しない。**

## 1. 観測モデル

測定値を次の二段階に分ける。単位はmm。

```text
真の局所寸法 = CAD寸法 + 特徴別偏差 + 経路別偏差
                + ジョブ差 + ベッド方向差 + 位置・個体・高さの差
測定値 = 真の局所寸法 + 器具の系統誤差
          + 当て方の偏り + 測定力による変形 + 読み取り・再設置のブレ
```

潜在的には階層モデルだが、全項を自由な係数として同時推定するだけの独立データがない。そのため現段階では次の小モデルに限定する。

```text
突起：    測定値 ≈ CAD外径 + 経路クラス別オフセット + 混合残差
直線壁：  測定値 ≈ CAD幅   + 特徴別・ベッド軸別オフセット + 混合残差
```

「混合残差」には真の造形差も計測差も含まれる。σをプリンターσ、ノギスσへ分割できない。押付けで凹む、中心から外れた弦を測る等の**過小側への偏り**は平均しても消えない。一方、穴・溝底等で誤差の符号が常に負とは限らず、概測値を真値の厳密な下限にも扱わない。未知の誤差に恣意的な±0.01／±0.1mmや正規分布を割り当てない。

倍率項も追加し得るが、同じ形状・条件でサイズを振った反復がないので固定オフセットと収縮率を分離できない。以下の切片は機械の補正定数ではなく、対象寸法付近での記述値。

## 2. 突起径：経路クラスを分ける

16片ジョブの右奥スタッドX/Y平均を**1片1標本**とする。X/Yを2回の独立印刷と数えない。

| 内側の経路 | 測定片数 | CAD外径の範囲 | 実測−CADの平均 | 片ごとの偏差の標本SD | 観測偏差の範囲 |
|---|---:|---:|---:|---:|---:|
| Gap infill | 6 | 9.20〜9.40 | −0.2375 | 0.0160 | −0.260〜−0.215 |
| Inner wall | 1 | 9.48のみ | −0.0650 | 推定不可 | 1点のみ |

今回のGap条件なら、例えばCAD9.40に対する平均表示値の予測は **9.1625mm**。同じCAD9.40の01/03/04は9.15／9.14／9.17mmだった。経路別平均偏差の差は0.1725mm。ただしInnerはCAD径・位置も違う1片なので、これを「経路変更の純粋な因果効果」とは呼ばない。

7片を一律オフセットで近似した訓練RMSEは0.0619mm、経路で分けると0.0136mm。ただし後者はInner1点を完全に当てているので、汎化性能ではない。Gap6片の1片ずつ除外した交差検証ではRMSE **0.0176mm**。傾きまで推定する直線回帰は同じ検証で0.0281mmだったため、今回は傾き1の単純オフセットを採用した。これは同一ジョブ内の検証で、次のジョブへの予測精度は保証しない。

過去結果との照合：

| 試料・測定セッション | CAD | 実測 | 実測−CAD | 解釈 |
|---|---:|---:|---:|---|
| 旧校正2・8点 | 9.40 | 平均9.35125 | −0.04875 | 後の再スライスはInner |
| 旧校正2・写真再測定 | 9.40 | 9.39 | −0.01 | 同じ個体の別測定。新しい印刷標本ではない |
| 旧校正3・8点 | 9.32 | 平均9.02750 | −0.29250 | 後の再スライスはGap |
| 旧校正3・写真再測定 | 9.32 | 9.05 | −0.27 | 同上 |
| 通常高さ2×2 | 9.40候補 | 9.38〜9.40 | −0.02〜0 | 印刷ファイル同一性・経路未確認 |

旧校正3へ今回のGap式を適用すると予測9.0825mm、旧8点平均との差は−0.055mm。旧データの経路は再スライスによる代理情報だが、少なくとも**今回の約0.018mmの交差検証誤差を、過去／将来ジョブの誤差幅へそのまま転用できない**。線種未確認のトンネルをGapと決めつけて学習には追加しない。

Gap式を逆算して実寸9.33を狙うとCAD9.5675になるが、これは学習範囲外であり、今回9.48でInnerに切り替わった事実とも衝突する。**逆算値を製作推奨値にはしない。** CAD径だけで線種を予測する閾値も置かない。旧9.40はInner、現9.40はGapという記録があるため、モデルの入力は実際のスライス経路とする。

## 3. 本体・裏内法：ベッド軸を分ける

今回の03だけ90°回転なので、ローカルXをベッドY、ローカルYをベッドXへ変換。他の測定済み6片は0°。対象は本体CAD31.80、内法CAD25.40、壁厚3.20mmの7片に限定する。

| 対象・ベッド方向 | 実測−CAD平均 | 7片の標本SD | 実測−CADの観測範囲 |
|---|---:|---:|---:|
| 本体X | −0.2043 | 0.0127 | −0.22〜−0.19 |
| 本体Y | −0.0671 | 0.0198 | −0.09〜−0.04 |
| 裏内法X | −0.1871 | 0.0377 | −0.24〜−0.14 |
| 裏内法Y | −0.0571 | 0.0419 | −0.10〜0.00 |

平均予測：本体 **31.596／31.733**、内法 **25.213／25.343**。本体の方向差は約0.137mm。1片の両軸を同時に除外する交差検証のRMSEは本体0.0180mm、内法0.0431mm。外形より内法の予測が粗い。

同じ片・同じローカル軸の `(外寸−内法)/2` は3.17〜3.21mm、平均3.193mm。CAD3.20に近いので、「内法が小さいのは側壁が大きく太ったから」という単独説明は合いにくい。外寸と内法には共通した方向差がある。ただし算出壁厚もノギス誤差を含み、これだけで熱収縮・機械軸・経路・計測姿勢の原因を特定しない。

旧本体測定には校正片31.51〜31.54、後の同じ校正片31.62／31.75等、通常高さ31.61／31.75、レール長63.47、カーブ63.51／63.78がある。旧校正片の当初の最大31.54と後の最小31.62でも0.08mm離れている。採寸位置・力・軸等が揃っていないので、これを純粋な再現性や経時収縮としない。

旧一般部品は軸不明なので値の組を保持し、ベッドX/Y係数の学習には使わない。63.8mm級への補正外挿もしない。33mm級で見えた方向差が倍になるか一定かは、まだ判別できない。

## 4. 計測ブレ：数値化できるものとできないもの

| 指標 | 観測値 | 含まれるもの／制約 |
|---|---|---|
| 旧校正2・8値のSD／範囲幅 | 0.0264／0.07mm | 4スタッド・2方向の形状差＋計測差 |
| 旧校正3・8値のSD／範囲幅 | 0.0158／0.05mm | 同上。8回の同一点再測定ではない |
| 今回突起の同一片XY差 | 0〜0.07mm | 真円度・方向差＋当て方・力。純粋な計測ブレではない |
| 今回チューブの同一片XY差 | 0.06〜0.25mm | アクセス制約・当て方等が大きい可能性。真の楕円度とは未確定 |
| 同じCAD9.40の01/03/04平均径 | 9.14〜9.17mm | 3個の位置・個体・測定差。04はチューブ径も異なる |
| 同一点・同一方向・同一高さの管理された再測定 | 0組 | 純粋な測定SDを推定不可 |

上のSDや範囲は、異なる集計対象を混ぜて足したり二乗和にしたりしない。同じ系統誤差が相関するためでもある。概測の穴径・チューブ径・曲面内幅は比較用データとして残し、精密補正係数の推定から外す。値の末尾0.01mmは器具表示の分解能であり、測定の正確さの根拠ではない。

高さは通常2×2−0.03、レール+0.02、カーブ−0.09mm。異なる3形状・別ジョブの少数データで、Z補正係数やZ精度は推定しない。溝底・球径・既存品内幅はCAD誤差の標本ではなく、比較形状の参考データ。

## 5. 嵌合は寸法モデルの別の出力

上面は、旧校正2の約9.35mmが概ね良好、通常高さ9.38〜9.40がきつい、今回9.415平均の15が入らない。今回Gap6片は保持しない。**9.32〜9.35mm付近は探索候補**だが、平均径だけの合否閾値にはしない。15は9.45／9.38と方向差もあり、上端R・穴・弾性・相手・着座も影響する。

裏面は、薄いチューブでも側壁が保持する可能性を入れる：

```text
側壁の名目締め代 I = ((列数−1)×純正ピッチ + 純正スタッド径) − 印刷内法
```

純正ピッチ16、スタッド9.32という参考値なら2列外端は25.32mm。旧校正2/3の内法約25.18〜25.22はI約+0.10〜+0.14で保持が良い。緩い直線トンネル25.34〜25.43はI約−0.02〜−0.11。今回7片の片方の内法25.16〜25.26はI約+0.06〜+0.16で、裏面全片「適度」と整合する。

中央チューブの名目隙間は `sqrt(8²+8²)−(純正スタッド径+印刷チューブ径)/2`。チューブ概測が小さいのに保持する試料があるため、チューブ径単独のモデルでは説明できない。これらは形状と接触の説明用指標で、保持力[N]を予測する式ではない。

カーブは2×2部分接続で弱く、4×2の4列接続では向きで保持が違う。これは接触範囲の重要性を支持するが、採寸方向との対応は訂正で不明になったため、57.17側が良好な向きだとは断定しない。薄壁化・チューブ拡大を一律適用する根拠にもならない。

## 6. 次に何を測るとモデルが進むか

まず新たな印刷を増やさず、手元の試料で分離する。

1. **測定由来のブレ**：01・03・15等の同一スタッド・同一軸・同一高さを各5回、毎回ノギスを離して軽い接触で測る。各回の値を保存。再設置を含む測定再現性を推定できるが、器具の絶対偏りや常に押し潰す偏りは残る。
2. **未測定9片**：まずCの06/08/09/11/14/16で位置・回転の反復を増やす。現在は基準Cが01と03の2個しか測定済みで、03だけ90°。次にW16/W24/T50で保持要因を比較する。
3. **形状差と力の影響**：01等で4スタッド×2軸を測り、同一点再測定とスタッド間差を分ける。チューブ概測には力を増して精密さを装わず、可能ならアクセスしやすいゲージ／断面比較を用いる。
4. 次の造形では、同じCAD外径で内側経路を変える対照を事前スライスで確認し、位置を入れ替えた反復を行う。内径変更による剛性・熱履歴の差も残るので、線種だけの因果とはしない。
5. 同一STL・設定・位置の別ジョブ反復でジョブ間差を推定。4個対5個の効果、中央X=90効果、サイズ倍率はさらに別の比較が必要。

## 再計算と検証

```sh
python scripts/analyze-dimension-errors.py
```

標準Pythonのみで[係数JSON](../measurements/2026-10-25-error-model.json)を再生成する。入力は正規化測定JSON。範囲や純正品は原データとして保持し、精密な造形誤差の学習には入れない。今回の係数・交差検証・03の軸変換・重複排除・無効測定除外を確認した。CAD／ビューアー変更はないためCAD生成やブラウザ撮影は実行対象にしない。自動補正は無効で、今回の解析のためにプリントやジョブ実行はしていない。
