# 設計・検証の境界

## 目的
標準2×4ブロックを出発点に、将来の変則ブロックをコードで設計し、CADで確認し、印刷・実測を次の改訂へ戻せる環境を作る。

## 採用した構成
Python + CadQuery 2.7.0 / OpenCascade。STLを直接いじらず、正確な円筒・平面からなるBRepを正とする。STEPは編集・他CAD連携用、STLはスライサー用。Matplotlibは実際の三角形メッシュとブーリアン切断形状を描画する。HTMLビューアーは外部CDN・サーバー不要でCAD由来メッシュを回転表示する。

`profile → BRep生成 → 体積/寸法/特徴検査 → STL/STEP書出しと再検査 → 組立干渉計算 → 断面/3D確認 → 印刷/計測 → profile改訂`

「閉ループ」の自動化範囲はCAD生成から検査・可視化まで。出力をエージェントが読み、欠陥を修正して再実行できる。物理試験はユーザーが担い、測定記録をエージェントが次の設定へ反映する。自動印刷、自動実測、FEA接触解析は未実装。

## 公差パラメータ
`clearance=c` は半径方向mm。スタッド半径をc減らす、側壁の内面をc外側へ移す、チューブ外半径をc減らす。チューブ内径は固定。c>0で緩く、c<0で意図的な幾何干渉が増える。

同じ設定同士では壁側隙間が2c、名目モデルとの片側比較ではおおむねcとなる。チューブ側は名目値で約0.00685 mmの隙間があり、これに両部品の補正が加わる。`first-print.json`の+0.05は未調整の候補であり推奨公差と断定しない。スイープ[-0.04,0,+0.04,+0.08,+0.12]は探索用で、全てが正常嵌合すべきという合否条件にはしない。

名目モデルは同じ形状生成器による**合成基準**。独立した純正実測形状ではないため、これとの無干渉は純正互換性の証明にならない。分析式による体積と明示的な寸法/特徴テストを併用し、生成器の自己一致だけに依存しない。

## 検証項目

- BRep妥当性・単一ソリッド・外形・底面開口・天井・スタッド・チューブ穴/壁。
- 独立した解析式とCADの体積比較。
- 実際に書き出したバイナリSTLの辺の出現数・向き・退化面・符号付き体積。これは全種類のメッシュ自己交差を検出するものではなく、有効なBRepの検査と組み合わせる。
- STEP再読込後の妥当性・ソリッド数・体積。
- 挿入経路5姿勢、印刷同士・合成基準の上下両方向の共通体積。
- 1ピッチずらし・90度交差、半ピッチずれ・押し込みの負例。
- 負の公差で干渉が発生し、正の公差でなくなること、底を塞いだCAD・欠損STLを検査が拒否すること。

干渉判定の1e-5 mm³は数値計算用の閾値。印刷精度の意味はない。現状は挿入軸に沿った離散姿勢での検査で、連続経路の衝突保証や任意形状の組立経路探索は行わない。HTMLの高さスライダーは表示用で、移動中にBRepを再計算しない。

## 実物のループ
1. プリンター、ノズル径、材料、積層ピッチ、スライサー設定、相手ブロックを記録する。
2. まず+0.08など緩い候補を単体印刷し、無理なく試せるか確認。各STLを別々に使うためラベルが混ざらないようにする。
3. 純正の上に印刷品、印刷品の上に純正、印刷品同士の3通りを確認。「入らない/きつい/適度/ゆるい/保持しない」を記録する。きついものは無理に押し込まず、その試料の試験を止める。
4. ノギスで外形・スタッド径を測定し、`measurement-template.json`に記入。記録は`measurements/`に別名保存する。
5. 記録に基づき新しいprofileを追加し、同じ検証を再実行する。必要なら次段階でスタッド補正・受け側補正を独立化する。

初回はスタッド上向き・底開口下向きを想定する。ただし天井下面はブリッジになる。サポートの要否や層厚、象の足補正などは機種とスライサーで確認する。保持部に残るサポートや象の足、真円度、収縮はこの形状検証では再現できない。機種不明のためG-codeは生成しない。

## 拡張順
実物で2×4を校正 → 2×2/2×3で再確認 → L字・斜め等の占有セルと接続面 → 任意姿勢の組立API → 必要性が判明してから材料試験・弾性/接触解析。1列ブロックは裏面の支持構造が異なるため、現在は明示的に拒否する。
