# Issue #39 第4段階 — 開放・トンネル急カーブの共通生成

- 追加実験 `experiments/course_curve_open/course.json` **Y01-V1** / `course_curve_tunnel/course.json` **Y02-V1**。歴史的C01-V5、C02-V5と新試作IDを衝突させない。
- 一つの生成器 `brickcad.course_curve_generator` と一つの形状組立 `brickcad.course_sharp_curve`。両方ともR16の連続トーラス案内溝＋西入口／南出口。天井 `open` / `tunnel` の選択だけで、開放側は **スタッド0**、トンネル側は高い屋根と局所半球逃げを採用し **屋根4スタッド**。
- 下面のE31-05は**経路切削後の切断型の形状**を維持。開放レールに不自然な孤立スタッドを追加しない。
- **広い転回室は導入しない**：C02-V4が底で停止、C02R-V1が衝突損失。C02-V5が復元した元C02-V2の局所的な上天井逃げを採用。CADで元V4が失った内壁2点を回帰判定。
- 原形との比較テストは `tests/test_course_curve_parity.py`：PR #36の固定コミット `fc70fdd3bf34a6b675595d54c721cec4544e1e76` を一時git worktreeに展開し、元のCADからSTEPを書き出す。新生成器を **旧刻印IDで構成**して双方向BRep差分が各0.05mm³未満かを判定。固定コミットが取得できなければ失敗（無言のスキップなし）。
- 球（実径24.26mm）19サンプル、過大球28mm不通過、通路床・屋根・元の内壁・E31チューブ、メッシュと体積を検証する。
- 可変曲率・左右反転・緩坂×急カーブなどは**まだ拒否**。BRepの幾何同等性と範囲制約が確認できた後に拡張する。
- **PR #55 Stage 1はユーザーの指示により「成功したと仮定」**して開発するが、実際の印刷/転がり/嵌合/バリ確認については未報告のため、CAD report、manifest、PRの `physical_rolling_validated` はfalseを維持。実物結果が出た時点でこの評価を置換する。
