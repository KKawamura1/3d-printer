# E31-05への実用パーツ移行計画（2026-10-31）

嵌合の暫定標準はE31-05（OD13.20/R0.20ビード/4スリット）。E31-07は代替として保持する。
純正同士並みの保持力や子供用玩具としての安全性は確認できていない。

| 順番 | 現行パーツ | 状態・サイズ | 移行方針 |
|---|---|---|---|
| 1 | 直線トンネル parts/tunnel | T01-V2、2x2、2段高 | **T01-V4** にE31-05とT04-V1の丸入口/高天井を統合。今夜は3個目安で1回印刷 |
| 2 | 90度トンネル parts/elbow | E01-V2、4x4、2段高 | E31-05、丸い入口→内側高天井へ移行。曲線の断面遷移とサポート/ブリッジを検証して別便 |
| 3 | 坂カーブ parts/sloped_curve | S01-V2、4x4相当 | 以前にスライス問題があったため支柱構造を先に見直し。今回は印刷しない |
| 4 | 直線レール parts/straight_rail | 独立の古い寸法系 | 必要になったらE31-05へ。純正の通常レールがあるため優先度低 |
| 5 | 通常ブロック parts/basic_brick | 2x4 | 純正があるため基本的に後回し |
| 旧8個セット | parts/play_set | P20-V2、旧版依存 | **今夜は生成しない**。各パーツの実用版が揃うまで更新しない |

## 初回の制約

- 配置個数はスライサー所要時間（約2時間以下）から逆算。3個を基本、超えたら2個。
- 2x2トンネル複数を優先し、大型4x4カーブ系は別便にして就寝前の2回目を確保する。
- T01-V4が採用した丸入口はT04-V1由来の1mm円形リップ＋4mm遷移。
- E31-05保持の証拠は通常高さの実験片によるもので、トンネルの4.75mm浅い下面へは未検証の転用。
- 生成成果は版付きSTLのみ。旧デザイン・実験の履歴は変更しない。
