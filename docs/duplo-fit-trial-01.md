# DUPLO 通常高さ2×2：接続試験01

次に印刷するファイルは `examples/duplo-fit-trial-01/brick.stl` です。
コンパクト試験片で得たユーザーの結果から、**突起2番＋受け3番**を組み合わせました。
追加の寸法調整や全体倍率の補正は行っていません。

| 項目 | 設定 |
|---|---:|
| 本体外形 | 31.8×31.8×19.2 mm |
| 突起込み高さ | 23.7 mm |
| スタッド間隔 | 16.0 mm |
| スタッド外径／穴径 | 9.40／6.50 mm |
| 内壁厚 | 3.16 mm |
| 裏面チューブ外径／内径 | 13.02／9.40 mm |
| 天井厚 | 1.60 mm |

CAD体積約9.763 cm³、密度1.24 g/cm³のPLA換算で約12.1 g。
パージ・サポートなどは別です。実使用量と印刷時間はスライサーの見積りを使います。

## 印刷と確認

- mm単位、倍率100%、突起を上向き、底開口を下向き。1個だけ印刷します。
- 比較できるよう、前回の試験片と同じ材料・スライサー設定を使ってください。今回同時に充填率やフロー等を変更しません。
- 今回は通常高さでの接続と保持力が確認対象です。壁・天井・チューブは肉抜きしていません。
- 完全に冷めてから、純正DUPLOの同じパーツと上下それぞれで確認します。

1. 純正の上に印刷品を載せる：受け3番の感触を維持しているか。
2. 印刷品の上に純正を載せる：突起2番の感触を維持しているか。
3. 両方向で、奥まで着座するか、軽く持ち上げても保持するか、無理なく外せるかを確認します。
4. 同じ組合せで3回程度着脱し、急に緩む／きつくなる、割れる等の変化があるかも記録します。

きつい場合は無理に押し込みません。
今回の通常高さ形状は未印刷で、`physical_fit_validated=false`です。
低い試験片からの寸法移植であり、壁のしなりや保持力が変わらないという保証ではありません。

## 根拠と記録

元の試験データ・実測値は `measurements/2026-10-24-duplo-compact-01.json` に保存しています。
上下の接続感を選択根拠とし、測定された本体の縮みから一律の倍率や収縮率を推定してはいません。
2番・3番の突起径の差は設計差より大きく、測定位置／方向／突起ごとの追加測定は保留中です。
機種・材料・印刷設定の詳細も未報告のため、記録では不明のまま残しています。
追加データに応じて、この候補を改訂します。

## 再生成

```sh
python -m brickcad build --profile profiles/duplo-fit-trial-01.json --out build/duplo-fit-trial-01
```

profileは通常高さのDUPLO。`clearance=0`とし、スタッド半径4.7、壁厚3.16、チューブ半径6.51を明示して補正の二重適用を防いでいます。
CAD・STL・STEP・組立姿勢の幾何検査と実ブラウザ確認を行います。幾何検査の合格は純正との実接続・保持力の保証ではありません。
