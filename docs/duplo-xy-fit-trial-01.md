# XY方向差を考慮した通常高さ2×2：条件付き候補01

[STL・STEP・ビューアー・設計レポートZIP](../prints/duplo_xy_fit_trial_01.zip)

ユーザーの「印刷中の14個実験が想定通りだったと仮定する」に基づく、次の設計候補。**14個の実測・嵌合結果はまだない。完成品の理想値や採用済みの補正ではない。** 外径9.40／穴6.40／Inner wallで上面が適合し、裏面も従来同様適度である、という仮定を置いて作成した。別の外径・穴径が良好だったらprofileの該当項目を変更して再生成する。

## 設計値

| 項目 | CAD値 mm | 設計意図 |
|---|---:|---|
| 本体ベッドX方向 | 32.00 | 31.80に約0.20加算 |
| 本体ベッドY方向 | 31.87 | 31.80に約0.07加算 |
| 本体高さ | 19.20 | Z補正は推定せず維持 |
| スタッド中心ピッチX/Y | 16.00 / 16.00 | 中心間の実測がないため維持 |
| スタッド外径／穴径 | 9.40 / 6.40 | 今回の実験が成功するという仮定 |
| スタッド高さ／上端R | 4.50 / 0.50 | 通常高さ・丸めを維持 |
| 裏面空洞内法X/Y | 25.40 / 25.40 | 適度だった16片基準Cの接触位置を維持 |
| 中央チューブ外径／内径 | 13.10 / 9.40 | 概測からの単純拡大をしない |
| 結果としての側壁厚X/Y | 3.300 / 3.235 | 外側だけ広げ、内側を動かさない |
| 天井厚／本体角R／底入口面取り | 1.60 / 0.80 / 0.30 | 基準形状を維持 |

寸法はCAD原点中心、Z上向き、底面Z=0。補正は本体の外側面だけに適用し、穴やスタッドやピッチを一括拡大しない。**小さいCAD長方形を印刷後のほぼ正方形へ近づける試み**であり、CAD上は正方形ではない。

## XY誤差の使い方と限界

出典は[既存の誤差モデル](duplo-dimension-error-model.md)とIssue [#1](https://github.com/KKawamura1/3d-printer/issues/1)。7片・1ジョブの本体偏差はベッドX平均−0.2043、Y−0.0671mm。これを同じ31.8mm付近の条件付きオフセットとして使うと、印刷外寸の例示値は次の通り。

- X：32.00−0.2043＝31.7957mm
- Y：31.87−0.0671＝31.8029mm

これらは**新しい測定値ではなく、仮定に基づく計算**。補正を0.01mm単位へ丸めた設計に、推定係数の桁数をそのまま製造精度として要求しない。ジョブ・位置・計測力・壁の経路で変わり得る。今回の14個実測で方向差が変わった場合は係数を更新する。

外寸31.8mmでの偏差だけから、中心ピッチを16.10／16.03等へ広げることはできない。固定オフセットと縮尺誤差を分離できず、スタッド径にも別の経路依存性があるため、グローバルなXYスケール補正は採用しない。スタッド・チューブの円形を楕円へ変更する根拠もない。63.8mm級や4×4への外挿も行わない。

裏面内法を一緒に拡大すると、現在の側壁による保持を失う可能性がある。そこで内法CAD25.40とチューブを維持する。以前の偏差がそのままなら、裏内法はX約25.213／Y約25.343mm。純正スタッドの2列外端約25.32mmに対して主にX方向が接触する、現在の良好な保持仮説を残す。**裏面を印刷後にも正方形にすることは、今回の優先目標にしていない。**

一方、外側を増やすため側壁剛性は変わる。内法が同じでも締まり具合が同じとは保証しない。形状が変われば熱履歴・スライス経路も変わる。最終スライスと実物確認は必要。

## 印刷と検証

1. まず進行中14個の結果で外径・穴径・裏面の適否を確認する。今回のZIPは先行設計で、実験結果より優先しない。
2. `brick.stl`をmm・100%、上向き、**回転0°（CAD X＝プリンターX）**で読み込む。自動回転と全体スケール補正を使わない。90°回すと補正方向が入れ替わる。
3. 同じBambu Studio設定（A1 mini、0.4mm、PLA、積層0.20、壁2周、Classic）で全4スタッド円筒部のInner wallを確認。穴・外周・ブリム・天井ブリッジも確認する。STLには設定やG-codeを含めていない。
4. 外寸X/Yを同じ高さで3回、裏面内法X/Y、4スタッドのX/Y径、上下両方向の純正嵌合を記録。軽い接触で測り、各回ノギスを離す。上面保持・完全着座・取り外し・10回着脱後、横に並べた隙間を比較する。
5. **新たに中心ピッチを測る**。同方向の2スタッド外端間から、それぞれの直径の半分を引くと中心距離の参考値になる（径と端間の測定誤差を含む）。外寸だけから推測せず、隣接・交差・ずらし接続も確認する。

CAD/STL/STEP検査と合成基準への挿入・交差・隣接・負例検査は保持力の試験ではない。レポートは干渉量を隠さず記録し、`passed`は形状・出力検査の合格、`physical_fit_validated=false`／`slicing_validated=false`は実物・最終スライス未検証を表す。

## 再生成

```sh
python -m brickcad.xy_trial --out build/duplo-xy-fit-trial-01 --zip prints/duplo_xy_fit_trial_01.zip
```

`profiles/duplo-xy-fit-trial-01.json`を独立した試作profileとして追加。既存の名目・製品profileを変更しない。profileは専用モジュール用で、従来の`python -m brickcad build --profile`へは渡さない。`--profile`で別の候補を指定できる。出力には実CAD由来のHTML、断面プレビュー、STL/STEP、設計値・仮定・予測を分けたJSONを含む。
