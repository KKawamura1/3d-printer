# 4×4・90度下りカーブ 試作01

黄色い既存カーブと同じ4×4ポッチの占有サイズに収め、球が90度曲がる間に1段下る。

**現在の印刷データは形状・転がり確認用で、保持力を改善した版ではない。** #1の追加3コメントにより、同じ受け寸法の直線レール／トンネルは「傾けるだけで外れる」という明確な保持力NGが判明した。下記の受け寸法を、適合済み・変更不要と解釈しない。入口・出口の位置はデュプロの16 mm格子と既存直線レールの接続条件から決める。黄色い部品の途中の曲率や内部形状の完全な複製ではない。

- [印刷・プレビュー用ZIP](../prints/duplo_sloped_curve_trial_01.zip)：名前付きSTL、STEP、組立STEP、自己完結viewer.html、検証JSON、本手順を収録。

|---|---|
| 外形 | 約63.8 × 63.8 mm以内。ユーザーの「4×4に収まる」を16 mm格子へ反映 |

| 落差 | 19.2 mm、今回の試作値（デュプロ1段） |
| 走路中心半径 | 48 mm。入口・出口位置と90度の接線を満たす四分円 |
| 入口 | 西辺、床基準点 (-32, -16, 25.55) mm |
| 出口 | 北辺、床基準点 (16, 32, 6.35) mm |
| 接続口の断面 | 既存 Rail と同じ開口25.74 mm、床6.35 mm、壁上端19.13 mm（入口は+19.2 mm） |
| 球 | 約24.26 mm、既報の実測参考値 |
| 底面 | 4×4格子上の水平な受け。走路の下に残る部分だけを保持 |
| 受けの寸法 | 既存試作の外径13.30 mm、内径9.40 mm、壁厚3.16 mmを継承。新しい嵌合補正は未実施 |
| 丸み | 走路の縁と壁上角R0.5、底板の外周角R0.8、挿入口0.3 mm面取り |

床高は角度の進行率 t に対し `6.35 + 19.2 × (1 − 3t² + 2t³)`。両端の勾配は0、中央の最大勾配は約20.9度。半径方向のU字断面を25断面の滑らかなBRepロフトでつなぐ。走路の下は底面まで支える構造で、カーブ自体に高低2枚の受け面は設けない。走路のない内側・外側の床を取り除き、四分円の帯状外形にした。帯の外周は4×4の占有サイズに合わせ、走路の測定幅との差0.075 mmだけを薄い縁として残す。元の四角い床や、そこに属する受けチューブの部分は残さない。

## 組み合わせと試し刷り

1. STLをmm単位・100%で読み込む。受けの水平な底面をプレート側、走路を上向きに置く。スライサーで約63.8 × 63.8 × 38.33 mmになることを確認する。
2. 裏面の受け天井はブリッジになる。プレビューでブリッジ・受け穴・壁の連続性を確認する。受け穴を埋めるサポートを無条件に追加しない。G-codeや材料・ノズル固有の設定は本データに含めない。
3. カーブ底面を基準高さに固定する。入口側の直線レールは通常ブロック1段で19.2 mm持ち上げる。出口側の直線レールはカーブと同じ底面高さに置く。組立STEPとviewerの「Rail connections + support」で配置を見られる。
4. 高い西側から低い北側へ球を流し、境目の引っ掛かり・中央での壁接触・出口での飛び出しを確認する。まず入口付近から小さな勢いで試し、次に手持ちコースからの流入を確認する。
5. 接続の保持力、球が止まる位置、脱線、レール端の段差を記録する。既存直線の受けが緩いという報告は残したままで、この部品の保持力も試し刷りで確認する。

## 検証と限界

BRepの妥当性・単一ソリッド、4×4外形からのはみ出し体積0、残った受けチューブの開口、両端の接続、組立部品間の無干渉、STLの閉メッシュ・体積差、STEP再読込を検査した。高い直線レールと支持ブロックの接続だけは、従来の試作プロファイルに由来する剛体干渉約1.09 mm³を別欄に明示している。これは保持力の証明ではない。

球の通路は両端の直線レールを含む49位置の静的な球で確認。傾斜による球中心の高さを考慮した検査用配置であり、連続した全経路の保証や運動シミュレーションではない。2 mm低い球、1段の高さ違い、半ピッチの横ずれを負例として検出する。出力STEPに対しても実際の入口・出口の床高と、サンプル間の球通過をテストする。

スプライン面のBRep包囲箱は保守的に膨らむため、実メッシュの外形と「63.8 mm角の外へ残るソリッド体積が0」の両方で占有サイズを確認している。検証JSONには保守的BRep包囲箱も残す。

## 床削除後の4×4への接続

下に合成名目の4×4ブロック（突起16個、外径9.40 mm、高さ4.50 mm）を置き、差し込み高さ5.7／4.5／3／1.5／0 mmで検査した。着座時の各突起についても個別の衝突体積を記録した。

- **床・外壁・走路など、受けチューブ以外との干渉体積は全姿勢で0 mm³**。削除部に露出する突起も含め、床を削ったことで着座を阻む突起衝突はない。
- 突起上端4.50 mmに対し受け天井は4.75 mmで、**上端の隙間は0.25 mm**。
- 従来の受けチューブ外径13.30 mmは合成名目の9.40 mm突起に対して**半径0.03629 mmの締め代**を持つ。着座時の重複体積は約2.28 mm³で、受けチューブ領域に限られる。**剛体の完全無干渉とは記載しない**。
- #1の実測参考値9.32 mmの突起に置き換えた感度確認では重複0 mm³。ただし実測範囲9.31〜9.33 mmや測定条件には不確かさがあり、これだけで現物の互換性を保証しない。
- 半ピッチずれは約432 mm³の干渉、0.5 mm押し込み過ぎはチューブ以外に約208 mm³の干渉として検出。検査が衝突を見逃していないことも確認する。

viewerの「Seated on 4x4」「4x4 insertion exploded」で、下のブロックと露出した突起を確認できる。削除後もBRepは単一ソリッド。受けの剛性・保持力は床の形でも変わる。特にこのカーブでは四角い部品の対向する内壁を一部削除しているため、側壁接触で保持していた校正片の結果をそのまま移植できない。現在の衝突検査のPASSは着座を塞ぐ欠陥がないことだけを示し、保持を示さない。

## issue #1・#2に基づく寸法の再評価（#1の追加3コメント反映）

[issue #1](https://github.com/KKawamura1/3d-printer/issues/1)の本文と追加3コメントを確認した。特に[最新の校正片2・3の再測定](https://github.com/KKawamura1/3d-printer/issues/1#issuecomment-6383416217)を優先する。途中の「チューブ径を13.4〜13.6 mmへ増やす」という仮説は、後続コメントで撤回されている。

| 比較 | 校正片3番（嵌合がベスト） | 2段直線トンネル（傾けるだけで外れる） |
|---|---:|---:|
| チューブ実測外径・概測 | 約12.94 mm | 約13.05 mm |
| 印刷した内壁間 X/Y | 25.22 / 25.18 mm | 25.43 / 25.34 mm |
| CAD内壁間 | 25.48 mm | 25.48 mm |

純正スタッドの過去実測9.32 mmと16 mmピッチから2ポッチの外端間は約25.32 mm。良好な校正片の内壁間はこれより0.10〜0.14 mm狭く、緩いトンネルでは0.02〜0.11 mm広い。**校正片では側壁接触が保持に効いていた可能性が高い**。チューブは良好な方が小さく、管径だけで原因・補正量を決められない。同じCAD内法でも印刷実寸が異なっており、形状・剛性・造形条件の影響は未分離。

| 対象 | 今回の判断 |
|---|---|
| 全体の占有サイズ・ピッチ | **維持**。直線レール／トンネルの継ぎ目・走行方向の長さ・位置合わせは実物で問題なし。過去の全長63.47 mmだけを根拠に一律拡大しない |
| 高さ・走行断面・角R | **維持**。直線部品では転がり・造形・角の触感が良好。カーブの転がり自体は未試験 |
| 受けの保持力 | **改善が必要**。現行13.30 mmチューブと壁3.16 mmのままで十分、という評価にはしない |
| チューブ径 | 単独で増やす案を採らない。壁の接触と独立して評価する |
| 受け内壁 | 第一段階の校正候補は壁3.16／3.22／3.24 mm（2×2のCAD内法25.48／25.36／25.32 mm）、チューブ13.30 mm固定。数値は試作仮説で未印刷 |
| カーブへの適用 | 床削除に伴い対向内壁の一部もなくなった。四角い2×2で成功した壁厚を入れるだけでは不十分で、残った壁・チューブ・突起の実接触をカーブ側で再評価する必要がある |
| 上面突起 | トンネルのCAD9.20 mm→実測8.99/9.03 mmは緩い。別系統で校正し、本カーブ（上面突起なし）の補正に混ぜない |

本PRの現行STLは、余分な床を除き着座の阻害を確認した**未補正の形状試作ベースライン**として保持する。上記の校正候補を検証せず「保持力を改善した版」に差し替えない。保持力まで満たしたものが必要な場合は、内壁の接触を主な候補として校正し、その後このカーブの残った接続部で再確認する。これは寸法変更が不要という結論ではない。

根拠・過去判断・追加データ・校正候補は[寸法レビュー記録](../measurements/2026-10-24-sloped-curve-dimension-review.json)に保存した。記録の物理的な良好評価は直線レール／直線トンネルに限定し、このカーブの実物評価には流用しない。

`physical_fit_validated=false`、`physical_rolling_validated=false`。曲がりながら加速するため、転がり・摩擦・跳ね・脱線と、スライサー上の造形性は実物で確かめる。
