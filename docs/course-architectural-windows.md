# Issue #37：窓付き全形状を共通デザイン比率で再試作（2026-11-06）

## 完了条件と設計方針

実印刷に成功した `D01-V3` の窓列と、Draft PR #74 の `SD04-V20` の設計を原則として採用する。

**窓のある壁面を一つの連続したファサードとして扱う。** 入口→窓間1→窓間2→出口の**壁の空白部分**の比率を次のようにする：

- **平面は 1.5 : 1 : 1 : 1.5**。壁の可視区間長と3つの窓幅から端余白・窓間隔を逆算。元のD01の成功した窓の形・寸法（幅8mm、ほぼ16mmピッチ）を継承。短めの直線では窓幅5.5mmを採用する。
- **凸曲面は 1 : 2 : 2 : 1**。壁を実際の面に沿う弧長で12等分し、区間1.5–2.5、5.5–6.5、9.5–10.5に縦長5角形窓を配置。凸曲面に直線が連続する場合は**一本の壁全体**に適用（SD04-V20の試作を参考）。
- **凹曲面には窓なし**。反対側の独立した平面がある場合、その平面だけ別のD01型3窓を試作。
- **2×2小型の例外**：幅・柱の強度を犠牲にして3窓を作らない。狭い壁・縦の落下シャフトは1窓。2×2直線T01には柱2.5mm以上を確保した3窓を試す。
- 坂では各5角形の頂点を個別に実路面の高さへ追従させる。各窓で壁を削った体積、球中心への視線、残る低いガード壁、単一立体、元の外形、STL水密と共通E31-05監査を必須とする。
- **従来成功のD01-V3は一切変更しない。** 既存のPR56・PR73・PR74のSTLと過去の印刷成功記録を変更せず、すべて新しい版を生成する。
- 4×4水平緩カーブE01は外形が矩形なので、現実にボールが見える入口・出口付近のそれぞれ32mmの平坦な壁区間に整然と3窓ずつ。ボールから遠い空白の四半分の側壁に穴を配置しない。
- 小さいC02の丸いポート周りは構造重視で、独立した外壁の正面に小さい1窓を採用。

## 実装・CI

`brickcad/course_architectural_windows.py` が上記3つの原則に従い、元のPR56の独立CADを生成後、必要な窓だけを引き算する。元の接合寸法や球の通路は変更しない。

`tests/test_course_architectural_windows.py` は平面の1.5:1:1:1.5、凸の1:2:2:1、凹面0の**配置計算と全11形状の網羅性**を高速検証。

専用の `.github/workflows/course-architectural-windows.yml` は**この実験ブランチだけ**を対象にする。11個の重いCAD/STL生成は `[generate-windows]` 付きコミットまたはワークフロー手動起動に限定（通常のPRのCIでは実行しない）。元の共通CADカタログCIも変更しない。

全形状がCAD・視線・メッシュ検証に合格したときのみ `scripts/course_architectural_plates.py` でA1 mini用の複数プレートへ分割して保存する。すべてを無理に一夜の1プレートへ圧縮しない。各パーツのSTLと印刷用プレートを別々のArtifactとして出力。

**CAD合格・印刷前のスライサープレビュー・実機印刷成功は別**。サポートOFFでの印刷・窓強度・ボールの転がり・印刷品同士の嵌合は未検証。これはDraft検証PRとして扱い、mainへはマージしない。
