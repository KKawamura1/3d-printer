# DUPLO 大規模校正実験01（Issue #1）

[印刷・測定一式ZIP](../prints/duplo_experiment_01.zip)を展開し、**plate.3mf**をBambu Studioにモデルとして読み込む。これは配置付きの標準3MFで、Bambuの印刷設定付きプロジェクトやG-codeではない。ZIPには全体3MF・個別STL16個・STEP・記録用ファイルを含む。再生成時のplate.stlも同じ16個で、重複データを減らすためZIPには含めない。全体3MFと個別STLを同時読み込みしない。全16個は別々のソリッドで、共通の床はない。100%・mm・突起上向き。

全試料は31.8×31.8×19.2mm、突起込み23.7mm。ピッチ16、突起穴径6.50、チューブ穴径9.40、天井1.60mmを固定。外角／上縁R0.8、突起上端R0.5、裏入口面取り0.3mmは既存rounded_brickと同一。**Cは旧校正片2番と接続CAD寸法が同じだが、高さ・丸め・マークは違う。旧試料と同一形状ではない。** 全候補で丸め等の条件を統一した。

## マークと測定方向

IDはローカル−Y外側面の高さ約9〜14mmに凹刻。**IDの上の矢印がローカル+X**、隣の+X外側面の矢印がローカル+Yを示す。刻印は深さ0.25mm、矢印はZ=15〜17mm。底面から5mmまで、突起、裏チューブ、内壁、上面着座部を変更していないことをBRep差分で検査する。側面の刻印自体による微小な経路・冷却差までは排除できない。

0°はローカルX=ベッドX、Y=ベッドY。90°はローカル+X=ベッド+Y、+Y=ベッド−X。取り外し前にプレート全体を撮影し、刻印と配置を照合する。個別STLはローカル原点・回転0°なので、単体再印刷ではreport.jsonの配置／回転を明示的に再現する。

## スライスと記録

旧plate.3mfからIssue #1に記録された期待設定をsetup.jsonに入れた。今回の実行条件とは区別する。A1 mini 0.4 nozzle／Bambu PLA Basic／0.20mm Standardを選び、以下を照合する。

- 層厚0.20、壁2周、Classic、外壁線幅0.42／内壁0.45mm、外壁200mm/s。
- Grid 15%、流量比0.98、XY輪郭／穴／象の足補正0、Aligned seam、円のscarf seam有効、circle compensation無効。
- レイヤーごと、サポートなし、auto brim／幅5mm。

温度、冷却、加速度、初層、動的流量校正など、この抜粋にない設定は勝手に推定しない。可能なら元のBambuプロジェクトの設定を使い、実際の設定付き3MFとスライス後G-codeを別名保存する。モデル読み込み後、全体中心(90,90)、寸法、16個の向き、ブリム／排他領域をプレビューで確認する。保存時に配置が変わっていれば元に戻し、actual_centers_and_rotations_verifiedを記録する。

通常高さ版の突起外周はZ≈21mm、空洞天井はZ≈17.6〜19.2mmでLine Type／Speed／Flowを比較する。**元の低い校正片のZ≈8mmを今回の突起比較に使わない。** 元3MFの再スライスG-codeは未提供なので、この実装で旧2番／3番の経路差を解明したわけではない。

印刷時間・材料量は今回のスライス結果を採用する。report.jsonのsolid_massはCAD全充填換算であり、15%充填の実消費や所要時間ではない。旧見積194gを確定値にしない。

## 印刷後の測定

setup.jsonに実際の版・条件・相手の純正品を記録する。measurements.csvには各個体の4スタッド×ローカル2方向×3回、外形・内壁間・チューブ径の2方向×3回の空欄を用意した。未測定は空欄のまま。スタッド位置はローカルXYの符号で記録する。

突起径はR部・根元を避けた同じ高さ（例：突起根元から2mm、Z=21.2mm）で、中心を通るように軽く当て、毎回離して測る。外形は刻印と角Rを避ける。内壁・チューブは入口面取りより上、同じ高さで測り、正しく当てられないものはapproximate=trueとしてメモする。押付力で小さくなる観察があるため、表示桁数を精度と扱わない。

同じ純正品を相手に、純正を印刷品の上に載せる場合／印刷品を純正の上に載せる場合を別々に評価し、setup.jsonのfit_resultsへ「入らない／きつい／適度／緩い／保持しない」、着座、繰返し回数を記録する。上側と裏側の採用候補は別々に選ぶ。

## 解釈できる範囲

8個のCで同一ジョブ内の個体・位置・向きを含む分布を調べる。回転は0°4個／90°4個だが同じ位置での対比較ではない。S/T/Wは各1個で位置と交絡するため、差を寸法変更の因果効果と断定しない。微差なら次回に位置を入れ替えて再現する。

この格子にはX=90mm上の試料がない。旧2番の中央配置仮説を直接検証するには、次のジョブで中央配置の同一CAD反復が必要。同時印刷4個対5個やジョブ間差も1ジョブでは検証できない。純正の薄壁構造への変更、保持力の保証、全体収縮率の決定は今回の範囲外。

## 再生成・検証

```sh
python -m brickcad.experiment --out build/duplo-experiment-01 --zip prints/duplo_experiment_01.zip
python -m unittest discover -s tests -v
python -m brickcad all
```

有効な16ソリッド、寸法、相互無干渉、各STL／プレートSTLの閉メッシュと体積、STEP再読込、刻印と接続部の非干渉を検査する。合成名目モデルとの接触が生じる太径候補も実験データとして保持する。合格は形状・出力検証であり、嵌合・保持力の物理検証ではない。全候補physical_fit_validated=false。

手動のCAD previewではexperimentを選択できる。生成フォルダのviewer.htmlは16個全体、sample/viewer.htmlは01 Cの詳細確認用。
