# 2段トンネル・試作01

上下は通常のDUPLO接続、側面の向かい合う2面にボール通路を設けた2×2ブロック。通常ブロック2段分の高さで、既存レールと同じ高さの通路を持つ。実物の嵌合・転がり・強度は未検証。

## 印刷するもの

- [印刷用ZIP](../prints/duplo_tunnel_trial_01.zip)：`duplo_tunnel_2x2_trial_01.stl`、STEP、検証JSON、印刷手順を同梱。
- [STL](../examples/duplo-tunnel-trial-01/brick.stl)
- [上下の通常ブロックとの組立画像](../examples/duplo-tunnel-trial-01/assembly.png)：赤が今回の印刷品。青・緑は配置確認用の合成基準モデル。
- [実ブラウザの確認一覧](../examples/duplo-tunnel-trial-01/review-sheet.jpg)

Bambu StudioにSTLを**mm・倍率100%・突起を上向き**で読み込む。既存のプリンター・ノズル・PLA設定を使用。積層0.2 mm・外周4周程度を初回候補とする。まず内部サポートなしでスライスし、天井の約5.24 mmの橋渡しと、底面の受け空洞の橋渡しをプレビューで確認する。サポート不要の保証ではない。内部のサポートが走行面や受けに残ると機能を妨げる。G-codeと印刷時間・使用量の見積もりは生成していない。

当初の「幅・高さ約26 mm」という案から、上部を山形に広げた断面に具体化した。下部円弧はレール試作01と一致。既存レールと同じ下ブロック上に並べ、中心を16 mmピッチで配置する。外形の隙間は通常0.2 mm。水平通路なので静止球が自動で進み続ける形ではなく、上流からの勢いが必要。

## 検証したこと

- 有効な単一BRep、外寸、床・天井・中空突起・裏面チューブ、STL閉殻と面の向き・体積、STEP再読込。
- 直径24.26 mmの球の中心を床＋半径＋0.05 mmに置く直線経路について、連続掃引体との共通体積が0。直径28 mmでは干渉を検出する負例も確認。
- レール試作01と隣接させ、継ぎ目の前後5位置で球との無干渉を確認。球径はユーザーの参考実測値。
- 上に通常高さの合成名目ブロックを載せる5挿入姿勢は無干渉。トンネル同士の整列・1ピッチずらし・90度回転も無干渉。半ピッチずれ・0.3 mm押し込みは干渉を検出。
- **下の名目ブロックと裏面受けには約0.0363 mmの半径方向干渉がある。** これは前回の緩い受けを改善する試作値を引き継いだもの。レポートに干渉量を残し、`fit_geometrically_clear=false`、`physical_fit_validated=false`としている。CAD検査PASSは保持力・純正互換性の保証ではない。
- ブラウザの11視点・表示状態を撮影し、上面、裏面、通路断面、組立、分解、交差、負例、モバイルを確認。詳細とハッシュは同じ例フォルダの記録を参照。

## 印刷後の確認

1. 角や通路内の垂れ・バリを確認する。
2. 上下を別々に純正ブロックにつなぎ、着座・着脱・保持を確認する。きつければ無理に押し込まない。
3. 手元のボールを両方向から通す。
4. 既存レールにつなぎ、低速でも継ぎ目で引っかからないか確認する。

## 再生成

```sh
python -m brickcad.tunnel
python -m unittest discover -s tests -v
python -m brickcad all
BRICK_CHROMIUM_PACKAGE="$PWD/build/browser-package/node_modules/@sparticuz/chromium/build/index.js" npm run browser:check -- build/duplo-tunnel-trial-01 build/tunnel-browser
python scripts/review-sheet.py build/tunnel-browser
```

初回の環境構築は[new-session.md](new-session.md)を参照。`python -m brickcad.tunnel`は回転・断面・トンネル同士・上下通常ブロックの表示を持つ自己完結型`viewer.html`も生成する。STL・STEPを正とし、画像は同じBRepから生成する。
