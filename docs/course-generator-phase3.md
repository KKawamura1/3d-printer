# Issue #39: 第3段階 — S01/S02の共通急落下トンネル生成器

この段階も **同じPR #56** に追加します。共通モデル `brickcad/course_steep_drop.py` は、PR #38 S01-V5 と PR #41 S02-V8 を参考にした**独立の再構成**です。元PRのSTLや既存の版は変更しません。

- `experiments/course_drop_east/course.json` → **X01-V2**（西高入口→東低出口、着地から出口まで9.75mm、約33°）。
- `experiments/course_drop_south/course.json` → **X02-V2**（西高入口→南低出口、着地から出口まで8.45mm、約33°）。北側閉塞を確認。
- 2つは**同じ組み立て関数**、同じE31-05受け、尖った屋根の縦穴、連続球サンプルとカプセル検査を共有し、出口の方向だけを設定で切り替えます。
- 南向きは**R16の水平90度円弧ではなく**、低出口に向かう坂で方向転換（PR #41に準拠）。
- 2×2×高さ3の矩形ボディに4スタッド・中央の下面チューブ。**曲線で削った外形や部分スタッドに転用する際は、ユーザー指定の切断型（クリップ）を要実装**。
- `scripts/cad_versions.py` は指定した生成器を検出し、依存Pythonモジュールとレシピを版固定の指紋に入れます。歴史的v1/v2ジェネレータには変更を加えません。
- 急落下の窓、開放レール、緩カーブ、他の出口方向、ランアウト勾配変更は未対応として拒否。
- **現物未検証**。旧S01-V4/S02-V6の実績は新しいX01/X02に継承しません。実際の無サポートスライス・着地衝突での速度損失・転がり・E31の嵌合を印刷後に確認してください。
