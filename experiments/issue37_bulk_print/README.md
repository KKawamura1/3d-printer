## 生成・追跡のルール

- 形状・刻印は元CADから一切変更せず、XY並進／90度回転だけで180×180mmプレートへ配置。モデル外接矩形間は4mm以上を検証。
- 各STLの出所を**PR head SHA・版番号**で固定。既存の成功Artifactがある9点はrun/artifact IDと**実ファイルSHA-256**を照合して再利用。runをPRごとに重複ダウンロードしない。
- PR #50 の左右2点は、直近の成功runに対象STLが含まれていないため例外として、**そのPRの固定head SHAから必要な2モデルだけをビルド**する。CADレポートpassedとmesh.passedを確認し、生成した実STLのSHA-256を公開manifestへ記録する。無関係なCADを全再生成しない。
- PR headが変わった、CAD版番号が変わった、成功Artifactを取得できない、SHAが一致しない、CADレポートが不合格、STLがない、配置間隔が不足する場合は**黙って旧版を使わず失敗**させる。
- 成功時はGitHub Actions `issue37-a1mini-print-plates` Artifactに11点の個別STL、合成2枚、ハッシュと座標を含む`manifest.json`を公開。Artifact保管は14日。Gitに生成STLはコミットしない。
- 物理印刷は未実施。Bambu StudioでサポートOFFのスライス、床面、天井、開口、刻印、嵌合、球の自然転がり各10回を確認し、Issue #42に**新しい版と旧実績を区別**して記録する。

旧プレート1（9点）の実印刷評価はIssue #42/#60とPR #55コメントに保存。新設計のCAD合格は実物合格を意味しません。
