# Issue #37: A1 mini 13種の一括印刷実験

元のCAD検証済みSTLを**形状変更せず**、XY方向の平行移動と90°回転だけで集約する実験です。STLは別々の閉鎖シェルとして一つのファイルに入ります。

- **Plate 01（9点）**: #43 GC01-V3、#46 SC03-V3、#52 SG01-V6、#53 SG02-V7、#48 SD01-V1、#49 SD02-V2、#50 SD03-V3、#51 SD04-V2、#36 C02-V5
- **Plate 02（4点）**: #44 D02-V2、#38 S01-V5、#41 S02-V8、#45 S03-V3
- 180×180 mmの範囲内に配置し、各パーツのXY外接矩形間には**4 mm以上**の間隔を取ります。Plate 01の総外接矩形は約167.4×167.4 mm。
- 成功したGitHub Actions `cad-verified-stl`の実行ID・Artifact ID・各STLのSHA-256を`sources.json`で固定。レポート不合格／ファイル未取得／ハッシュ不一致は**スキップせず失敗**とします。
- ワークフロー `Issue 37 multi-part A1 mini print plates` の成功runから `issue37-a1mini-print-plates` を取得。中身は**2枚の合成STL + 13点の単体STL + 出典と配置のmanifest.json**です。生成物本体はGitにコミットしません。

## 印刷前の確認

Bambu Studioで2枚それぞれを読み込み、**A1 mini 180×180 mmでサポートOFFの実スライスを確認**してください。天井、内部のバリ、浮動片持ち梁、初層、ブリムの干渉は人間の確認が必要です。4mmの間隔は左右2mmずつのブリムが接する大きさなので、ブリムが大きい場合や1個ずつ順番に印刷する場合は配置を見直してください。異常があれば合成プレートを使わず、付属の単体STLを使用してください。

## 実物評価

各刻印IDで識別し、ボール径約24.26mmの自然転がり10回、停止/出口勢い、造形バリ、純正DUPLOとの嵌合、印刷品同士の嵌合を記録。特に **C02-V5** はバリ除去後に良好だった旧C02-V2と比較し、**S01-V5 / S02-V8** は実物良好だった旧S01-V4 / S02-V6と比較します。結果は [実物試験 #42](https://github.com/KKawamura1/3d-printer/issues/42) に記載。

**対象外:** すでに実物良好のC01-V5、実物不採用のC02-V4/C02R-V1、#40 SC02-V5（刻印修正版の成功Artifactを未確認）、#47（重複としてクローズ済）、通常ブロック/通常レール。#40の修正版STL確認後に別プレート追加可能です。
