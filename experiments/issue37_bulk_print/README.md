## 成果物・検証

- 180×180mmのA1 miniベッドに収め、XY外接矩形間で**4mm以上**を確保。板1には9点、板2には4点。
- 成功したGitHub Actions `cad-verified-stl`から**run ID・Artifact ID・SHA256で版を固定**して取り込み、CADレポート`passed=true/mesh.passed=true`を必ず確認。欠損・失敗はスキップしません。
- ワークフロー `Issue 37 multi-part A1 mini print plates` の `issue37-a1mini-print-plates` に**合成2枚・単体13点・manifest.json**を添付。生成物はGitにコミットしません。
- Bambu Studioでは**サポートOFF**で実スライスを確認。特に天井、内部バリ、浮動片持ち梁、初層、ブリム干渉（4mm間隔は2mmずつのブリムで接する）を確認。物理的な印刷・転がりの成功をCAD合格から推定しない。
- 刻印IDごとに球径約24.26mmの自然転がり10回、停止位置・出口勢い・バリ・嵌合を [#42](https://github.com/KKawamura1/3d-printer/issues/42) に記録。

**対象外:** 実物良好のC01-V5、実物不採用C02-V4/C02R-V1、成功Artifact未確認の#40 SC02-V5、重複クローズの#47、通常ブロックと通常レール。#40の修正版STLが入手できれば次の実験へ。

Artifactは14日間の保管期限。期限切れの元Artifactがある場合、元PRから再生成して版・ハッシュ・成果物IDを改めて更新する必要があります。
