# E29-V3：子どもの着脱を目標にしたDUPLO二重嵌合機構（試作）

追跡：[#26](https://github.com/KKawamura1/3d-printer/issues/26)（問題管理）、[PR #23](https://github.com/KKawamura1/3d-printer/pull/23)（E28外壁/チューブ接触の切り分け）。E28の実物評価がまだなので、E29も**解決済みとは扱わない**。

## 目的

純正DUPLOの凸・凹とは良好でも、印刷品同士では初動から硬く、子どもにとって着脱しにくい。既存の寸法調整とは別に、**浅いスタッド溝＋分割式中央チューブ＋丸い内部係合ビード**という「面摩擦に頼りすぎない保持」を比較する。0.20 mm積層を維持し、子どもが触れる外側に爪・突起・鋭いエッジを作らない。

**注意：このプレートは設計実験であり子ども向け完成玩具ではない。PLA Basicの分割チューブに亀裂や破片が生じる可能性があるため、強度・バリ・反復着脱を大人が確認するまでは子どもに渡さない。乳幼児の手の届かない場所で保管する。**

## 5個の比較条件

| 刻印 | 上面スタッド | 下面中央チューブ | 切り分け |
| --- | --- | --- | --- |
| E29-01 | 従来 | 従来 OD13.50 | 基準 |
| E29-02 | 浅い環状溝 | 従来 OD13.50 | スタッド側だけ |
| E29-03 | 従来 | OD13.30、4分割スリット | 弾性保持だけ |
| E29-04 | 従来 | OD13.20、4分割＋丸いビード（最大OD13.52） | 弾性＋係合部 |
| E29-05 | 浅い環状溝 | E29-04と同じ | **印刷凸×印刷凹の専用係合** |

全て本体31.8角、通常高さ19.2、スタッド高4.5、中心ピッチ16、下面内法25.40、スタッド基本外径9.40／穴径6.40、チューブ内径9.40mm。Grooveは深さ0.19 mm、スタッド基部から1.05〜3.20 mm、中央はR4.51 mm（最小スタッド壁厚1.31 mm）。内部ビードはR0.16の円弧、受け側底面からZ2.25mm（着座時はスタッド基部から約Z2.25mm）。4本のスリットは幅1.10 mm、先端をR0.65で丸くし、底の入口を少し広げている。チューブの最小名目肉厚は1.90mm。

※ ビードの最大OD13.52は公称CAD輪郭であり、**印刷後の保持力・干渉・滑らかさは未検証**。E29-05が本当にスナップ保持するかも実物で確かめる仮説である。細い単独爪や取り付け式小部品は設けない。

## 生成

- `experiments/dual_fit_e29/cad-build.json` を `E29-V3` として登録。バージョン追加・更新時のみGitHub ActionsでE29だけ自動生成（テスト・説明だけの編集は再生成しない）。
- 生成物は `cad-verified-stl` Artifact内の `E29-V3/E29-plate.stl` と `E29-V3/E29-0X/brick.stl`。リポジトリに大量のSTLをpushしない。
- 5個セットのベッド配置は(45,68), (90,68), (135,68), (45,112), (90,112) mm。A1 miniの180×180に収まる。
- A1 mini / PLA Basic / 0.4mmノズル / **0.20mm積層**。スタッドを上に、サポートなしを初期条件とするが、Bambu Studioで各スリット終端・ビード・溝の実際のツールパス/ブリッジを確認する。特に0.20 mm凹凸がスライスで消えないかを確認し、警告が出たら印刷前に修正する。
- CADのwatertight・STEP再読込・幾何チェックに成功しても、スライス、造形強度、子どもへの安全性は別評価。

## 比較手順（大人のみ）

まず爪や小片の亀裂、バリ、細い糸、尖った感触がないか確認。無理な嵌合はしない。

1. **純正凸→各印刷凹**：滑らかさ、開始時の硬さ、保持、曲げを比較。E29-03/04/05で純正が硬くなる／緩くなるなら採用不可。
2. **各印刷凸→純正凹**：E29-01と02/05を比較。溝で純正との嵌合が緩くならないか。
3. **印刷凸→印刷凹**：01→01（別の既存基準でも可）、01→03、01→04、02→01、02→04、**05→04/05**。04と05の凹は同じ、02と05の凸は同じ溝なので、効果を分けて観察。
4. 各ペアで差込み初動／最後まで／抜くとき／保持／摩擦のガタガタ／必要な力を記録。純正×純正の滑らかさと比較。必要なら90度回して再試験。
5. **耐久**：大人が10回→30回の反復着脱（初期案）。1回ごとに過大な力や白化・亀裂・欠け・脱落・バリを確認し、異常時は直ちに中止。異常のない候補のみ、追加の耐久と安全評価を検討する。

### 判定の優先順

1. **安全・強度**：指に痛い角がない、印刷バリがない、亀裂・白化・小片脱落がない。危険な形状・破片化の恐れがあれば不採用。
2. **純正互換**：純正との上下両方向で従来の良好な嵌合を維持する。
3. **印刷同士の快適さ**：最後まで無理なく入り、子どもでも抜き差しできる程度を目標とする（成人が安全を確認した後にのみ子どもに触れてもらう）。
4. **再現性**：同じCADでも印刷配置や表面で差が生じ得る。結果の良い候補は再印刷して確認する。

## 未解決

- PLAの積層方向に沿ったチューブの疲労破断・長期耐久性は不明。割れや白化が出るならPETG等の材料切替、スリットを廃止した大きな弾性構造も候補。
- E28で外壁が支配的と判明すれば、E29も下面外壁の接触帯を見直す。**全寸法を一括で緩くすることはしない**。
- 3Dプリント品は安全認証済みの玩具ではない。乳幼児のいる環境では印刷物を遊び道具にする前に適切なリスク評価が必要。
