# Issue #89 — E01 × SC02 の外形共通化・初回PoC

- 親Issue: https://github.com/KKawamura1/3d-printer/issues/89
- **このモデルは比較用 E01-V11 で、印刷承認版ではありません。**
- このPRは `main` のE01 / SC02 / PR #75 #85 #87 には一切変更を加えません。

## 試作の範囲

E01-V3 (水平・R48・4×4トンネル) と同じ `course_r48_tunnel.channel()` を使用し、**外装だけ** SC02 の `course_r48_sloped_tunnel.curved_footprint()` で扇状に切り詰めます。箱の広い無関係な四隅を除去する設計比較です。

- 経路 R48・真円口 `BALL_TRACK.opening=25.74mm`・床 `BALL_TRACK.floor=6.35mm`・直径24.26mmの球・入口出口の位置と方位は旧E01に合わせる。**既製レールとの接続口は拡径しない**。
- 上面スタッドは同じスタッド列を生成後、SC02と同じ輪郭で切る。
- E31-05は**完全に残る下面3チューブだけ**に追加。元の9チューブの一部が輪郭で切断されても、部分支持材として残す（E31スリットは追加しない）。
- 箱形E01で使っていた南外壁の刻印場所は消えるため、SC02同様に西端の可視面に新型番を刻む。
- 本段階は**窓なし**（PR #75/#87のファサード窓移植は次段）。坂あり側の走路・形状変更もしない。
- 現行形状の外形差を知ることが目的。E01とSC02を共通の単一ロフト生成器へ統合するのは、この比較試験の後。

## 再現

軽量な輪郭・接続・下面チューブ位置テスト:

```sh
python -m unittest experiments.r48_compact_e01.test_layout -v
```

対象1形状のCAD / STL / report生成（他の19モデルは生成しない）:

```sh
python -m experiments.r48_compact_e01.design --out build/issue89-e01
```

4方向画像（**必要な場合のみ**）:

```sh
python scripts/stl_snapshot.py --stl build/issue89-e01/brick.stl --out build/issue89-e01/preview.png
```
