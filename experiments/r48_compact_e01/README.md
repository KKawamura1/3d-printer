# Issue #89 — E01 × SC02 の外形共通化・初回PoC

- 親Issue: https://github.com/KKawamura1/3d-printer/issues/89
- **このモデルは比較用 E01-V11 で、印刷承認版ではありません。**
- このPRは `main` のE01 / SC02 / PR #75 #85 #87 には一切変更を加えません。

## 試作の範囲

E01-V3 (水平・R48・4×4トンネル) と同じ `course_r48_tunnel.channel()` を使用し、**外装だけ** SC02 の `course_r48_sloped_tunnel.curved_footprint()` で扇状に切り詰めます。箱の広い無関係な四隅を除去する設計比較です。

- 経路 R48・真円口 `BALL_TRACK.opening=25.74mm`・床 `BALL_TRACK.floor=6.35mm`・直径24.26mmの球・入口出口の位置と方位は旧E01に合わせる。**既製レールとの接続口は拡径しない**。
- 上面スタッドは同じスタッド列を生成後、SC02と同じ輪郭で切る。
- E31-05は**完全に残る下面3チューブだけ**に追加。元の9チューブの一部が輪郭で切断されても、部分支持材として残す（E31スリットは追加しない）。
- 箱形E01で使っていた南外壁の刻印場所は消えるため、SC02同様に西端の可視面に新型番を刻む。
- 本段階は**窓なし**（PR #75/#87のファサード窓移植は次段）。坂あり側の走路・形状変更もしない。
- 現行形状の外形差を知ることが目的。E01とSC02を共通の単一ロフト生成器へ統合するのは、この比較試験の後。

## 2026-11-22 実STLの目視レビューと比較版E01-V12

**レビュー済み画像の対象**: [PR #75のE01-V8およびSC02-V17 Artifact](https://github.com/KKawamura1/3d-printer/actions/runs/42239204814/artifacts/13515171245) と [PR #90のE01-V11](https://github.com/KKawamura1/3d-printer/actions/runs/44975721481/artifacts/14736130110) の**実際のSTLを取得し、同じ縮尺・視点でレンダリング**。また、E01-V12の実STLも後続Actionで確認。

### 目視所見（CAD成功とは別の判定）
1. **外形の統一：達成**。E01-V11 はSC02と同じ扇形フットプリント。旧E01の不要な四角い面が大幅に除去された。
2. **E01-V11の外壁：不採用**。窓が全くなく、カーブ外周に下方へ伸びる細い縦溝・細長い残留壁が顕著。既存SC02にも似た縦スリットがあるため、E01だけの問題ではない。切断エッジが尖る疑いがある。
3. **スタッド：要改善**。扇形外輪に沿って部分的なスタッドが残る。根元・部分環の耐久性と子どもの手触り未検証。完成版では「機能しない細片」を残さないこと。
4. **下面：要改善**。元の4×4下面チューブが輪郭で途中切断され、内側支持や露出細片として残る。完全チューブは3本のE31-05。CAD上で一体でも、切断端の強度・引っ掛かりは不明。
5. **窓付き比較版E01-V12**を追加。D01/PR75系の五角形窓をR48の**凸曲面に幅10mm×5つ**切り、凹面は無窓。旧レール端面と元のR48走路は変更しない。
6. **V12も現段階では未採用**。窓の開口自体は成立するが、切り残った縦リブと窓が重なり、外壁の統一感が乏しい。窓周囲の角丸、部分支持、強度、スライス品質の実測と補正が必要。
