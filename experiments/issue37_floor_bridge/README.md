# PR55下面床ブリッジのA/Bテスト（印刷未検証）

2026-11-03。PR #55 のプレート1（9点）、ユーザー提供Bambu Studio G-code/3MFと実物写真で床面が糸状に崩れる問題を確認。**既存PR/メイン設計は書き換えず、短い2×2試験片を作り、原因を分けて検証する。**

## 確認できたG-code事実

0.20mm・PLA Basic・サポートOFFで、Z=5.0mmのBridgeは216経路、総延長11,160.8mm、最長単一路65.2mm、中央値50mm/s。Z=5.2/5.4mmのInternal solid infillは中央値250mm/s。長い移動経路が全区間無支持という意味ではない。

## 試作条件

| 条件 | E31スリット終端中心 | 床支持リブ |
| --- | ---: | --- |
| A_original | 4.40mm | なし |
| B_short_slots | 3.50mm | なし |
| C_ribs_only | 4.40mm | あり |
| D_both | 3.50mm | あり |

元の4.40mm終端＋R0.65mmは最大Z5.05mmとなり、空洞天井Z4.75mmを0.30mm突き抜ける。短縮条件は最大Z4.15mmに抑える。

補強リブは幅1.2mm、4.85mm高（床に0.10mm食い込ませて一体化）、X/Y中央線上。中心チューブに直接つながらないよう半径7.5mm以内を切除し、各位置(+/-8,+/-8)のR4.7mm相手スタッドに干渉しない設計。

## 現時点の解析（本番STLではなく簡略試験片）

`python experiments/issue37_floor_bridge/experiment.py`

依存: cadquery, trimesh, numpy。閉鎖STL・CAD単一ソリッド・相手スタッドとの交差体積ゼロは検証済み。Z4.6mmの簡易断面モデル（水平方向49走査線、チューブスリット欠損を無視）では平均最大空間距離16.57→11.12mm、20mm超の線22→2。一方、最悪25.45mmは残る。**スライス後の改善・嵌合維持・実印刷の成功は未確認**。

## 実機確認と判定

1. `build/issue37-floor-bridge/four_up.stl`をBambu Studioで読み、元と同じPLA Basic/0.20mm/サポートOFFでスライス。Z4.8〜5.4mmのBridge/solid infillと浮いた部分を確認。
2. A/B/C/Dを印刷して床面の垂れ・糸状崩れ・抜去力と耐久（純正凸/純正凹/印刷同士）を比較。子どもへの提供は破損・小片を確認したあと。
3. 別の対照としてユーザー提供の元3MFの**Bridge50→25mm/s、Internal solid infill250→80mm/s**だけ変更した複製で再スライスする。これは幾何形状を変更しない速度の効果を切り分けるためで、こちらの3MFはこのPRには含めない。
4. 成果が確認できれば実パーツの複雑な外形へ必要な場所のみリブを適用し、E31スリット深さも再検証する。4×4へ一律展開しない。

一括STLを再印刷する前にBambu Studio経路・試験片の実物結果を確認する。CAD合格=印刷成功ではない。
