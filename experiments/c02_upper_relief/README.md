# C02R-V1 内側球面逃げ型 急カーブトンネル（比較用実験）

**C02-V4は削除・置換しません。** 2026-11-01に印刷済みC01-V5（開放R16急カーブ）が「問題なく良好」、C02-V2（トンネル）は内側で球が停止、と報告されました。開放版の走路を極力温存した対照候補を作ります。通過改善は**仮説**で、実物未検証です。

## V4との違い

| | C02-V4（既存） | C02R-V1（この実験） |
|---|---|---|
| 転回室 | 円筒+半球、直径26.5mm | **半径13.25mmの球体逃げ**（中心0,0,z21.75） |
| 下側 | 6.35mmの平坦な広い床 | **C01-V5のR16案内溝を保存**（少なくともz<8.5mmで同一） |
| 上側 | 広い室で方向転換 | 丸い内壁を局所的に後退させる。滑らかな曲面 |
| 共通 | 31.8mm角・高さ2・上面4スタッド・E31-05受け・西→南・円形出入口 |

C02R-V1の球面逃げは z=8.50〜35.0mm。外側側壁厚さ公称2.65mm以上、屋根最薄公称3.4mm。元からある中央天井ドームも保持。球がぶつかる位置や実際の流れを確認するまでは、この寸法が最適とは判断しません。

## 比較印刷

1. 既存の **C02-V4** と、新規 **C02R-V1** を同じ設定（0.20mm積層、材料・入口傾斜・球・組み合わせ）で印刷する。
2. スライサーで内部曲面・天井オーバーハング・下側の溝が意図通り造形可能か確認する。
3. それぞれ10回通して、成功数、どこで止まるか、出口の勢い、意図しない跳ね／逆走を記録する。
