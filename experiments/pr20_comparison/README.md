# PR20 比較候補

継続パーツの現行形とは別に、一度の印刷で比較する候補。刻印・STL名・下記IDを一致させる。

| 刻印 | 形状 | 比較の狙い |
|---|---|---|
| T02-V1 | 直線トンネル、全長真円 | 垂れが実用上問題になるか確認 |
| T03-V1 | 両端1mmが真円、各2mmで現行涙滴へ遷移 | #19の短い遷移案 |
| T04-V1 | 両端1mmが真円、各4mmで現行涙滴へ遷移 | 遷移長による差 |
| S02-V2 | 坂カーブ、完全な円筒3本＋閉じたD形4本＋小さい中実支柱1本 | S01-V2の完全な円筒3本・開放下面との保持比較 |

S02-V2は切れた円筒の切断面に約2.05mm厚の壁を加え、上から見て閉じたD形にする。小さすぎる1か所は中実。縦角・下端はR0.5。走路・落差・接続口と隅の床を省いた外形を維持し、下面天井の支えを増やす。3本構成のS01-V2と比較する。旧ローカル案S02-V1（四角い床）は採用しない。実スライス・保持力は未確認。

```sh
python -m experiments.pr20_comparison.design
python -m parts.play_set.design
```

各`<ID>.stl`が個別の印刷用。8個のまとめ配置は `parts/play_set/play-set-8.stl`。STLはmm・100%。サポートOFFでスライスし、天井・遷移部・浮き・下面ブリッジを確認する。新形状の実スライスと印刷は未確認。

比較時は最初に大人が縁と天井のバリを触って確認する。トンネルは同じ球を両方向へ通し、引っかかり・天井の垂れ・見た目をID別に記録する。坂カーブは同じ下ブロックに順に取り付け、外れやすさ・傾き・触感を比べる。無理な計測は不要。
