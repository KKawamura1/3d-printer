# E27：下面チューブ径4条件の同時比較

[4個まとめた印刷用STL](E27-plate.stl) をmm・100%で読み込み、スタッド上向きで同一ジョブ・レイヤーごとに印刷する。STL内は独立した4ソリッド。個別STLは specimens/ にある。モデルの刻印とファイル名は E27-01〜04、前面（−Y）に刻印。

| 条件 | 刻印 | チューブCAD外径 mm | ベッド中心座標 X,Y mm |
|---|---|---:|---|
| A | E27-01 | 13.35 | 69,69 |
| B（本命仮説） | E27-02 | 13.40 | 111,69 |
| C | E27-03 | 13.45 | 69,111 |
| D（対照） | E27-04 | 13.50 | 111,111 |

ベッド180×180mm中央に配置した場合の座標。全体73.8×73.8×23.7mm、各個体の隙間10.2mm。自動整列・回転をした場合は実際の座標をsetup.jsonへ記録する。

固定条件：2×2、本体31.8×31.8×19.2mm、ピッチ16mm、スタッド外径9.40／穴径6.40／高さ4.50mm、下面内法X/Yとも25.40mm、チューブ内径9.40mm、天井厚1.60mm。外角0.8／スタッド上端0.5／下面入口面取り0.3mmも固定。刻印を除く変更はチューブ外径のみ。共通規格 duplo-xy-trial-v1 を明示し、実験内で外径をoverrideする。共有規格・現行パーツは更新しない。

## 根拠と不確実性

2026-10-27の現物比較では、成功した上面（右）を左の下面へ入れると緩すぎ、中央の下面へ入れるとややきついが許容範囲。右の上面は純正の下面にぴったり。左＝16片実験の13.10mm、中央＝下面3片実験の13.50mmという対応は現物の特徴による推定で、IDの重複により確定していない。中央の下面は以前、純正の上面とぴったりだった。

印刷ジョブが異なるため、保持力差を外径だけに帰属しない。13.40mmは探索の中心であり、最適値の確定ではない。同一ジョブで外径差を比較するが各条件1個なのでベッド位置・個体差は分離できない。観察原文と推定の区別は records/prior-observations.json に保存。

## スライス時の確認

過去の成功条件を参照した予定設定を [setup.json](records/setup.json) に用意した。実際の設定は未取得。A1 mini／0.4mm／Bambu PLA Basic、0.20mm層、壁2周、Classic、Grid15%、流量比0.98、XY補正0を参照し、実際に使った値と配置を記録する。

**4条件×4スタッドすべてでInner wallが生成されることを、スライサーの線種表示で確認する。** 外径・穴径が同じでも線種の一致はCADから保証できない。Gap infillが混じったらそのまま比較せず、設定・スクリーンショットを記録する。3MFを保存し、必要ならG-codeとともにSHA-256も記録する。スライス・実印刷・実物嵌合は未検証。

## 評価

[measurements.csv](records/measurements.csv) へ各試料の内法X/Y・チューブ外径・スタッド外径X/Y・4スタッドの線種を記録する。相手の純正ブロックは同じ個体を使い、印刷品の凸はまず同じ1個（E27-02等）を共通の相手として各下面と比較する。過去の「右」を使うなら個体名と写真を残す。

1. 純正品の凸 → 各印刷品の凹：挿入力・抜去感・保持・曲げX/Y。
2. 各印刷品の凸 → 純正品の凹：上面の成功条件が再現するか確認。
3. 印刷品の凸 → 各印刷品の凹：共通の凸で比較し、候補決定後は各個体間でも確認。

判定は「入らない／きつい／適度／ゆるい／保持しない」と自由記述。各方向の挿入・抜去を10回繰り返した後も記録する。1と3の両立を採用条件とし、純正互換を犠牲にして選ばない。保持力をCADの干渉体積から予測しない。新規条件のphysical_fit_validatedはfalseのまま。
