# E28：外壁・中央チューブの接触位置切り分け

目的：純正凸×印刷凹、印刷凸×純正凹は良好なのに、印刷凸×印刷凹だけ硬い現象を、**0.20 mm積層のまま**調べる。形状を変えた比較から接触機構を推定する実験であり、CADだけで実物の接触位置や保持力を断定しない。

## 1ジョブ・4個の比較片

| 刻印 | 条件 | 下面内法 X/Y | 中央チューブ外径 | ベッド中心 X,Y |
| --- | --- | --- | --- | --- |
| E28-01 | 基準A（共通凸候補） | 25.40 / 25.40 mm | 13.50 mm | 69, 69 |
| E28-02 | 基準B（再現性確認） | 25.40 / 25.40 mm | 13.50 mm | 111, 69 |
| E28-03 | **外壁緩和** | **25.60 / 25.60 mm** | 13.50 mm | 69, 111 |
| E28-04 | **チューブ緩和** | 25.40 / 25.40 mm | **13.30 mm** | 111, 111 |

4個とも2×2デュプロ互換、本体31.8×31.8×19.2、スタッドを含めた高さ23.7 mm。上面スタッド外径9.40、穴径6.40、ピッチ16、中央チューブ内径9.40、外角R0.8、スタッド上端R0.5、下面入口面取り0.3 mmを共通とする。E27後の基準 duplo-e27-play-v1 から**下面の1パラメータだけ**を個別に変更し、共有profileと既存のpartsは触らない。

内法＋0.20 mmとはX/Y各軸の総幅＋0.20 mm（片側＋0.10 mm）。チューブ外径−0.20 mmも半径方向−0.10 mm。チューブ自体をなくす試験ではない。刻印は -Y外壁の嵌合帯より上、4個すべて固有ID。プレートは約73.8×73.8×23.7 mmに収まり、4つのソリッドは互いに接していない。

## まだ印刷せずに試せること

既存の印刷品同士で、片側を90°回して嵌合感が変化するか比較する。変化があればXYの造形方向差や寸法差の可能性がある（変化しない場合も否定はできない）。

必要であれば印刷品の凸外周に落とせる水性マーカーを薄く塗り、乾燥させてから純正凹・印刷凹に1度ずつ入れて擦れた箇所を観察する。マーカー膜と摩擦が結果を変え得るので定量的な証明とは扱わない。溶剤や強い押し込みは避ける。

## STL生成（手動・対象実験だけ）

リポジトリの [CAD preview and print artifacts](https://github.com/KKawamura1/3d-printer/actions/workflows/cad-preview.yml) で Run workflow を使う。

- branch: このPRの experiments/e28-receiver-contact
- targets: experiments/receiver_contact_e28
- previews: false（必要になったときだけtrue）

pushで実験生成を自動実行することはない。成果物は14日間保持の cad-verified-stl Artifact 内に配置する。

- 一括印刷：experiments/receiver_contact_e28/E28-V1/E28-plate.stl
- 個別印刷：同ディレクトリ以下の E28-01/brick.stl 〜 E28-04/brick.stl
- report.json に各個体の寸法、STL検査と物理未検証の状態を記録

A1 mini／Bambu PLA Basic／0.4mmノズル／**積層0.20mm**で、実物で使った条件に合わせる（過去の参考値：壁2、流量比0.98、XY補正0）。スタッド上向き、mm・100%。自動整列・回転・スケーリングはせず、配置と条件を記録する。スライサーの線種プレビューで各スタッドが Inner wall になっているか確認し、Gap infill混入やサポート警告があるときは比較前に記録する。STL生成成功はスライス成功や物理的な嵌合成功ではない。

## 印刷後の評価（共通の上側凸で比較）

基準A/B同士が著しく違うなら、同一ジョブ内でも印刷ばらつきが大きい可能性があり、緩和差の判定を保留する。

1. 同じ純正凸 → E28-01/02/03/04の各凹を比べる（純正互換）。
2. **E28-01の凸** → E28-02/03/04の各凹を比べる。E28-01の凹はE28-02の凸で確認する。
3. E28-01/02/03/04の各凸 → 同じ純正凹を比べる（上面が本当に同じ品質か）。
4. 差がある場合、共通凸をE28-02に交代したり、嵌合相手を90°回して再試験する。

入り始め、奥まで入るか、抜きやすさ、保持・グラつきを「入らない／きつい／適度／ゆるい／保持しない」と自由記述で記録する。無理に押し込まず、引っ掛かる箇所・音・表面剥離も観察する。必要なら各片の内法X/Y、チューブ外径X/Y、スタッド径X/Yをノギスで測定する。
