# SD04-V17 — D01のリズムを持つ一面3窓（試作）

PR #73への追加提案。**まだ採用しない**。ここでは一形状を完成させて、実STLの正面・斜め・上面・下面を比較してから残りへ展開する。

## ねらい

「球が見えるように穴を増やす」より先に、「同じ外壁に整然と並ぶ、同じ形の窓列」を設計する。以前印刷に成功したD01-V3の縦長の5角形を用いる。

## 見た目の規約

- 対象：**SD04-V10（2×4×高さ3の緩坂・急左カーブ・トンネル）**から生成する新ID `SD04-V17`。
- **窓は+Y側面の直線32mm区間だけ**。曲面の出口、他の面には開けない。以前のV15で起きた「2窓が正面・1窓だけ曲面の角」という破綻を作らない。
- **幅5.5mmの縦長・山形の5角形を3窓**。中心位置は進行方向に沿ってX = `[-24, -16, -8]mm`。
- **ピッチ8mm**、窓と窓を隔てる**2.5mmの柱**、左右端の余白**5.25mm**で対称。片側だけ不自然に短い柱を作らない。
- 窓の下辺・両肩・山形頂点は、D01と同様に**レールの高さに沿う**。床からの相対高さは7/18/22mm。窓の形状そのものは全て同じ。
- 窓から球の中心へ視線が通ること・実際の外壁を貫通していること・窓の下側に球のためのガード壁が残ること・屋根の外形が変わらないことを幾何学的に検証。
- 反対側の壁にはあえて窓を設けない。まず**正面の窓列が美しく見えるか**を基準に採否を決める。

## 安全性と差分

PR56の`brickcad.course_loft_family.build_course()`をそのまま使い、標準E31-05・スタッド・接続面を保つ。既存`SD04-V10`およびPR73 `SD04-V15`には変更を加えない。刻印のみ新ID `SD04-V17`。

## 実機検証

CadQuery/BRep・STL検証の合格と、Bambu Studioの印刷プレビュー・実機の結果は区別する。**実機印刷・球の転がり・窓柱の強度・嵌合はいずれも未検証**。

試作が美しいと判断できた場合だけ、他の2×4/4×4パーツに一般化する。その際も4×4カーブの壁面や走路を考慮して個別に配置を検討し、機械的に3窓をコピーしない。
