## 目的と今回の絞り込み

**最優先は印刷品同士を子どもの力でも着脱できること。**
次に純正品との双方向互換、通常の持ち上げ・軽い揺れに耐えること。
純正を超える保持力は不要。大人が試験する段階のパーツであり、子どもには渡さない。

E30-07（OD13.20＋4分割＋R0.16ビード）は挿抜感が良い一方、
上側接合部にE30-07を用いた積み上げでは、軽い揺れで下2個まで保持・3個で脱落。
純正同士は下6個まで保持・7個で脱落した（揺れ強度等は未計測）。

追加実験では以下を確認した（矢印は凸→凹）。
- 08→09：抜去適度／曲げしっかり保持
- 09→08：抜去やや緩い／曲げ多少弱いが実用的
- 07→09：抜去適度／曲げしっかり保持
- 純正→08：抜去やや緩い／曲げ多少弱いが実用的
- 純正→09：抜去やや緩い／曲げしっかり保持

**E30-07、08、09の凹面はCAD上同形状**で、08/09は上面に浅い溝を持つだけ。
よって、09凹で良い保持が得られたことは凹面設計差の証拠ではない。
印刷位置、個体差、回転向き、使用回数などの影響も考える。
07凸→09凹が良好だったことから、上面の溝追加は必須とせず、
本実験は下面受けの保持機構のみを変更する。

ユーザーの印刷時間削減要望に合わせて、E31-V1の9個を**5個に削減**。
同形状の対照は1個のみとし、寸法の細かい刻みをやめ、
比較価値の高い4機構を残す。IDはV1案から維持する（欠番は意図的）。

## E31-V2の5条件

共通：2×2、31.8×31.8×23.7mm、上面スタッドOD9.40/穴ID6.40、
下面内法25.40、上面溝なし、4分割スリット幅1.10・終端R0.65、
中央チューブOD13.20、下側ビードZ2.25・断面R0.16（特記条件以外）。
角R0.8、スタッド端R0.5、下面入口面取り0.3。

| ID | 変更点 | 最大ビードOD | 狙い |
| --- | --- | ---: | --- |
| **E31-01** | E30-07と同じ嵌合形状 | 13.52mm | 基準（1個のみ） |
| **E31-05** | 下側ビード断面R0.20mm | 13.60mm | 係合ビード側で保持を増やす |
| **E31-07** | 中央チューブ本体OD13.28mm | 13.60mm | 円筒径側で保持を増やす |
| **E31-08** | スリット終端Z4.40→3.60mm | 13.52mm | 分割チューブの剛性を上げる |
| **E31-09** | Z3.55mmに上側接触帯を追加 | 下側13.52mm／上側13.46mm | 2段接触で曲げ・揺れ耐性を探る |

E31-05とE31-07は最大ビード外径が**ともに13.60mm**。
接触部を局所的に太くする方法と、円筒全体を太くする方法の違いを比較できる
（スリットの弾性などは独立ではない）。E31-09の上側ビードは
スライスで消える可能性がある。細かい変更は0.20mm積層・ノズル経路の
影響を受けるため、CAD寸法差が実造形に反映されるか必ず確認する。
この実験で採用プロファイルや量産パーツは変更しない。

## 1回の印刷

A1 mini / PLA Basic / 0.4mmノズル / 0.20mm積層を初期条件とする。
スタッド上向き、100%スケール、サポートOFF。
配置は**2行×3列、5個**、中心ピッチ45mm、外形121.8×75.8×23.7mm。

```text
前列  E31-01  E31-05  E31-07
後列  E31-08  E31-09  （空）
```

Bambu StudioでInner wall/Gap infill、ビード、スリット終端、ブリム、
サポート・ブリッジ警告、特にE31-09の上側接触帯が実際に生成されるか確認。

## 評価（大人のみ）

1. **まず追加印刷なしの確認**：E30-09凹の上側接合部で
   E30-07と同条件の積み上げ・軽い揺れ（下3個→5〜6個）を試す。
   E30-07/08/09の各凹を同じ純正凸・同じ回転向き／90度回転で比較。
   E30-09凸→純正凹も確かめる。全結果で相手・向き・回数を記録。
2. **試験片の安全点検**：バリ、白化、ひび、スリット・チューブの損傷、
   破片の有無。異常があれば直ちに中止。乳幼児から隔離する。
3. **印刷同士**：基準01凸→各候補凹（01は既存E30-07凸を使用可）。
   初動、着座、抜去、曲げを評価。逆方向の各候補凸→01凹も評価。
   抜去が硬い候補は、保持が強くても不採用とする。
4. **純正との双方向**：同じ純正凸→各候補凹、各候補凸→同じ純正凹。
   抜去、曲げ、ガタつき。印刷位置や個体差を過剰に設計効果とみなさない。
5. **保持余裕**：着脱が適度な候補のみ、同条件の積み上げ・軽い揺れを比較。
   上側のどの接合部が外れたかを記録。E30-07の下2個は参考値であり
   力比を意味しない。
6. **耐久**：有望品のみ大人が10→30回の挿抜を試し、
   白化、亀裂、摩耗、脱落物、緩みを確認。異常なら中止・廃棄。

試験はID・版・印刷設定・組合せ・回転向き・着脱・曲げ・揺れ・摩耗を記録。
CAD/メッシュ/STEP成功はスライス適合、実物嵌合、長期耐久性、
子ども用玩具としての安全性を証明しない。
