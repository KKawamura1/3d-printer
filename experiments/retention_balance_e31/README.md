## 判断基準（2026-10-31の実物結果）

**優先1：印刷品同士を子どもの力でも組み外せること。** ただし試験片そのものを子どもに渡してはいけない。
次に純正DUPLOとの双方向互換、普通に持ち上げ・軽く揺らしたときの保持余裕を確かめる。
純正より強い保持力は目指さず、揺れ耐性のために印刷品同士が硬くなれば不採用とする。

E30-01→02は入り口から硬い。01→03の外壁緩和では改善せず、
01→04のチューブOD13.50→13.30緩和で抜き差しは適度になるが純正凸→04凹は緩い。
E30-06（OD13.30、4分割）は純正凸との曲げ保持がかなり弱い。
E30-07（OD13.20＋4分割＋R0.16ビード）は印刷同士の挿抜感はよいが
純正凸との保持は緩め。手で静かに上げると12個ぶら下がる一方、
軽く揺すると下2個までは保持、3個でトップ接合部が外れる。
純正品同士は同条件の手振りで下6個までは保持、7個で外れた
（実測荷重や振幅は記録しておらず、この数は力の比を示さない）。

**目的は07の着脱の容易さを失わずに保持余裕を少し増やせるかの探索。**
曲げ耐性は参考値であり、今回の形状選定の最優先項目ではない。

## E31-V1 の9条件

全個体とも2×2、外形31.8×31.8×23.7mm、上面スタッドOD9.40mm、
下面内法25.40mm、スタッド／角の丸みはE30-07を維持。
**上面には溝を設けない。** スタッドを固定し、下面受けだけを変える。
ベースの分割は4本、スリット幅1.10mm、終端R0.65、
チューブOD13.20、ビード中心Z2.25mm／断面R0.16。

| E31-01 | E30-07と同形状、基準A | 比較基準 |
| E31-02 | 同形状、基準B | 印刷ばらつき |
| E31-03 | 下側ビード断面R0.14mm | より軽い着脱 |

## 印刷

A1 mini / PLA Basic / 0.4mmノズル / 0.20mm積層を初期条件。
100%スケール、スタッド上向き、サポートOFF。実際のプリンター設定は記録する。
プレートは3×3・45mm中心ピッチ、全9個・1回で印刷できる想定。
**Bambu Studioで各接触ビード、スリット終端、Inner wall、Gap infill、
ブリム、サポート警告をレイヤー表示で確認してから印刷。**
ビード半径の差や上側接触帯が消える場合は、印刷せず設計変更する。

STLはGitHub Actions `cad-verified-stl` の
`experiments/retention_balance_e31/E31-V1/E31-plate.stl`。
個別 `E31-01/brick.stl` ～ `E31-09/brick.stl` も生成する。
`cad-build.json` の版更新時のみ自動生成。巨大STLはGit管理しない。

## 評価手順（大人のみ）

1. 角、バリ、白化、ひび、分割チューブの裂け、欠け、脱落物を確認。
   異常があれば力を加えず試験中止。乳幼児の手の届かない場所に保管。
2. **印刷同士**：基準01凸を各候補の凹に入れる。入り口・着座・抜去を
   `入らない/硬い/適度/緩い/保持しない`で記録。逆向きも試せる範囲で。
   01凹と02凸の比較で個体差を確認。
3. **純正互換**：同じ純正凸→各候補凹、各候補凸→同じ純正凹。
   緩さが悪化する試料は除外。上面は全条件同一設計でも実造形差は記録する。
4. **保持余裕**：有望候補のみ同じ純正品を下に数個つなぎ、静かに持ち上げ、
   軽く揺らす。振り方を可能な限り統一し、外れた接合箇所を記録。
   E30-07の下2個保持／3個脱落を当面の参考値とし、純正の6個は上限目標ではない。
5. **耐久**：有望候補に限り、大人が10回→30回着脱して白化・亀裂・
   ビード摩耗・スリット破損・破片・保持力低下を確認。異常なら中止・廃棄。
   10/30回の異常なしも長期安全性の証明ではない。

試験項目はID・版・印刷設定・相手・向き・評価・メモを保存する。
CAD形状、STEP/STL整合性、Bambu Studioスライス、実物挿抜、子どもの安全性は別々の検証。
本プレートは**大人の試験専用であり、子ども用玩具として未認証**。
