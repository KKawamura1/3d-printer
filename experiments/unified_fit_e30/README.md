# E30-V1：E28＋E29 嵌合比較を1回の印刷に統合

[Issue #26](https://github.com/KKawamura1/3d-printer/issues/26)／[E28 PR #23](https://github.com/KKawamura1/3d-printer/pull/23)／[E29 PR #27](https://github.com/KKawamura1/3d-printer/pull/27)

**制約：印刷ジョブ回数を最小化する。** E28（外壁／チューブ干渉）とE29（スタッド溝／分割チューブ／丸い係合ビード）の全主要条件を、A1 miniの180×180mmに入る**3×3、9個、1枚のSTL、1印刷ジョブ**に統合する。基準2個と複合機構2個を入れ、同じ印刷品同士を直接比較できる。E28とE29の個別プレートを追加印刷する必要はない。

## 形状、ID、配置

すべて2×2、31.8×31.8×19.2mm（スタッド含む高さ23.7mm）、ピッチ16mm、上面OD9.40/穴ID6.40mm、基本下面内法25.40×25.40mm、入口面取り0.3mm、上面端R0.5、外角R0.8、0.20mm積層想定。元のE28-V1／E29-V3の**嵌合ジオメトリを再利用**し、刻印だけE30固有IDに変更。共有プロファイルや成果パーツは変更しない。

| ID | 元の条件 | 下面内法 | 中央チューブOD | スタッド |
| --- | --- | --- | --- | --- |
| **01** | E28-01基準A / E29-01基準 | 25.40 | 13.50 | 従来 |
| **02** | E28-02基準B / E29-01基準の再現 | 25.40 | 13.50 | 従来 |
| **03** | E28-03 外壁緩和 | **25.60** | 13.50 | 従来 |
| **04** | E28-04 チューブ緩和 | 25.40 | **13.30** | 従来 |
| **05** | E29-02 スタッド溝 | 25.40 | 13.50 | **浅い溝** |
| **06** | E29-03 分割チューブ | 25.40 | 13.30、4分割 | 従来 |
| **07** | E29-04 分割＋ビード | 25.40 | 13.20、4分割＋内部ビード | 従来 |

- 01～09の配置は左手前から左→右、前→後の3×3。中心座標はX/Y=45,90,135mm（+Yが奥）。各ブロック間の空きは13.2mm。プレート外寸121.8×121.8×23.7mm。
- **01/02は同寸法**、**08/09は同寸法**。外側の刻印だけ異なる。
- 07の凹＝08/09の凹、05の凸＝08/09の凸、01/02の凸＝03/04/06/07の凸とCAD上は一致。ただし実際の造形ばらつきはあり得る。
- 06はチューブOD13.30と同じ条件の04から**スリットのみ追加**した比較としても利用できる。
- 画像やCADパスの成功は実物の挿抜感、疲労強度、安全性の証明にはならない。

## 印刷品同士の組合せ（矢印は「凸 → 凹」）

### 必須：印刷品同士の接触箇所・機構の比較

| 凸 → 凹 | 判定したい差 |
| --- | --- |
| **01 → 02、02 → 01** | 従来形状同士。双方向の基準（再現性・相性差） |
| **01 → 03、02 → 03** | E28 外壁緩和の効果。基準凸を切替えて再現性確認 |
| **01 → 04、02 → 04** | E28 チューブ径緩和の効果。基準凸を切替えて再現性確認 |
| **01 → 06、01 → 04** | E29 分割チューブの効果を、同ODの非分割04と比較 |
| **01 → 07、05 → 07** | E29 丸いビードを従来凸と溝付き凸に挿した差 |
| **05 → 02、01 → 02** | スタッド側の溝のみの効果 |
| **08 → 09、09 → 08** | **新しい複合機構同士を直接評価**（双方が溝と分割ビード受け） |
| **05 → 07、08 → 09** | 同じCAD上の係合機構の異なる個体組合せによる再現性の参考 |

### 純正品との両方向の互換性

- **同じ純正凸 → E30-01～09の各凹**：保持、入れ始め、着座、抜き取り、ガタつき、曲げ方向の安定性。E28-03/04、E29-06～09で緩みすぎないか。
- **E30-01～09の各凸 → 同じ純正凹**：特に溝付き05/08/09で従来品との保持が弱まらないか。
- **純正凸 → 純正凹**を基準。純正品×純正品も別途用意（本プレートには純正品は含まない）。

## 最初の最小確認（短時間・大人のみ）

1. 9個のID、角の丸さ、スリット先端、バリ、糸、欠けを確認。**白化・割れ・小片の兆候があれば中止**。
2. 01→02で印刷同士の基準、01→03と01→04でE28の仮説、01→06と01→07でE29の仮説を比較。
3. 05→07と08→09で「溝＋弾性ビード」が作用しているかを比較。
4. 同じ純正品の凸/凹と各部品を両方向に嵌め、純正互換性が失われていないか確認。
5. 有望なペアだけ大人が10→30回繰り返して、変形・白化・亀裂・破片・バリを毎回観察。異常時は直ちに廃棄。外観だけでは隠れた弱さは証明できない。

簡易評価：`入らない / きつい / 適度 / 緩い / 保持しない` ＋ `入り口 / 着座 / 抜去 / 曲げ`、異音・ひっかかり。可能なら同じ凸を90度回して再評価し、X/Y造形差も切り分ける。**保持できる＝子どもに渡せる、ではない。** 現段階では子どもへの手渡し・使用を禁止し、乳幼児の手の届かない場所で管理する。

## 生成と検証

- `experiments/unified_fit_e30/cad-build.json`に`E30-V1`を登録（`auto:true`）。新規追加・バージョン変更時だけ自動生成、README等の小変更では生成しない。
- 版の参照：E28-V1とE29-V3を明示的に検査し、ソース実装を再利用。後でE28/E29のCADが更新される場合はE30も**明示的に新バージョンを作る**。現状の形状に対する静的な参照であり、他実験のSTL全量を依存生成しない。
- [GitHub Actions](https://github.com/KKawamura1/3d-printer/actions/workflows/cad-preview.yml) 成果物 `cad-verified-stl` の `experiments/unified_fit_e30/E30-V1/E30-plate.stl` が**1回の印刷用**。個別STL `E30-01/brick.stl` ～ `E30-09/brick.stl` も含む。
- Bambu Studio: A1 mini / PLA Basic / ノズル0.4mm / 積層0.20mm / 壁2 / 流量比0.98 / XY補正0を初期条件。**スタッド上向き、サポートOFF、100%スケール、配置・回転変更なし**。各スタッドがInner wall主体か、Gap infill・スリット終端・ビードのツールパス、サポート警告、ブリムの干渉を必ずプレビューで確認。スライス結果を記録する。
- CADテスト、メッシュチェック、STEP再読込に合格しても、スライス・印刷可能性・嵌合・子どもへの安全性は未検証のまま。
