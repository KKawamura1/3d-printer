# PR56 one-plate A1 mini physical validation (Issue #37 / PR #55 comparison)

PR #56の**4軸設定から独立生成する本番CAD**をそのまま使用し、180×180 mmのBambu Lab A1 miniに**1プレートで収まるだけ**詰める試験です。原典の個別PRのexporter、旧STL、PR #55のArtifactから生成物をコピーしません。原典のSHAはPR56カタログ内の比較用出典としてmanifestへ記録するだけです。

## 印刷候補と優先順位

PR #55の最新版plate1で**良好と報告済み**の4形状 `E01-V3`、`SD04-V10`、`S02-V16`、`S01-V8`のうち、最も小型で比較に向く`S02-V16`だけを**再現比較用コントロール**として固定します。

それ以外の16形状（`SC02L-V6`、`SC02-V12`、`SD03-V11`、`E01L-V1`、`C02-V8`、`SC05-V1`、`S03-V10`、`SC03-V5`、`R01-V1`、`T01-V6`、`D02-V4`、`D01-V3`、`SD02-V4`、`SD01-V4`、`GC01-V5`、`C01-V6`）が新CADの印刷・嵌合検証候補です。特に、旧底面不良に関連するトンネル／左右反転と、R01直線開放のE31仕様を重視します。いずれも**このPR56生成経路の実物検証は未完了**であり、旧版の良好判定を引き継ぎません。

通常のPRでは高コストな20件全再生成を行いません。このプレートのワークフローは上記17件だけを生成します。各候補のSTLの**実外接矩形**を計算し、モデル個数を第一、検証リスクの優先度を第二として、配置順序・90°回転を320パターン探索します。必須のコントロール1点を含め、残りは入るだけ配置します。四隅3 mmの余白、部品外接矩形間4 mmの間隔を機械検証します。

**注意:** 自動探索で見つけた最多数であり、全組合せを網羅した数学的な最大充填証明ではありません。採用形状数は**実際のSTLを生成・計測後**に確定します。入りきらなかったものは`manifest.json.not_on_plate`で確認できます。無理に縮小・Z回転・形状変更はしません。

## GitHub Actions / 出力

`.github/workflows/course-validation-plate.yml` はPR内の本検証コードを変更したとき、または手動実行で次の処理を行います。

1. PR56のカタログ検証＋独立ユニットテスト（失敗なら生成しない）。
2. `scripts/course_catalog.py --mode build --targets <17 ID>` で、全候補をPR56共通本番エンジンから**新規生成**。E31-05の下面、浅い受け、単一最終刻印を監査した`contract_evidence`がないものは失敗。
3. 17件のSTL/報告書/ハッシュを突き合わせ、A1 miniに1プレート自動配置。サイズ・間隔・出力STLの整合を検証。
4. `pr56-a1mini-one-plate-<run ID>` Artifactに以下を収録。
   - `pr56-validation-<N>parts.stl`：配置済み1プレート
   - `individual/<ID>.stl`：プレートに載ったモデルの**無変形**の元STL
   - `layout.svg`：上から見た配置図
   - `manifest.json`：実際の採用・非採用ID、Issue37分類、4軸、出典SHA、個別STL SHA、回転角度、座標、共通契約の実行時監査
   - `pr56-source-manifest.json`：PR56から生成した17件のソースmanifest

リポジトリのmainでなく、**PR #56のブランチをベースとする依存PR**です。PR #56のコード変更に追従する際はベースを更新し、CAD生成・監査・プレート組立を改めて実行してください。原典の旧版を使って成功扱いにはしません。

## この1プレートの実物確認

サポートOFFでスライスし、底面のブリッジ・スリット終端、トンネルの円形開口、左右反転後の刻印、切断スタッド／下面支持、印刷同士・純正との保持、各モデルの球の10回連続通過を記録します。可逆候補`GC01-V5`／`C01-V6`／`C02-V8`は両方向で確認してください。

比較用`S02-V16`は**PR55版とPR56版の同名・別生成経路**の評価に使います。差があった場合は印刷条件と個別STLのSHAを分けて記録します。CAD生成とプレート配置が成功しても、実スライス・印刷・転がり・嵌合の成功を意味しません。
