## 2026-11-22 追加検査：大きな球は本当に通るか

前回の`export.py`は直径24.26mmの球を**走路床との接触高さから+0.55mm**に配置して21点の干渉を評価していた。球が自然に転がるという主張には不十分で、接触付近の干渉を見逃す。

GitHub Actions [#91の実STEP](https://github.com/KKawamura1/3d-printer/actions/runs/44979039817/artifacts/14736738216) を再読み込みし、**接触基準+0.03mm**で、走路中心線の端点を含む11地点、直径24.26・24.5・24.75・25.0・25.2・25.5・25.75・26.0・28.0mmを静的剛体球BRepで照合した。実装した再実行スクリプトは`ball_size_audit.py`（固定7径で正式レポート生成）。接触高さ0mmちょうどのOCC BRep booleanには偽の大きな交差体積が出る場合があるため、0.03mmのごく小さな浮かせを設けた。**+0.55mmの検査結果は自然通過の根拠として扱わない。**

| 直径 | 水平 E01 | 坂 SC02 | 考察 |
|---:|---|---|---|
| 24.26mm | 11地点干渉なし | `t≈0.65/0.75/0.85` で最大約0.138mm³ | 坂の一部の床付近でわずかに接触/干渉 |
| 24.5mm | 11地点干渉なし | 同部分で最大約0.158mm³ | 同上 |
| 25.0mm | 11地点干渉なし | 同部分で最大約0.214mm³ | 同上 |
| 25.2mm | 水平側干渉なし | `t=.5`で約0.080mm³（ほかの地点は未詳細走査） | 坂中央の上側にも干渉し始める |
| 25.5mm | 11地点干渉なし | `t=.5`で約4.625mm³ | 明確な中央/屋根側干渉。径の上限目安 |
| 26.0mm | 入口・出口近辺で最大約12.67mm³ | 中央や両端等で最大約38.18mm³ | 入口25.74mmより大きく既製品互換上不可 |
| 28.0mm | 全域に近い位置で大きく干渉 | 全域に近い位置で大きく干渉 | 対象外 |

数値は**特定の11地点、中心線中央、接触+0.03mm条件**における体積（mm³）であり、物理的な停止確率ではない。球の位置が左右へずれたり、床の積層不整・静止摩擦があれば悪化し得る。逆に小さな干渉は実際には球の転がり方によって解消する可能性もある。

`t=.75, d=24.26`で球を+0.1mm浮かせると干渉が消える（+0.03mmでは0.138mm³）。これは小規模だが未解消の通過リスク。`t=.5, d=25.5`では高さを上げると上側への干渉が増え、単なる浮かせでは直らない。

**判定: 坂側の「24.26mmが無干渉」および「25.5mmも通る」はどちらもまだ主張できない。** まず標準球について、床の走路曲率に沿った連続スイープを作成し、天井・外側壁と別々に必要な逃げを最適化する。**入口径25.74mmは広げず**、必要なら内部のみに逃げを追加する。同時に材厚・印刷性を再検証。

### 床曲率を考慮した候補経路の追加検査

一定勾配の床なら球中心高さは`床Z+r√(1+勾配²)`になるが、**実際のR48曲線＋smoothstep坂は床勾配が球の長さの中でも変化**し、その単純な接平面高さの近くに極小の幾何重複が出る。

実STEPで、標準24.26mm球の下り21点について、交差体積が0.01mm³以下となる最小の上方補正を二分探索すると、**必要な補正は最大約0.056mm**（t≈0.70–0.75）。25mm球もt=.65/.75/.85の探査では約0.08mm以内だった。

さらに接平面位置から**一律+0.08mm**の候補中心経路で、球径24.26/25.0/25.5mm×各21点を試すと、**全て交差体積0**。この中心経路の高さは各点で単調減少（大きい球径25.5mmも21区間の最大上昇は負：最小降下約0.106mm/区間）。これを`ball_size_audit.py`で24.26/25.0mmの**候補経路**として独立に検証する。

これは **「3D剛体球が干渉しない下り経路が少なくともサンプル点に存在する」**という主張のみを支持する。球が静摩擦・慣性・偏心・公差の下で自動的にこの経路をたどる証明ではない。実プリントは一切承認していない。

旧+0.55mmは広すぎて見逃しがあった。今回の+0.08mmは上記床曲率による最小補正≲0.06mmを参考に採用した**CAD上の小さな幾何補正上限**であり、造形誤差を覆い隠す「公差」ではない。

### 口の実STL形状の抜き取り比較

旧`E01-V8` / `SC02-V17`と、新`X89-E01-U1` / `X89-SC02-U1`の**実STL**を各ポートから0.02mm内部の平面で切り、真円の近傍頂点を比較した。既存は半径約12.868〜12.872mm、新版も主たる真円部分は12.868〜12.90mm程度。数値契約の開口直径25.74mmを変えていないことと整合する。ただし傾斜・STL三角化・入口付近の肉厚差があり、**全断面のBRep厳密パリティや印刷品との嵌合保証ではない**。開口周辺の他の縁や継ぎ目の段差は別途。

### 干渉確認の厳密化：通れる中心経路と接続口の実BRep

`ball_size_audit.py`で坂付きSC02の**直径24.26mmおよび25.0mm**を21地点（0〜1の0.05刻み）、接平面基準+0.08mmの球中心で検査。同時に候補中心Zが下り方向へ**単調減少**することを確認。小さな床曲率の補正が必要なため、`+0.03mm`位置だけの干渉を「通過不能」と同一視しない。**両方ともサンプリング点で交差ゼロ／単調減少なら`candidate_rolling_corridor_passed`**とする。旧`strict_nominal_slope_clearance_passed`は診断項目として保持し、意図せず事実を隠さない。

これとは独立に`export.py`が**生成済みCAD BRepの実ポート**を西／北それぞれ24方位×半径内外2点で照合（計96サンプル）。口から0.02mm内側で、仕様半径12.8703mmの内側0.15mmは空洞、外側0.15mmは実体であることを確認。**接続規格が数値だけ一致して本体CAD口は塞がっている**という回帰を捕捉する。

- 上記は**有限サンプルのCAD可否判定**であり、旧/既製品の実物接続・Bambuスライス・表面粗さ・運動エネルギー・慣性・偏心を保証しない
- +0.08mmは実測で必要だった約0.056mmの接触曲率補正に対応する**球の中心位置の候補**であり、印刷時の造形公差として足してよい値ではない
- 25.5mmの球も21点では候補経路の干渉0だったが、入口25.74mmとの差0.24mm（片側0.12mm）のため余裕が極めて少なく、試作の合格径には含めない
- 引き続き`print_ready: false`、ドラフト、実機テスト前のマージ禁止
