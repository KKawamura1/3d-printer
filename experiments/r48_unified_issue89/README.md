# Issue #89 — R48カーブトンネルを「坂の有無だけ」で生成し直す

- 親Issue: https://github.com/KKawamura1/3d-printer/issues/89
- 元の箱型E01をSC02の扇形で切るだけのPR #90とは**設計が異なる**。
- 新エンジン: `brickcad/course_r48_unified.py`
- **実機印刷前提ではなく、2モデル同時生成・比較・球干渉確認のための独立PoC**。
- 旧E01/SC02、既存成功版、PR #75/#85/#87は一切編集しない。

## 1つの生成器・2つのモデル

| 入力 | 水平E01系列 | 坂ありSC02系列 |
|---|---|---|
| 新実験ID | `X89-E01-U1` | `X89-SC02-U1` |
| R48中心線 | 同一XY | 同一XY |
| 床Z | 6.35mm一定 | 西口25.55mm→北口6.35mm、smoothstepで19.2mm降下 |
| 外装 | 曲線に沿うLoft | **同じ**曲線Loft |
| スタッド | **同じ7個の完全な円形スタッド** | 同じ7個 |
| 下面チューブ | **同じ3本の完全なE31-05チューブ** | 同じ3本 |
| 窓 | **同じ外周5窓・角R0.8** | 同じ5窓（床の高さに追従） |
| 屋根上面 | Z=38.4mm | Z=57.6mm |
| 検査対象球 | 直径24.26mm | 同じ24.26mm |

- 本体外形ははじめからR48沿いにLoftし、矩形完成モデルの切断で細い支持片を作らない。
- シェル上下R、窓の角R、スタッド頭Rは共通。
- 屋根上面は**水平**（通常デュプロを載せるため）。坂ありモデルだけ屋根上面が高い。
- ポート中心の座標・向き、真円断面直径25.74mm、球径24.26mm、E31-05の下面スリット深さとビード仕様は固定。
- 内部の走路半径は両方とも端面から約1mmのリップで元通り、奥に約4mm遷移して **半径+0.4mm**（過去の停止報告に対応）。既製品側の開口を拡げる変更ではない。
- `X89-...` の凹刻印は試験的に5mm。E31/既存本番刻印標準は改変しない。

## 強い制約と完了条件

- [ ] CAD結果が単一実体かつSTL水密、デュプロ外形内
- [ ] E01/SC02の球サンプリング21点でCAD干渉がなく、`+0.4mm` の内側径の端部遷移が連続
- [ ] 接続口が旧E01/SC02と**実BRep断面・位置・接線方向**で一致すること。今のポート解析は数値／入力契約検査で、完全な旧品との形状差分テストではない
- [ ] **同尺度・同視点**で5窓、7スタッド、3チューブ、内外壁、刻印の位置を手で目視
- [ ] Bambu Studio/A1 mini/PLA Basic/0.20mm/サポートOFFでスライスを確認
- [ ] 実機の保持力、支持材強度、子供が触る角、実際の球の転がり・継ぎ目停止を確認
- [ ] 左巻き版は鏡映後の刻印位置を別途確認し、改めてモデルID発行。現在は右巻き2品のみ
- [ ] 最終採用時だけ新規本番版IDとディスパッチャ統合を検討。旧版を上書きしない

**CADで球が干渉しない ≠ 実際に転がる/止まらない ≠ 印刷して遊んで安全。**

## 2026-11-22 追加検査：大きな球は本当に通るか

前回の`export.py`は直径24.26mmの球を**走路床との接触高さから+0.55mm**に配置して21点の干渉を評価していた。球が自然に転がるという主張には不十分で、接触付近の干渉を見逃す。

GitHub Actions [#91の実STEP](https://github.com/KKawamura1/3d-printer/actions/runs/44979039817/artifacts/14736738216) を再読み込みし、**接触基準+0.03mm**で、走路中心線の端点を含む11地点、直径24.26・24.5・24.75・25.0・25.2・25.5・25.75・26.0・28.0mmを静的剛体球BRepで照合した。実装した再実行スクリプトは`ball_size_audit.py`（固定7径で正式レポート生成）。接触高さ0mmちょうどのOCC BRep booleanには偽の大きな交差体積が出る場合があるため、0.03mmのごく小さな浮かせを設けた。**+0.55mmの検査結果は自然通過の根拠として扱わない。**

| 直径 | 水平 E01 | 坂 SC02 | 考察 |
|---:|---|---|---|
| 24.26mm | 11地点干渉なし | `t≈0.65/0.75/0.85` で最大約0.138mm³ | 坂の一部の床付近でわずかに接触/干渉 |
| 24.5mm | 11地点干渉なし | 同部分で最大約0.158mm³ | 同上 |
| 25.0mm | 11地点干渉なし | 同部分で最大約0.214mm³ | 同上 |
| 25.2mm | 水平側干渉なし | `t=.5`で約0.080mm³（ほかの地点は未詳細走査） | 坂中央の上側にも干渉し始める |
| 25.5mm | 11地点干渉なし | `t=.5`で約4.625mm³ | 明確な中央/屋根側干渉。径の上限目安 |
| 26.0mm | 入口・出口近辺で最大約12.67mm³ | 中央や両端等で最大約38.18mm³ | 入口25.74mmより大きく既製品互換上不可 |
| 28.0mm | 全域に近い位置で大きく干渉 | 全域に近い位置で大きく干渉 | 対象外 |

数値は**特定の11地点、中心線中央、接触+0.03mm条件**における体積（mm³）であり、物理的な停止確率ではない。球の位置が左右へずれたり、床の積層不整・静止摩擦があれば悪化し得る。逆に小さな干渉は実際には球の転がり方によって解消する可能性もある。

`t=.75, d=24.26`で球を+0.1mm浮かせると干渉が消える（+0.03mmでは0.138mm³）。これは小規模だが未解消の通過リスク。`t=.5, d=25.5`では高さを上げると上側への干渉が増え、単なる浮かせでは直らない。

**判定: 坂側の「24.26mmが無干渉」および「25.5mmも通る」はどちらもまだ主張できない。** まず標準球について、床の走路曲率に沿った連続スイープを作成し、天井・外側壁と別々に必要な逃げを最適化する。**入口径25.74mmは広げず**、必要なら内部のみに逃げを追加する。同時に材厚・印刷性を再検証。

実行（事前に`export.py`で2つのSTEP生成）:

```bash
python -m experiments.r48_unified_issue89.ball_size_audit \
  --step-root build/issue89-shared-r48 \
  --out build/issue89-shared-r48/oversize-audit.json
```

### 精査用のオンデマンドCI実行
この実験は直径別のSTEPブーリアン演算が重いため、通常pushでは実行しない。次の`[issue89-oversize]`コミットで専用CIを明示実行し、診断reportをArtifact保存後、標準球近接干渉が残る場合**プリント承認ゲートで意図的にFAIL**にする（CAD/STL生成そのものの成功とは区別）。
