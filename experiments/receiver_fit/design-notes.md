# 下面保持力の独立比較・試作01

14片実験10番の下面が純正スタッドに対して曲げで外れやすいため、側壁と中央チューブを別々に変更する。上面は成功条件のOD9.40 / ID6.40 mm、スタッド間隔16 mmで共通。実物の保持力改善は未確認。

| 刻印 | 条件 | 下面内法X / Y mm | チューブ外径 / 内径 mm |
|---|---|---|---|
| 01 | A：現状基準 | 25.40 / 25.40 | 13.10 / 9.40 |
| 02 | B：Y壁のみ | 25.40 / 25.34 | 13.10 / 9.40 |
| 03 | C：チューブのみ | 25.40 / 25.40 | 13.50 / 9.40 |

本体31.80角、高さ19.20、スタッド高さ4.50、天井厚1.60、外角R0.80、スタッド端R0.50、下面入口0.30 mm面取りを統一。Y壁は両側0.03 mmずつ内側へ移す。チューブは過去の16片実験にもある13.50 mmを比較値に採用。CAD13.10→実測約12.93という過去例を参考に、接触に届く可能性を試す値であり、一定の縮みを仮定した確定補正ではない。チューブ増厚は剛性・印刷経路にも作用する。

今回の基準は**14片10番**。PR #12の外寸補正32.00×31.87は同時適用しない。外寸と下面を一緒に変えると、保持力の違いを切り分けにくくなるため。製品への採用やPR #12への反映は結果を見て判断する。

## 印刷用

[3個まとめたSTL](plate.stl)・[印刷一式ZIP](https://github.com/KKawamura1/3d-printer/blob/c0ff73d59efe906385426e859ac26ff70e7f650e/prints/duplo_receiver_trial_01.zip)。
個別STLは [01](01/brick.stl) / [02](02/brick.stl) / [03](03/brick.stl)。

STLは100%、回転0度で、スタッド上向き・開口下向き。まとめSTLは115.8×31.8 mm。モデル中心をベッド(90,90)へ置くと個体中心は(48,90)/(90,90)/(132,90)。自動配置・自動回転で軸を変えない。刻印面の横矢印が+X、右面の矢印が+Y。各条件1個なので配置や印刷のばらつきは分離できない。

A1 mini / 0.4 mm / PLA Basic、0.20 mm層、Classic、壁2周、Grid15%、流量比0.98、XY補正0を前回条件の出発点とする。全12スタッドの中間層でInner wallを確認する。3MFとG-codeも保存し、実際の設定・配置をsetup.jsonに記録する。上面形状が共通でも印刷結果まで同一とは限らない。

## 比較手順

1. 同じ純正ブロックのスタッドを各試料の**下面へ**差し込み、着座・取り外す感触を比較。上面再校正と取り違えない。
2. 同じ構成・長さの純正タワーで一つだけ差し替え、同じ持ち位置でX/Yへ曲げ、どの界面から外れるか記録。純正同士を対照にする。力を計測しない場合は定性的な相対評価。
3. 既存の印刷10番・13番をそれぞれ各試料の下面へ差し、きつくなりすぎないか確認する。新試料同士も組み合わせてよいが、受け側・突起側を記録する。
4. 10回着脱後に再確認。内壁間X/Y・チューブ径を同じ位置、軽い押付力で測り、measurements.csvに記録。強い抵抗がある場合は押し込まない。

10番の実測内法X25.19/Y25.37、純正2列の名目外端25.32 mmに対し−0.13/+0.05。ただし曲げ耐性に方向差をあまり感じないという観察がある。Yだけが原因とは断定しない。0.05 mmの差は測定ばらつきと同程度になり得る。最終判断は実物の保持・着脱で行う。

## 再生成・検証

```sh
python -m experiments.receiver_fit.design --out build/duplo-receiver-trial-01 --zip prints/duplo_receiver_trial_01.zip
```

各個体・まとめのBRep、STL閉鎖性、STEP再読込を検査。上面と天井が同一で、変更が狙った下面部位に限られることを幾何テストで確認する。意図した接触に伴う剛体干渉はreport.jsonに量を残し、無干渉や保持力合格とは扱わない。各viewer.htmlは実際の形状から生成する。
