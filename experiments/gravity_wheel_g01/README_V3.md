# GW01-V3 — ボールを保持する軸方向ホイール（実機未検証）

GW01-V2は回転中にボールが開放カゴから落ちる可能性があり、入口・出口のガイドも空中に浮く状態でした。
V3では、**回転する密閉寄りの筒**でボールを保持し、**固定ゲート**で出口タイミングを制御します。
入口・出口ガイドにはそれぞれデュプロの下面接続を持つ支柱と三角リブを追加しました。

## ボールの経路（+Y方向）

1. **入口**: 上段レール床83.15mm（デュプロ4段分の高さ）の先から、X=-32mmの入口ガイドへ進む。
2. **回転**: 球径24.26mmのボールが内径27.10mmの回転筒に入る。反対端の固定出口板に阻まれたボールの重さが、半径32mmのモーメントを作り、ホイールを下向きに回す想定。
3. **排出**: およそ60°回ると、固定出口の52°〜68°の開口部が球を通せる位置に来る。
4. **出口**: X=-16mmへ横に16mm移動し、+Y方向の出口ガイドを下り、床25.55mm（デュプロ1段分の高さ）の既存レールへ接続する。

回転軸は+Y方向へ6.84°下り。2か所のレール端点のX座標は16mmピッチ上にあり、左右に1ピッチずれる。カゴの観察窓は直径9mmで、球の直径より小さい。

**重要**: これは流路・位置の「静的な設計」。ボールが実際に回転を始めるか、どの位置で止まるか、最終的に出口まで移るかは実物試験が必要です。

## 生成

    python -m unittest experiments.gravity_wheel_g01.test_axial_v3 -v
    python -m experiments.gravity_wheel_g01.axial_v3 --out build/gravity-wheel-g01-v3

CAD Actionsの `experiments/gravity_wheel_g01/cad-build.json` もV3へ変更。
V1は `design.py`、V2は `axial.py` に残し、実験履歴を保持。

## 6つのSTL

| STL | 内容 |
|---|---|
| `rotor.stl` | 2本の閉じた回転筒＋3本の接続リブ＋軸ハブ。窓8個 |
| `frame_inlet.stl` | 固定入口ゲート＋長い支柱＋共通E31-05下面 |
| `frame_outlet.stl` | 固定出口ゲート（約52°〜68°開口）＋支柱＋共通E31-05下面 |
| `axle.stl` | 直径4.40mmのシャフト＋片側ヘッド |
| `guide_inlet.stl` | 上段83.15mmからカゴへ下るレール、柱・リブ・E31-05下面つき |
| `guide_outlet.stl` | カゴから下段25.55mmへ下るレール、柱・リブ・E31-05下面つき |

既存の `brickcad.course_contract.course_fit` と `add_course_receiver_features` から支柱下面を生成し、試作品独自の寸法を重複定義しない。

## CADで検証できたこと

- ボール径24.26mmに対して筒内径27.10mm、固定ゲート穴径28.40mm
- 回転0〜90°の複数サンプルで、ローター／ゲートに干渉なし
- 筒内の球とローターの静的干渉なし（観察窓も球を通さない）
- ボールは入口位置では出口ゲートに阻まれ、60°では出口開口を通る
- 4本の支柱下面接続はデュプロ16mmピッチで配置
- 既存上段・下段床の高さに一致
- 6部品それぞれ単一の正しいBRep。メッシュ閉曲面もエクスポート時に確認
- 各部品のXYZ外接寸法はA1 mini公称180mm以内（**造形向きやサポートは別途確認**）

## 完成まで未解決の課題

1. **本当に動くか**: ローター、ボール重量、固定ゲート摩擦、ゲート開口幅、出口レール段差を実物で検証（各10回）。
2. **自動復帰**: 今回も1球ごとの手動待機位置合わせ。自動連続運転には重り・ストッパー等の機構追加が必要。ボール重量の実測が有益。
3. **軸抜け対策**: シャフトは頭付きだが抜け止め未完成。部品破損・脱落、角R、スライサーのサポートと初層安定性も要検証。
4. **既存のレールとの接続**: レール末端は床高さと進行方向を一致させたが、既存パーツのリム・ジョイント構造は未複製。自由に連結するためのアダプター調整が必要。
5. **遊具安全性**: 24.26mm球や軸・支柱の安全性未評価。**子どもには渡さず、大人だけで検証**すること。

## 推奨する初回実物テスト

1. 支柱とローターと軸を大人が組み立て、手で軽く回す。
2. 入口・出口を置く前に筒が回転中に干渉しないこと、軸が抜けないことを確認。
3. 入口ガイドに1球置いて、手動で初期角度を合わせて投入。
4. 始動、回転停止、出口排出の成否を各10回記録。止まったら止まった角度を記録。
5. 始動しなければボール質量・軸摩擦を、排出しなければ固定ゲートと出口の段差を優先修正する。

### 取り扱い

A1 mini/PLAのスライスと印刷は未実施。各STLは部品単位で印刷姿勢を決めること。
公称寸法内でもサポート・接地・積層方向を見て不適切なら造形しない。
小さな部品と球は幼児から隔離。動力・安全性は保証されないエンジニアリング試作品。
