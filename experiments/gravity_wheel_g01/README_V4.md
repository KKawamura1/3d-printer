# GW01-V4 — 120°回転して既存レールに戻る軸方向ホイール

V3は約60°で排出していたため回転の迫力が小さかった。V4は**120°付近まで回転してからボールを排出**する比較試作です。
回転筒や軸、デュプロ接続部はV3と同一設計です。V3のaxial_v3.pyを共通ジオメトリとしてパラメータ化し、V4は角度だけ指定する薄いラッパーaxial_v4.pyにしました。**元の60°版もそのまま再現できます。**

## 経路・寸法

- ボールは入口 **X=-32mm** から回転軸に平行な+Yへ進入
- ポケット中心は回転軸から半径32mmで、重量によって0→90°回転
- 90°以降は重力トルクが回転に逆らうため、**それまでに蓄えた回転の慣性が必要**
- 固定出口ゲートの弧状穴を **112〜128°** に配置し、およそ120°でボールを解放
- 出口は **X=+16mm**。入口から右へ48mm（デュプロ16mmピッチ×3）移動
- 入口の床83.15mm（デュプロ4段上）、出口の床25.55mm（1段上）はV3と同じ
- ローターの2つの筒は維持、筒内径27.10mm・球径24.26mm・軸傾斜約6.84°は共通

## 重力回転の制約

ボールの半径32mmの回転円で、0°を最初の横向き位置とすると、球中心の回転による高度低下は

    Δh(θ) = 32 mm × sin(θ)

- 60°: 約27.7mm下がる
- 90°: 32mm下がる（最も低い位置）
- 120°: 約27.7mm下がる
- 150°: 16mm下がる
- 180°: 0mm（元の高さに戻る）

**120°は運動エネルギーが残っていれば到達し得る設計ですが、必ず回ることを示すものではありません。**
180°ちょうどまで球だけで回す場合、初期と最終の位置エネルギーが同じで、摩擦を含めると余裕がゼロです。追加エネルギー・慣性制御・ラッチ等なしで確実に180°到達する設計ではありません。
逆にボールを120°で排出した後、ローターが慣性で180°に向かう可能性はありますが、止め具がなく自動復帰とは呼べません。

## CADの生成

    python -m unittest experiments.gravity_wheel_g01.test_axial_v4 -v
    python -m experiments.gravity_wheel_g01.axial_v4 --out build/gravity-wheel-g01-v4

既存V3: `python -m experiments.gravity_wheel_g01.axial_v3 --out build/gravity-wheel-g01-v3`

生成するSTLは同じ名前の6点です:

- rotor.stl
- frame_inlet.stl
- frame_outlet.stl
- axle.stl
- guide_inlet.stl
- guide_outlet.stl

ローター・入口ゲート・軸・入口ガイドはV3から形状変更なし。
変更があるのは**出口ゲートの穴位置、出口ガイドのX位置**です。
6つの部品は同じA1 miniの公称造形サイズ内に収まります。

## まだ実物で確かめること

1. 球を1球投入して0→90°→120°まで止まらず回るか（摩擦の影響が大きい）
2. 放出開始角度・ゲート引っ掛かり、出口ガイドへの受け渡し（各10回）
3. 出口レールが純正・既存プリントレールと段差なくつながるか
4. 120°放出後にローターがさらに回りすぎないか、180°での自動位置決め可能性
5. 軸の抜け止め、スライサーのサポート、幼児向け安全性

**注意**: 24.26mmの球、細い軸、取り外せる部品を含むため、現段階では完成玩具ではなく大人の検証専用です。印刷・動的動作・連続運転はまだ未検証です。
