# GW01-V1 — 2カップ式・重力回転ホイール（実験）

24.26 mmの既存ボールが**左のU字カゴに入ると、その重量でホイールを回して下へ落とす**ことを狙った、手動リセット式の試作。自動復帰機構はない。ローターは180°対称、2個のカゴは逆向き。実物で回る・落ちることは**未検証**。

## 構成

| STL | 役割 |
|---|---|
| `rotor.stl` | 2個のU字カゴ・スポーク・ハブ。軸穴と側板用の止まり穴あり |
| `guard_left.stl`, `guard_right.stl` | 軸方向のボール脱落を減らすガード。直径14mmの覗き穴と位置決めダボ |
| `stand_left.stl`, `stand_right.stl` | 左右の軸受・DUPLO 2×2下面受け。E31-05浅型スリットを採用 |
| `axle.stl` | 頭付きの取り外し可能な軸。抜け止めは未完成、安全性要改善 |

- 軸方向Y、移動方向X、鉛直方向Z。軸中心の高さ58.18mm。
- 上段レールの床：44.75mm（通常レール床6.35mm＋2段分38.4mm）、下段レール床：6.35mm。
- 2つの台座の中心はY=±32mm。**同じデュプロ基盤上に4ピッチ離して配置**する（Y座標の中心差64mm）。
- 直径24.26mmのボール、カゴ内半径13.5mm、回転軸直径4.5mm、軸穴直径5.5mm、両側ガード外面±15.4mm、軸受内面±17.5mm。
- 回転中にボールを捕捉できること、下部で滑らかに落とせること、落下球を既存レールで回収できることは**CADの静的な干渉検査では証明できない**。受ける下段レールの位置・向きは実物で探る。

## 生成とテスト

```bash
python -m unittest experiments.gravity_wheel_g01.test -v
python -m experiments.gravity_wheel_g01.design --out build/gravity-wheel-g01
```

CAD preview and print artifacts workflowで `targets=experiments/gravity_wheel_g01`。`assembly.step` は配置確認用、**印刷用ではない**。6個のSTLを個別にスライス・配置する。ローターは軸方向が造形高さ方向になるように寝かせればU字断面が連続積層となる。フレーム・ガード・軸は各自サポートと積層方向を確認すること。

## 実機チェック（成人のみ）

1. 各部品の剥離、バリ、ガード固定具・軸の脱落がないことを確認する。小さな部品とボールは乳幼児から隔離。
2. まずローターとガード2枚を組み、軸を通して手で軽く回す。カゴに接触するガードがないか確認する。
3. 2個のスタンドをデュプロ上でY方向64mm間隔に固定する。部品が柔らかくグラつくなら使用しない。
4. 左カゴが上向きに開く位置へ手動セットし、上段のレールから1球を転がす。勝手に回り始めるか、どの角度で球が落ちるか、下段で跳ねないかを10回程度記録する。
5. 失敗時は、軸摩擦、受け位置、カゴの端壁の高さ、ボールの実重量を計測して次版を作る。無理に押し込まず、危険があれば実験を中止する。

**未解決**: 無負荷のローターはほぼ対称で戻り機構なし。ボール重量だけで始動するか、どこで放出されるかの物理試験が必要。軸が抜ける・側板が外れる構造は子どもに渡せない。設計物を完成品と扱わない。
