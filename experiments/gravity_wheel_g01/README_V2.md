# GW01-V2 — 軸方向入出力・傾斜軸の重力ホイール

GW01-V1の改善試作。従来方式は design.py に残し、軸方向方式は axial.py に分けています。
ボール直径は24.26mm。**入口と出口は回転軸とほぼ平行な+Y方向**です。

## ボールの流れ

1. 上側の guide_inlet から+Y方向に球が進み、初期位置のU字カゴに入る。
2. 球の重みが回転軸から離れた位置に掛かり、ローターを回転させる。
3. 出口側固定円盤の弧状開口（回転角50°〜80°）にカゴが到達すると、
   球が guide_outlet へ抜け、引き続き+Y方向に進む。
4. 連続運転・自動復帰は未実装。球ごとに手動セットする前提。

## なぜ軸が斜めなのか

水平軸では、ホイール回転後に球を軸方向へ運ぶ重力成分が弱い。
軸自体を+Yへ6.84°下る方向に傾け、回転後にも出口へ重力が働く設計とした。
ただし、実際の摩擦・始動・排出タイミングは運動解析も実物試験も未実施。

## 6部品

| STL | 内容 |
|---|---|
| rotor.stl | 180°対向の2カゴ・ウェブ・中央軸穴 |
| frame_inlet.stl | 入口側固定ゲート＋支柱＋DUPLO 2×2下面 |
| frame_outlet.stl | 出口側の弧状ゲート＋支柱＋DUPLO 2×2下面 |
| axle.stl | 頭付き軸（抜け止め不完全） |
| guide_inlet.stl | 軸方向のU字入口ガイド |
| guide_outlet.stl | 軸方向の短いU字出口ガイド |

支柱下面は既存共通の E31-05浅型レシーバーを使用。
brickcad.course_contract.course_fit と add_course_receiver_features を呼び、
寸法・スリットを既存レールと統一しています。
台座の中心は X=+48mm, Y=±64mm（Yの間隔128mm、8ピッチ）。
回転軸の傾斜率=-0.12、球径24.26mm、カゴ内半径13.55mm、
固定ゲート穴径28.4mm。

## 生成とテスト

    python -m unittest experiments.gravity_wheel_g01.test_axial -v
    python -m experiments.gravity_wheel_g01.axial --out build/gravity-wheel-g01-v2

CAD Actionsは experiments/gravity_wheel_g01/cad-build.json を参照。
6部品のSTLを個別に印刷します。assembly.step は形状確認用。
元のV1を再生成したい場合は design.py を明示実行します。

CADでは形状妥当性、カゴと固定ゲートの0〜90°非干渉、
球とローターの非干渉、軸・支柱の静的な非干渉を検証します。
**CAD検査は実際に回る・転がることを保証しません。**

## 大人による実物検証

最初は支柱・軸・カゴだけを仮組みし、スムーズに回転するか確認。
ボールを1球入れて始動角度、停止箇所、出口での引っ掛かり、
出口レールへの受け渡しをそれぞれ10回程度観察。
球の重さ、軸摩擦、ゲート開口位置、入口と出口の段差が主要な調整候補です。

**安全**: 小部品、長い軸、脱着可能な部品と24.26mm球を使用。
軸抜け止め・耐久・小児安全性は未検証。完成玩具ではなく、
保護者のみが扱う機械試験用としてください。
