# SC02-V17 の内部停止と窓の改善 — 4条件比較（CAD試作）

**実物観察の根拠:** SC02-V17 は他のブロックに載せなくても内部で不定期に球が噛み込み、前後に傾けても抜けない再現例がある。停止しないときは何十回も続く。バリが目視で見当たらない個体もある。短時間の無停止を改善の証拠としない。[Issue #77](https://github.com/KKawamura1/3d-printer/issues/77)、[観察記録](../../docs/ball-stop-observation-log.md)。

**目的:** 通路のクリアランス不足と、窓の視認性を*独立に*比較してから統合する。元の SC02-V17 / SC02L-V11 / PR #75 の11形状と旧 STL は変更しない。

| 新しい刻印ID | SC02-V17からの変更点 | 主に比較する効果 |
| --- | --- | --- |
| SC02-V18 | 内部の通路断面を半径方向+0.20mm（直径相当+0.40mm）。窓は現行の外側3個 | 造形誤差余裕A |
| SC02-V19 | 内部の通路断面を半径方向+0.40mm（直径相当+0.80mm）。窓は現行の外側3個 | 造形誤差余裕B |
| SC02-V20 | 現行通路のまま、外側窓を幅10mm×5個に増やす | 窓だけの効果 |
| SC02-V21 | 内部通路+0.40mmと外側窓5個を組み合わせ | 統合の適合性 |

**注意:** 「直径相当+0.4 / +0.8mm」はCAD空洞の断面円弧半径を増す設計パラメータであり、印刷実物の最小クリアランスや球との距離を示す数値ではない。接続口の原形状は変更せず、中心経路の始点・終点からの規定位置で滑らかに拡大/復帰する。共通の `BALL_TRACK`・E31嵌合・通常パーツの既定値は変更しない。

## 窓と強度

既存版は外側の凸曲面に3窓（幅およそ8.35mm）。今回の窓増量案では**外側に5窓（幅10mm）**を均等に設ける。通路に沿って下辺が変化する五角形の窓形状を踏襲し、低い側壁ガードを残す。CADでは元の材料から窓を切り抜いた後にBRep・視線・下部ガード・メッシュをチェックする。

**凹側の開口は未実装**：カーブ内側の壁・天井・支持構造の断面を先に調査し、開けても走行/剛性に影響しない範囲を見つける。今回の実験結果が出る前に全トンネルへ波及させない。窓縁のR統一は別途安全確認が必要。

## 印刷物

`experiments/sc02_robustness/cad-build.json` のモデルを GitHub Actions **CAD preview and print artifacts** で生成する。個別STL 4点と、A1 mini 180mmベッド向け4点配置版 `sc02-compare-4.stl` を用意。全4点をまとめて印刷する前に、Bambu Studioで**サポートOFF・積層0.20mm**のスライス/オーバーハング/バリと所要時間を確認する。

```bash
python -m experiments.sc02_robustness.design --out build/sc02-robustness
```

### 実物合格の考え方

1. 原版 SC02-V17 と各候補の単体走行・噛み込み位置を記録。数十回無停止だけで合格にしない。
2. 同じ球を使い、複数の造形個体を比較して3Dプリンター固有のばらつきを分離する。
3. 長いコースへ組み込んで完走率と停止箇所（内部/接続口）を分ける。
4. 大きい窓による強度、接続保持、手触り、印刷上のバリ、型番の判読性を実物で検証する。

`report.json` の `physical_rolling_validated` / `slicer_validated` / `durability_validated` は意図的にfalseであり、CAD PASSと実物PASSを混同しない。
