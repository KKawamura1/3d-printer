ZIP内の `plate.stl` は全試料を一つにまとめた配置済みSTL。個別STLと同時に読み込まない。mm・100%、スタッド上向き・底開口下向き。180×180mmベッド中央に置く。STLはベッド絶対座標を保持しないため、読み込み後の中心90/90と向きを確認し、自動配置や自動回転を避ける。印刷設定やG-codeは含まない。

## 第1段階：印刷せずスライスで穴径を選ぶ

| 側面ID | 外径mm | 穴径mm | 環状壁厚mm | ベッド中心X/Y mm |
|---|---:|---:|---:|---|
| 01 | 9.40 | 6.50 | 1.450 | 69 / 111 |
| 02 | 9.40 | 6.45 | 1.475 | 111 / 111 |
| 03 | 9.40 | 6.40 | 1.500 | 69 / 69 |
| 04 | 9.40 | 6.35 | 1.525 | 111 / 69 |

通常高さ2×2。本体31.8×31.8×19.2、スタッド高さ4.5、上端R0.5、本体角R0.8、底面入口面取り0.3。裏面は16片実験の基準Cと同じ壁厚3.20（内法25.40）、チューブ外径13.10／内径9.40、天井厚1.60。既存レールprofileの壁3.16・管13.30とは別。側面IDと軸矢印は16片と同じ彫刻方法で下面5mmの接触域を変更しない。穴径変更は通常レゴとの混在接続など、穴利用の互換性も未検証。

1. Bambu Studioで4条件を同じ設定のままスライス。基準はA1 mini／0.4mm／Bambu PLA Basic、積層0.20、壁2周、Classic、外壁幅0.42、内壁幅0.45、Grid15%、流量比0.98、外壁200mm/s、XY輪郭・穴補正0、レイヤーごと印刷。保存済み3MFの設定を引き継ぎ、実際の設定はsetup.jsonに残す。
2. 線種プレビューでスタッド円筒の中間層（例Z=21.2）を確認。**Outer wallの内側の経路**について4スタッド全てのInner wall／Gap infillを記録する。円筒部の隣接層でも安定するか確認。上端R部分だけで判定しない。
3. `slicing-and-fit.csv`に各スタッドの線種・観察Z・バージョン、notesに速度・線幅も記録。3MFとG-codeを保存する。Innerになる中で穴の縮小が最小の条件を候補にする。線種混在・不安定なら保留。全てGapでも即採用せず結果を残す。

プレート範囲73.8×73.8mm、5mmブリム込み83.8×83.8mm。実際の除外領域・ブリム・継ぎ目・経路はスライサーで確認する。第1段階の印刷は必須ではない。

## 第2段階：選定穴径で外径を調整

付属の仮候補ZIPは穴径6.40。**選定結果を先取りした推奨値ではない**。違う穴径を選んだら再生成する。

| ID | 外径mm | 個体 | ベッド中心X/Y mm |
|---|---:|---:|---|
| 01 | 9.36 | 1 | 48 / 111 |
| 02 | 9.40 | 1 | 90 / 111 |
| 03 | 9.44 | 1 | 132 / 111 |
| 04 | 9.44 | 2 | 48 / 69 |
| 05 | 9.40 | 2 | 90 / 69 |
| 06 | 9.36 | 2 | 132 / 69 |

外径を変えると環状壁厚も変わる。**6個とも4スタッドのInner wallを再確認してから印刷する**。9.36だけGap等なら同一経路の外径比較とは扱わず、穴径を再検討する。プレート範囲115.8×73.8mm、5mmブリム込み125.8×83.8mm。重複は位置偏りを弱める対称配置で、位置効果の完全な分離ではない。

同じ純正ブロックで、完全着座・逆さ保持・子どもが取り外せる程度の着脱・約10回着脱後の緩みを比較。入らないものは無理に押し込まない。上面／裏面の評価を分け、裏面も確認用に記録。四隅の各スタッドの直胴部、同じ高さをX/Y測定し、ノギスを離して軽い接触で3回繰り返す。側面矢印はローカル+X／+Y、スタッド位置の符号はその軸に対応。実測9.32〜9.35は暫定目標で、径だけで採用を決めない。穴径による剛性差も嵌合に影響し得る。

出発点はIssueの旧校正2番CAD9.40→約9.351・Inner・ほぼ理想、新16片のCAD9.40→平均約9.153・Gap・保持なし、CAD9.48→9.415・Inner・入らない。`9.40−0.065=9.335`は1片からの外挿で予測保証ではない。

採用後にレール・トンネルへ反映し、最終部品でも経路と実物嵌合を再確認する。本PRは既存製品profileや名目基準を変更しない。

## 再生成

```sh
python -m experiments.stud_inner_wall.design --out build/duplo-stud-holes --zip prints/duplo_stud_holes.zip
# 第1段階で選定した穴径を明示（6.40は例）
python -m experiments.stud_inner_wall.design --stage diameters --hole 6.40 --out build/duplo-stud-diameters --zip prints/duplo_stud_diameters_ID6p40_provisional.zip
```

空の出力先を使う。report.jsonに寸法・メッシュ検査・STEP再読込結果・配置、setup.jsonに期待設定と未入力の実設定、sha256.jsonにハッシュを保存。各IDディレクトリには実形状のブラウザビューアーを生成する。`slicing_validated=false`、`physical_fit_validated=false`は今回の実施状況で、線種や測定値を推測で埋めていない。
