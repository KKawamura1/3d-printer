## 2. 2×4以上のトンネルに窓を設ける

本番カタログ20種の旧ID・原典・印刷済み記録はそのまま残し、**新しい形状・新バージョン**を追加試作する。

| 旧版（無窓） | 新しい窓付き版 | 寸法 |
| --- | --- | --- |
| `E01-V3` | `E01-V4` | 4×4×2、水平緩右カーブT |
| `E01L-V1` | `E01L-V2` | 4×4×2、水平緩左カーブT |
| `SC02-V12` | `SC02-V13` | 4×4×3、緩坂緩右カーブT |
| `SC02L-V6` | `SC02L-V7` | 4×4×3、緩坂緩左カーブT |
| `SD03-V11` | `SD03-V12` | 2×4×3、緩坂急右カーブT |
| `SD04-V10` | `SD04-V11` | 2×4×3、緩坂急左カーブT |

`D01-V3`（2×4×3、緩坂直進T）は**すでに3窓ある**ので新規作成しない。
2×4以上の**開放レール**には壁・天井がないため、窓は作らない。2×2のトンネルは今回は対象外。

**窓の仮仕様：** 側面1か所、約10 mm（横）×9 mm（縦）の長方形覗き窓。4×4は入口側の外側壁、2×4の急カーブは入口側直線部の側壁。窓底はボール走路より上、上端は天井より下とし、床・屋根・下面E31・スタッドを残す。走路は元モデルのCADから**材料を引くだけ**なので、ボール通路を狭めない。鏡映左側にも外側窓を設ける。刻印は新しい版のIDで共通関数により1回だけ彫る。

**必須の検証：** BRep単一ソリッド、STL水密、除去量、共通E31・刻印監査、印刷後の窓開口・壁強度・サポートOFF、自然転がり、純正/印刷品との嵌合。**新しい窓形状は未実機検証**。コード生成ができても製品版へ自動採用しない。

## 3. 一括印刷プレートの生成

A1 mini 180×180 mm、外周余白3 mm、パーツ間4 mmで**全件を複数プレートに分割**する。配置の都合で一部が省かれることはない。Z回転・サイズ変更・旧STL再利用なし。

```bash
python -m unittest tests.test_course_followup_print tests.test_course_validation_plate -v
python scripts/course_followup_print.py --set missing
python scripts/course_followup_print.py --set windows
# または --set all
```

GitHub Actions **Issue37 follow-up printable plates** で `set=all` または `missing/windows` を選び、成功後は以下のArtifactsを取得する。

- `issue37-followup-missing-<run>`：未印刷7種を収録する `plate1/`・`plate2/` 等の個別+一括STL、manifest、layout.svg
- `issue37-followup-windows-<run>`：窓付き新版6種の同形式出力

**Artifactsが存在しCI成功を確認するまでは、STLの生成成功・実機使用可能とは主張しない。**
印刷時はA1 mini / PLA / サポートOFFでスライスを確認。特に曲線側壁の窓の開口・造形ブリッジ・下側ガード壁・刻印を目視確認する。

印刷後の確認結果はIssue #42へ追記し、窓付き版を採用するか決める。2×4以上の印刷品同士の嵌合が硬い問題はIssue #26で別管理し、本PRでは寸法の一律変更を行わない。


## 4. 一晩用の最優先1プレート：実形状ネスティング9点

ユーザー要望「一晩に1プレートしか印刷できない」に合わせ、当初の外接矩形配置から**CAD STLのXY投影シルエットを活用する配置**を追加した。4×4カーブ部品の空洞を使用することで、下記の**9点を同じ180×180mmプレート**に配置する。

- **旧PR56版の未印刷7点を全部**：E01-V3、SC02-V12、GC01-V5、SC03-V5、SC05-V1、SD04-V10、S01-V8
- **新しい窓付き版2点**：SD03-V12（急右カーブ）、SD04-V11（急左カーブ）

位置・Z軸回転（0/90/180/270度）を固定した再現スクリプト \`scripts/course_overnight_plate.py\` が、各CADを新規生成して位置決めし直す。別バージョンへの勝手な差し替え・メッシュの縮小なし。移動後の**実際の全STL三角形**を0.5mm解像度でXY投影し、3mmのベッド外周と4mm以上の相互クリアランスを保守的にチェックする。検証が失敗した場合は一括STLを公開せずCIを停止。

\`\`\`bash
python -m pip install "opencv-python-headless>=4.12,<5"
python scripts/course_overnight_plate.py
\`\`\`

Actions \`Issue37 follow-up printable plates\` の \`overnight\` job、手動の場合は \`set=overnight\` で生成。成果物 \`issue37-overnight-9parts-<run>\` に合成 \`pr56-overnight-9parts.stl\`、各パーツSTL、実投影配置画像 \`layout.png\`、証跡 \`manifest.json\` を収録。

**9点という数は発見済みの配置であり、計算上の最適数を証明したものではない。** 9点のサポートOFFスライス・実物は未確認。CADで有効なメッシュと造形成功は別なので、初回はBambu Studioのプレビューで窓・下面・スタッドと移動経路を確認する。残りの窓付き版4点は将来の別プレート候補として引き続き残す。
