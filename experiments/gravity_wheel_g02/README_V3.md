# GW02-V3 — 遠心保持を優先した、カバーなし反転カゴ

PR #97 の V2 を保持したまま、新たに V3 を追加。入口の球を受けて回転し、
160°/170°/180°の衝撃ストッパーで停止、左下へ放出する**機械的仮説**を試すもの。

## V2 からの修正

| 項目 | V2 | V3 |
|---|---|---|
| カゴの出口軸 | 初期 +10°（右上） | 初期 -20°（右下）、160°後はほぼ左水平 |
| 遠心力の出口方向成分 | 正、出口側へ押す | 負、底側へ押す（球中心で約 -2.57mm の径方向投影） |
| 入口・出口 | 開いた筒 | カゴ外側に高さ約3.45mmの保持段差 |
| 内側の開口 | 幅17mmの観察スリット | 幅22mmのレリーフ（24.26mm球より狭い） |
| 保持・脱出 | 開口方向に転がり出る懸念 | 静的には中央で段差に止まり、約2.5mm内側にずれると通過できる |
| 支えのウェブ | 出口に干渉する可能性 | 削除（スポーク・補強リブは維持） |

**「遠心力で保持される」条件を作っただけであり、連続回転・自動投入・
慣性放出が実際に起きると証明したわけではありません。**
摩擦、落下開始時のトルク、投入速度、衝突・反発を含めた動的試験が必要です。

### 物理上の考え方

- 回転軸からカゴ中心への位置: (X,Z)=(+10,+35)mm。
- 出口軸の向き: （X,Z）=(cos(-20°),sin(-20°))。
- 位置と出口軸の内積は約 **-2.57mm**。回転による見かけの遠心力は
  出口ではなく**閉じた底**へ向かう。V2 の +10°では約+15.9mmで逆向き。
- 出口軸と回転時の接線速度のなす角は約4°。急停止時に球が開口へ向かう条件を残す。
- 160°停止なら出口はほぼ左向きで、接線速度もほぼ左へ向く。
  170°/180°での運動と排出方向は必ず実機で比較する。

### 静的形状テストとその限界

- 24.26mm球を入れた時のカゴ・ローター干渉なし。
- 水平な出口進行（カゴ座標系 x=18mm、内側へのずれなし）には段差が干渉する。
- 約2.5mmの内側変位を伴う出口進行には**幾何学上の通り道**がある。
- カゴ開口は球直径より2.26mm狭く、開口を通じた直接の抜けを抑制。
- 5部品の妥当性、3角度の衝突・干渉とSTLメッシュは既存の検証を継承。

これらは**スムーズに飛び出すこと、そもそも一周回ること、ボールが
不意に外れないことの証明ではない**。段差はむしろ排出失敗を生む可能性がある。
回転中に球がカゴの軸方向へ移動する挙動は未評価。

## 生成

```bash
python -m unittest experiments.gravity_wheel_g02.test_open_cup_v3 -v
python -m experiments.gravity_wheel_g02.open_cup_v3 --out build/gravity-wheel-g02-v3
```

標準出力: `rotor.stl`, `stand_front.stl`, `stand_back_stop.stl`, `axle.stl`,
`stop_pin.stl`, `assembly.step`, `report.json`。

## 印刷用STLの座標と配置（浮き対策）

CADの組立空間ではローター・軸の中心が地面から66mmにあり、そのままSTLを
出力すると空中に浮いた状態になります。**V3の印刷用STLは全5部品を個別に
回転し、最下点をZ=0mmに配置**します。X/Yは個別部品の中央に揃えます。
一方、`assembly.step`は組立位置のまま保持します。

| STL | 印刷向き | 造形時の注意 |
|---|---|---|
| rotor.stl | 回転軸を鉛直、ハブの一端を接地 | ハブだけが接地するため、**ツリーサポートとブリムを推奨**。カゴ内部にサポートが残らないか必ずスライスで確認 |
| stand_front.stl | デュプロ下面リムを下 | 支柱は高く細いのでブリム推奨 |
| stand_back_stop.stl | 同上 | ストッパー部のオーバーハングを確認、必要ならサポート |
| axle.stl | 軸頭を下、軸を上に立てる | 細長いのでブリム推奨 |
| stop_pin.stl | 太い頭を下、細い軸を上に立てる | 細長いのでブリム推奨 |

`report.json`の `print_poses` に各部品の印刷姿勢・Z最小値・
底面接触面積・XY外形を記録します。テストは全STLのZ最小値≒0、
底面接触とA1 mini 180mm角の範囲内に収まることを検査します。

**注意:** Z=0への接地は「サポート不要」「印刷成功」の証明ではありません。
特にローターのカゴは張り出しが大きく、支えを追加しないと造形できない可能性が
あります。モデル内へのサポート侵入、サポートを除去した後のボール通路の
滑らかさを確認し、危険なスライスなら印刷せず追加設計を行ってください。

## 印刷前・実機評価

1. CI と STL 出力、組立図、Bambu Studio でのプレビュー・サポート要否を確認。
2. 成人の検証専用。支柱固定、軸とピン抜け止めが未完成なので、球・部品の
   飛散を防止する囲いの中で実験する。
3. **160°を先行**し、球がカゴに入るか、初動で回るか、途中で出ないか、
   停止時に左へ出るかを各10回計測。
4. 170°・180°も同条件で比較し、引っかかる場合は保持段差高さ・
   カゴの角度を再調整する。
5. 入口・出口レールはこの版にはまだない。接続機構は動作成立後に設計する。

V1/V2コードは比較用として保存。小さなピンと球、衝撃を受けるPLA部品があり、
**幼児の遊具として使わないこと**。
