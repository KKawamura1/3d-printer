# GW02-V6 — ローターを2分割し、平面を下にして造形

## 問題
V4は「STLがプレートに接する」テストは通ったが、接触面はハブのみ。
カゴが大きく宙に張り出し、サポートなしでは印刷できない。
添付のBambu StudioのG-codeではサポートOFF（enable_support = 0）。
形状と造形性を混同したのが原因。

## V6の修正
- **既存のローターを軸方向Y=0で前後半割**。それぞれの切断平面をビルドプレートに接する向きに変換したSTLを出力。
- ハブに**4組の位置決め穴**（径3.1mm、深さ6mm）。
- **ジョイナーピン**（径2.84mm、長さ11.5mm）を別に出力。これを**4本印刷**して接合する。ガタがあれば回転させない。
- V5の単純な半割では前側カゴが3つの独立ソリッドに分かれたため、後側と対称に**前側補強リブ**を追加。追加リブは球の通路を切り欠き、球と干渉しないようにした。
- カゴ、内部の段差、ストッパー角度はV4から変更しない。
- カゴの内側には組み立て前にアクセスできるため、サポートが必要でも除去しやすい。

### STL内訳
| STL | 個数 | 向き |
|---|---:|---|
| rotor_front.stl | 1 | 分割平面が下 |
| rotor_back.stl | 1 | 分割平面が下 |
| rotor_joiner.stl | **4** | 細いピンを立てる |
| stand_front.stl | 1 | DUPLO受け面が下 |
| stand_back_stop.stl | 1 | DUPLO受け面が下 |
| axle.stl | 1 | 軸の頭が下 |
| stop_pin.stl | 1 | ストッパーの頭が下 |

assembly.stepは4個のジョイナーピンを組み込んだ元の空間座標。
STLは各部品ごとにZ=0、XYは中央へ移動。

## 造形上の注意
半割は「サポートゼロ」を保証するものではない。半円状の溝の
**天井側で短いブリッジやオーバーハング**が残る可能性がある。
Bambu Studioのレイヤープレビューで確認し、必要ならサポートON。
半分に開いているため、組み立て前に内部サポートを除去できる。
カゴ内面の突起・ザラつきは球停止の原因になり得るので除去する。

### CADテスト
前後のローターがそれぞれ単一ソリッドであり、互いに重ならず、V4の外形に前側補強リブと位置決め穴以外
余計な形状差がないこと、ボール領域と干渉しないこと、全7種類の
STLがA1 miniの180×180mmに入りZ=0に接すること、**各ローター
半体の平面接触面積が150mm²以上**あることを検証する。
メッシュ検査も実施する。

### 組立と安全
4本のピンは試作の位置決め用で、耐衝撃の固定強度は未測定。
確実に接合できない場合は回転させない。接着による固定も考えられるが、
ボール通路や軸穴に接着剤を流さないこと。
まだ重力回転・球の保持・180°停止・排出は動的に検証していない。
小さなピン・球があるため、**成人だけの囲い付き試験用**。
