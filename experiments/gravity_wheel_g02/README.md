# GW02-V1 — 上部で球を受け、180°反転して左下へ出す2カゴ・ホイール（試作）

ユーザーの手描き図に沿う、PR #76 の **軸方向・120°排出方式とは別設計**。24.26 mm の既存ボールが右上から `-X` 方向へ入り、2カゴの一方を荷重で回し、カゴと球が約180°下がったところで左下へ排出する意図。もう片方のカゴが反転後の上段待機位置に来る（自動停止・位置決めまでは未実装）。

## 実装したもの

- **ローター**: 180°対向の2本の傾斜筒（内径27.30 mm、外径32.00 mm）。筒軸は横方向から10°の勾配。上では右→左に転がり込み、180°反転後は左下へ転がり出る向き。
- **固定外周カバー**: 回転途中の開放端から球が落ちないよう覆う、内径124.2 mmのリング。入口と出口に限り直径30 mmの通過孔を開ける。2つの下面パッドで支持。
- **ベアリング支柱2本と軸1本**: 軸径4.9 mm、穴径5.7 mm。デュプロ下面は `brickcad.course_contract` の E31-05 共通受け形状を利用。
- **球の位置**: 初期は回転軸より中心で (X,Z)=(+10,+35)mm、180°後は (-10,-35)mm。ボール中心が70 mm下がるため、PR #76 V4 の横始動と異なり、180°時点でも正の位置エネルギー差が残る。完全な上下死点を避けるため初期位置を真上からずらした。

```bash
python -m unittest experiments.gravity_wheel_g02.test -v

```

出力: `rotor.stl`, `shroud.stl`, `stand_front.stl`, `stand_back.stl`, `axle.stl`, `assembly.step`, `report.json`。

## 重要な未完成事項

1. **入口・出口の既存レールとの接続**: 支柱下面は共通の受け形状だが、ガイドレール・トンネル出口・ボール受けは未設計。今の5部品のみではボールコースとして完成しない。
2. **180°で確実に止まる機構**: 反転した時点で球は排出できる想定だが、惰性による回り過ぎを抑えるラッチ／デテントがない。球が次のカゴへ入れる位置に自動停止する保証もない。
3. **排出時の引っ掛かり**: 筒の内径・外周リングの静的干渉は確認しているが、摩擦、ボール反発、転がり方は未検証。
4. **軸の抜け止め・印刷姿勢**: シャフトは片頭のみ。簡単に外れる側の固定と、外周カバーの造形サポートを要検討。
5. **実機試験と安全**: 初期版は大人の検証専用。小児に渡さない。形状合格は運動成立の証明ではない。

## 検証範囲

CadQuery形状の単一ソリッド性、15°刻みのローター対カバー静的クリアランス、軸穴、24.26 mm球の筒内適合、出口窓の開閉を確認。**動力学・摩擦・物理動作は未検証**。原型の改善ではなく、新しい GW02 系として独立に開発する。

次版では、既存DUPLOレール床レベルに合う上下ガイド、180°停止機構、球保持・排出の動的実験を優先する。
