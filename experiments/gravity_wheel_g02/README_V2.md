# GW02-V2 — カバーなし・180°反転カゴ＋付け替え式ストッパー

手描き図と追加提案から生まれた **GW02の新方式**。PR #76 / GW01とは別方式。V1の`design.py`は履歴保存し、V2は`open_cup_v2.py`で独立実装。**固定外周カバーは完全撤去**。

## 球の動作仮説

1. 上段・右側から直径24.26mmの球をカゴの開放端へ入れる。回転軸はY方向で、上側のカゴの中心は軸から(X=+10,Z=+35)mm。
2. 重力トルクで回転。180°対向したもう一方のカゴは下から上に動く。径17mmの内向き観察スリットはボール径より小さく、外周側の受け壁は残るので、固定外周カバーなしでも球を保持する狙い。
3. ローター片側の突起が、後部支柱の取り外し式ストッパーピンに衝突して停止。その瞬間の慣性と、反転したカゴの10°下り傾斜で球を左下へ排出する狙い。
4. **手動リセット**で最初の待機位置へ戻して次球を投入する。自動復帰・連続運転は今回の対象外。

## 実装

- `rotor.stl`: 対向2カゴ・スポーク・一方だけの停止突起。内径27.30mm、外径32mm。入口は右上の開放端、180°後は左下向きに反転。
- `stand_front.stl`, `stand_back_stop.stl`: E31-05共通DUPLO下面受け付き。後部のみ**160°／170°／180°**のストップ穴（設定値はピンが最初に触れる名目回転角度）。穴の中心は接触角を補正してある。
- `axle.stl`: 直径4.9mmの頭付き軸。抜け止めはまだない。
- `stop_pin.stl`: 直径4.4mmのピン1個。後部支柱の希望する穴へ移して角度を比較。同時に複数の穴へ入れないこと。
- 軸高さ66mm、回転前後の球中心高度差70mm、名目カゴ半径約36mm。ボールのエネルギーはローターの回転・摩擦・衝撃損失に消費されるため**物理的に180°到達する保証はない**。

## 生成と検証

```bash
python -m unittest experiments.gravity_wheel_g02.test_open_cup_v2 -v
python -m experiments.gravity_wheel_g02.open_cup_v2 --out build/gravity-wheel-g02-v2
```

出力STL5点、非印刷用`assembly.step`、`report.json`。GitHub Actions `CAD preview and print artifacts` の`targets=experiments/gravity_wheel_g02`でも生成可能。

CADで検査: 5部品単一ソリッド、実STLメッシュ、軸径隙間、球適合、カゴvs支柱0〜180°静的干渉、3種のピン接触と早期衝突なし、固定カバー不在。**実球の挙動・カゴ内での摩擦・遠心保持・衝撃耐久は検証していない**。

## 初回印刷・評価（大人の試験専用）

1. スライサーで5部品の印刷姿勢、支柱の細長い形状・サポート・ピンの向き・カゴの筒内サポート残留を事前確認。無理なサポートが必要なら印刷しない。
2. 軸と支柱を固定し、回転抵抗・軸抜け・ピンのガタを確認する。ピンが保持されない場合は使用を中止する。
3. 最初は**160°位置**にピンを入れ、手で球を静かに投入。回転開始・途中落球・停止角・排出方向・反発の有無を各10回計測。
4. 同条件で170°・180°へピンを移し比較。**160°付近は最下点（約164°）に近く、180°よりトルク条件がよい可能性がある**。必ずしも180°の方が飛びやすいとは限らない。
5. 入口・出口レールはまだ未実装。周囲を囲った試験環境で落球を受け、飛散する可能性に備える。既存レールへの受け渡しは次版で設計。

**安全**: 直径24.26mm球、抜け得る軸、小さな脱着ピン、PLA衝撃部品がある。幼児には渡さず、保護者の監督下でも成人による設計試験に限定。固定カバーをなくした分、球が途中で落ちる可能性も増える。
