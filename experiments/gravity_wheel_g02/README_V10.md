# GW02-V10 — 1枚のSTLで全パーツを印刷

## 解決した問題
V6では、ローターのカゴを平置きしても、ストッパー突起が印刷面から12mm上で開始し、サポートOFFのままだと空中造形になっていた。V7ではカゴとハブの連続補強を追加したが、停止突起が途中から始まる問題は残っていた。

V8は**前後ローター半割、共通受けの支柱、軸、ストッパーピン、位置決めピン4本の計10部品を、ひとつの print_plate.stl に並べる。**接着一体化したSTLではないので、印刷後は個別に取り外せる。

- A1 mini 180×180mmの範囲に収まる設計配置。
- V7の前後半割構造・補強リブを継続。
- 片側ローターの停止突起の下に**印刷専用の折り取り仮支柱**を追加。径5mmの柱に細い径2.3mmの首を設け、印刷後に取り外す。
- **前後各ローターのカゴ内部に4本ずつ、折り取り式の細い印刷支柱**を追加。長い空中ブリッジを支える。
- この仮支柱は回転機構には含まれず、assembly.stepには入れない。
- 主ファイルは print_plate.stl。従来の個別STLは補助的な出力として残す。

## 印刷・組み立て
1. Bambu Studioで **print_plate.stl を1ファイルだけ** 読み込む。自動整列・回転をかけない（すでにプレートへ配置済み）。
2. サポートOFFでも構造的に浮かないよう設計したが、実際のレイヤープレビュー、オーバーハング、ブリッジを必ず確認する。実機でのスライス成功は未検証。
3. **前後ローターの各4本の仮支柱と、ストッパー直下の1本をすべて折り取る。** バリも取り除き、24.26mm球が両カゴを通れることを確認する。
4. 位置決めピン4個で半割ローターを組む。4ピンの保持力が弱ければ回転させない。軸の抜け止めも未設計。
5. 160°ストッパーから囲い付きで成人のみ実験する。

## 重要な制限
実球の重力回転、衝突放出、遠心保持、球のすり抜け、ピンの破損は未検証。
メッシュの水密性やCADチェックはBambu Studioのスライス合格を保証しない。
小さなピンがあるため子どもには渡さないこと。

## V9 G-codeの解析とV10での修正で見つかった問題と修正（2026-11-23）

実際の `GW02-V10-print_plate_PLA_2h35m.gcode` を解析。サポートOFFで、
ローター後半体の **Z=11.2 mm** に約 **19.7 mm** の支持されない造形を確認した。
これはストッパーではなく、V4由来の側面補強リブが印刷高さ11 mmで突然始まる一方、
基礎となるスポークは高さ8 mmで終わっていたため。

**修正**：前後両側・上下両方の補強リブを、分割面（Y=0）から外面（|Y|=18 mm）まで
連続した断面として構築し、ボール通路とはブーリアン差分を維持。
既存のスタッド、受け、カゴの基本径、停止突起と取り外し支柱、10部品1枚STLは維持。

**回帰確認**：スポーク→補強リブの境界にあたる高さ8.1–17 mmで、
カゴ2か所・前後両面の材料連続性をテストする。

**未検証**：この修正後にBambu Studioで再スライスしたG-codeは未取得。
STLはメッシュ検証に加えて再スライスでブリッジを確認する。

### 補記：屋根を支える印刷専用仮支柱

補強リブ連続化だけでは高さ11.2mmの未支持箇所が残ったため、前後のローター半体それぞれ4本の仮支柱を追加。Bambu Studio旧G-codeとCAD断面から、旧設計では最大約19.7mmの未支持距離があった。補強リブ＋仮支柱配置のCAD断面上では、同じ高さの直下層からの水平距離を約5.2mm以下に抑える配置を検討した（実スライサー上の再計測は未完了）。支柱は印刷前から一体化されるが、完成品から取り外す必要があり、組み立てSTEPには含めない。
