# SG01-V4 — 急落下 × 緩左カーブトンネル（4×4×高さ3）

[Issue #37](https://github.com/KKawamura1/3d-printer/issues/37) の左回り試作。入口は西高、出口は曲線の低側、総落差19.2mm。緩カーブの中心線はR48、球径24.26mmを想定。

## V3〜V4の修正理由
- V2では「高入口の通路」「低出口の通路」だけを切り抜き、設計上用意した**縦落下室の円筒と円錐屋根を切り抜いていなかった**。そのため入口と出口の連続球通過テストが失敗。
- V3で高入口通路・低出口通路・円筒落下室・円錐屋根の**和集合を一度に切り抜く**よう修正。
- V3で凹刻印切削の検証が失敗したため、V4では凹刻印を下面受け部に近いZ5.55mmから**西側の入口壁Z12mm**に移動し、文字サイズ2.0mm、深さ0.45mmに変更。刻印の成立性もCADテストで検証する。
- 通路の折れ線を連続カプセル掃引で検査し、単に入口・出口を球が通るだけでは合格にしない。球が意図した通路を通れることは必要条件だが、自然に転がり出ることの保証ではない。

## 仕様と未確認事項
- 16mmスタッドピッチ、4×4の設置面、高さ3段（本体57.6mm、スタッド先端62.1mm）、落差19.2mm。元のV2 READMEに記載された「高さ19.2mm」は誤記。
- 外周は曲線形状に切り、完全な下面チューブにE31-05を適用。屋根付き、上面スタッド付き、下面の非走行面へ凹刻印 `SG01-V4`。
- 物理的な球の衝突・自然転がり、Bambu Studio A1 miniでのサポートなしスライス、下面保持力、子どもによる着脱は**未検証**。モデルを修正しても実機検証を省略しない。
- 特に急落下から緩カーブへ入る区間は、通過可能でも速度が不足したり衝突で停止したりする恐れがある。

## 生成と検証
```sh
python -m unittest parts.steep_gentle_tunnel_left.test -v
python -m parts.steep_gentle_tunnel_left.design --out build/steep_gentle_tunnel_left
```

GitHub Actionsの対象限定生成で `cad-verified-stl` Artifact（STL/STEP/CAD検証レポート）を出力する。検証失敗時のArtifactを印刷に使わない。
