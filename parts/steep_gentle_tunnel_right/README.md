## V3：落下室の切削漏れを修正

- V2では円筒・円錐の落下室切削体を作っていたが、本体から減算していなかった。このためCADの連続球通過検証で失敗した。
- 高入口・低出口の通路を切削した後、落下室の円筒・円錐屋根を**個別に切削**する。円筒の底面は低い走路床より0.5mm下に置き、落下球の下半分も通るようにする。
- 連続球掃引の厳密判定は維持する。CAD合格後も自然転がり、スライス、実物は別途確認する。

## V4：緩カーブへの出口坂を滑らかに

- V3の切削漏れを直しただけでは、同系統の左回りモデルのCIで下り坂終端に球と床の干渉が残った。
- 高さ9.75mmの誘導坂を12〜32mm区間に配置し、始端・終端それぞれ4mmをなめらかにつなぐ。最大勾配は約31°で、高入口から低出口への総落差19.2mmは維持。
- 傾斜中の球の掃引断面に必要な幅を確保するため通路の最大半径を14.0mmから14.7mmに変更。これにより側壁の公称余裕が減るため、スライサー上の肉厚と実物の走行試験が必要。
- 連続掃引によるCADの衝突検査は維持し、検査が不合格のSTLを実用品と扱わない。

- 西側壁の凹刻印を Z12 mm・2.0 mm文字に変更する（従来の Z5.55 mm・1.1 mm文字より読みやすくし、受けの接触範囲を避ける）。
