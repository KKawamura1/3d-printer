# SB01-V1 — 手動左右分岐スタートボックス（試作）

上からボールを置き、前面の大きなレバーを左右に倒すことで進行方向を選ぶ、4×4×高さ3ブロック相当のスタートパーツです。**現物印刷・動作・安全性は未検証**です。

- 両側面に出口。中心のランニング床は 25.55 mm、左右の出口床は 6.35 mm（落差19.2 mm）。
- 固定のV字状の下り床と、レバーで約±20°傾ける中央の揺動板を組み合わせます。左右端付近の薄い壁ストッパーが倒れすぎを制限します。
- 下面は既存の **E31-05／浅い4.75 mm受け**（13.20 mm中央チューブ、PR58のZ3.50 mmスリット）です。上面は入口を開けたため、スタッドは外周の8個だけです。
- 出口のランニング床の位置と向きは既存のレールに合わせますが、V1出口は**矩形の開口**であり、円弧断面への遷移および転がり速度は実物検証が必要です。
- 上面は**大きな開口**です。中央の揺動板の上にボールを入れてください。固定された小さな投入穴／自動供給ホッパーは付けていません。

## 生成物と印刷向き

| ファイル | 内容 | 印刷向き |
|---|---|---|
| `brick.stl` | 本体、上から嵌める軸受け溝、左右ストッパー | そのまま（受け面を下） |
| `lid.stl` | 軸受け溝を塞ぐ穴あき蓋、差込ペグ4本 | **裏返した印刷向きで出力済み**。ペグを上向きにして印刷 |
| `lever.stl` | 揺動板・一体成形軸・手前の操作グリップ | 平坦な面を下。軸下面にも印刷平面あり |

STLはそれぞれ独立した部品で、スライサーに3ファイルを読み込んでください。`report.json` にはCAD／メッシュ検証と「実機未検証」フラグを記録します。

## 組み立て

1. 本体中央の縦長スロットに、レバーの軸を上から下ろします。操作グリップは本体の手前（マイナスY側）に向けます。
2. 蓋を印刷向きから裏返し、8個のスタッドを蓋の穴に通します。4本のペグを本体上面の穴に挿入して、軸が上に抜けないようにします。
3. レバーを左右に倒して動くこと、倒れすぎないことを確認します。中央の揺動板を狙ってボールを投入します。

## 印刷後に必ず確認すること

- Bambu Studioで各部品がサポートOFFで成立するか、特に本体の受け面・小さな壁ストッパー・蓋の穴のブリッジを確認する。
- 左右それぞれ10球以上を試し、ボールが引っかからないか、隣のレールへ滑らかにつながるかを確認する。
- レバーの操作力、±約20°の機械ストッパー、軸の脱落防止、蓋とペグの嵌合・抜けにくさ、繰り返し操作後の磨耗を確かめる。**スナップ式の位置決め機構はV1にはありません**。
- 蓋の保持が弱い場合、そのまま子どもに渡さない。大人が固定方法を見直す。小さな破損片・バリがないかも確認する。

CADの球干渉サンプルは剛体位置の抜き取り検査で、揺動板から出口床への跳ねや滑走を保証しません。採用前の試作品として扱ってください。

```sh
python -m unittest parts.switch_start_box.test -v
python -m parts.switch_start_box.design --out build/switch-start-box
```
