# 水平レール試作01・丸角2×2試作02

2026-10-24の通常高さ2×2の実物評価「突起がきつい・裏面が緩い・CADの直角が痛い」を反映。初回品と測定データは残し、名目profileは変更しない。

## 印刷するファイル

- `parts/straight_rail/model.stl`：水平直線レール。63.8 × 31.65 × 19.13 mm。
- `experiments/fit_trial_02/model.stl`：丸角2×2。31.8 × 31.8 × 19.2 mm、突起込み23.7 mm。
- `prints/duplo_rail_trial_01.zip`：上記のSTLを分かりやすいファイル名で同梱。

Bambu StudioでSTLをmm・100%で読み込み、レールの溝／ブロックの突起を上にして置く。既存のプリンター・ノズル・材料profileを使う。スライス後、裏面の高さ4.75 mmの空洞天井（レール）や通常ブロックの天井のブリッジを確認する。外周4周程度・積層0.2 mmを初回候補とし、サポートは接続空洞に残ると嵌合を妨げるのでプレビューで確認。印刷指示やG-codeは生成していない。

レールには上面突起を付けない。裏面は通常ブロックと共通の`receiver()`を使用し、X/Yの16 mmピッチを維持。レールの実測外幅に合わせて側壁厚を3.085 mmへ調整し、横方向の内壁位置を従来と同じに保つ。底面のチューブは3本。レール同士は共通の下ブロックで支持して端面を並べる方式で、未測定の専用ラッチは作らない。

## 検証と限界

CADの妥当性・単一実体、寸法、STL閉殻・面方向・体積、STEP再読み込みを検査。角丸の球面極でSTLのfloat32座標が完全一致する三角形だけを除去し、結果を同じメッシュ検査へ通す。形状の平滑化や寸法変更は行わない。

ボール径24.26 mmは参考値。球の中心を溝底+半径+0.05 mmに置き、端を含む13位置で交差なしを検査。径28 mmの球が干渉する負例もテストする。転がり・摩擦・既存レールとの継ぎ目は未検証。水平なので単独で静止球が進み続けるわけではなく、上流からの勢いが必要。

**13.30 mmチューブは名目9.40 mm突起に半径方向約0.0363 mmの剛体干渉を持つ。** これは保持を強くする物理試作値。`fit_geometrically_clear=false`と接触体積をそのまま出力し、形状検査PASSを無干渉／保持力保証とは扱わない。合成基準は純正スキャンではない。`physical_fit_validated=false`。

印刷後は①手で触って角の痛さ、②純正ブロックへの着脱と保持、③既存レールとの溝底の高さ、④両方向にボールを転がして継ぎ目で引っかかるかを確認する。きつくて外せない場合は押し込まず、チューブ径を次の改訂で戻す。

## 再生成

```sh
python -m parts.straight_rail.design --out build/duplo-rail-trial-01
python -m parts.straight_rail.design --kind brick --out build/duplo-fit-trial-02
python -m unittest discover -s tests -v
python -m brickcad all
BRICK_CHROMIUM_PACKAGE="$PWD/build/browser-package/node_modules/@sparticuz/chromium/build/index.js" npm run browser:check -- build/duplo-rail-trial-01 build/rail-browser
```

レールはパラメータ`Rail`、接続調整は`fit_profile()`、丸角通常ブロックは`rounded_brick()`。任意長・坂・カーブは未対応。従来のCLI/profileと通常レゴは維持。
