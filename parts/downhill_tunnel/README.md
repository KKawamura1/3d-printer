# D01-V1 覗き窓付き下り坂トンネル

DUPLO 2×4ポッチ、高さ3段（本体 63.8×31.8×57.6 mm、スタッド込み62.1 mm）。
西側の入口から東側の出口へ、**通路の床が正確に19.2 mm（1段）下がる**直線坂。

- ポート床：高側 Z=25.55 mm、低側 Z=6.35 mm。隣接する水平ボールレールは入口側だけDUPLOで1段高く設置。
- 入口の見た目は既存T01-V4に準拠する丸穴。内部は半径最大14.0 mmへ拡張し、上部に印刷しやすい涙滴形の屋根を設ける。
- **覗き窓は手前の長辺に3個**。位置X=-16/0/+16 mm、各幅8mm。坂の高さに合わせて上下をずらした五角形（45°に近い山型上端）。
- それぞれの窓の下に床から7mm分の側壁を残す。球径24.26mmより窓幅を狭くし、球がそのまま飛び出せない設計。窓と切断縁の安全性は実物で評価する。
- 共通嵌合は E31-05：上面OD9.40mm/ID6.40mm、下面チューブOD13.20mm＋R0.20ビード＋4スリット。3段高形状への移植のため、実物嵌合は未検証。
- 長辺の窓より下に **D01-V1** を深さ0.4mmで凹刻印。既存の水平トンネルと別の継続パーツ。
- 下面は浅い受け（4.75 mm）。床の最薄部は1.60 mm、天井最薄部は名目1.75 mm以上（曲面・積層・刻印等の実物公差は別）。


`cad-verified-stl` Artifact の `parts/downhill_tunnel/D01-V1/brick.stl` を取得します。

## 造形と実物検証（残作業）

1. Bambu Studio・PLA Basic・0.20mm積層で、スタッド上向き、サポートOFFの初期条件からスライスする。**窓の上端、通路の山型天井、下面チューブの4スリット、スタッド内壁とブリッジを積層プレビューで確認**。サポートなしで成功するとは未確認。
2. 各窓の奥のバリ、鋭い角、白化・割れ・脱落小片、球に触れる箇所を大人が確認する。
3. 入口に1段高い水平レールを接続して、低速・高速で球の詰まりと窓からの脱落を確認。球が跳ねても窓から出ないか試す。
4. 純正凸→印刷凹、印刷凸→純正凹、印刷凸→印刷凹の着脱感・保持・繰返し劣化を別々に評価する。

CADの33位置の球体干渉なしは**有限サンプリング**で、連続掃引、物理転がり、窓からの脱落、印刷成功、子ども向け玩具としての安全性を保証しない。窓や小さな球は乳幼児の誤飲・指挟みなどに注意し、成人管理下で扱う。
