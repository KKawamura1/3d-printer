# S02-V7 — 急カーブ × 急落下トンネル（2×2×高さ3）

PR #36（C01-V5）の **西から進入→南へ退出する右90°の接続方向** と、PR #38（S01-V5）の **密閉落下室・約33°の出口坂** を組み合わせた複合試作です。

- **入口**：西・上段、床 Z25.55mm
- **出口**：南・下段、床 Z6.35mm。全体の落差19.2mm
- **サイズ**：31.8×31.8×57.6mm（上面4スタッド込み高さ62.1mm）
- **走路**：屋根付き垂直落下室から、勾配0.65（約33.0°）の南向き急坂を経て水平3mmの出口へ。落下室中央から坂終端までの落差 **8.45mm**
- **出入口の整合**：既存の円形口径とポート位置を維持
- **嵌合**：E31-05下面受け、4スリット＋ビード／上面4スタッド
- **刻印**：S02-V7

## PR36との関係

C01-V5の上面スタッドが0個になっても、このパーツは **天井付きのため4スタッドを残します**。急カーブ方向は継承しますが、2×2内に完全な水平R16円弧と垂直落下穴を重ねると不要な開口が生じるため、下段は直線的な南向き下り出口です。**完全なR16カーブではありません**。

## PR38との関係

S01-V5で導入された33°の下り坂、斜めボアによる球の頭上クリアランス、入口床を侵さない最大勾配の制約を反映しました。S01-V5は落下室がX=-2mmで東向き走路が15mmですが、このS02は中央の落下室から南向きに13mmのため、坂部分の落差は **9.75mmではなく8.45mm** です。

## 生成・検証

```sh
python -m parts.steep_sharp_curve_tunnel.design --out build/s02
python -m unittest parts.steep_sharp_curve_tunnel.test -v
```

`cad-build.json` はC01-V5・S01-V5に固定し、新版のSTLだけGitHub Actionsの `cad-verified-stl` Artifactへ出力します。STLはGitへcommitしません。
