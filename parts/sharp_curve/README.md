# C01-V6 急カーブ（右90°、2×2×高さ1）

- **外形**：31.8 × 31.8 mm／デュプロ高さ1段19.2 mm（上面スタッドなし・最大高さ19.2 mm）。
- **コース**：西から進入し南へ退出する**右90°**。ボール中心線R16 mm。
- **ボール**：直径24.26 mm、従来の水平レールと同じ床6.35 mm・円形断面半径約12.87 mm。
- **構造**：上面が開いたレール。球が通るので、上面スタッド4つをすべて省く（上にはブロックを接続しない構造）。下面はE31-05候補（中央チューブ外径13.20 mm、ビードR0.20、4スリット）。
- **刻印**：非走行面の北側面に `C01-V6`。

トンネル化は別設計（2×2×高さ2）として扱う。この高さ1段版に屋根を付けるとボール通過高さが不足する。

## 作成・検証

```sh
python -m parts.sharp_curve.design --out build/sharp-curve
python -m unittest parts.sharp_curve.test -v
```

`cad-build.json` の版を更新した時だけ push でGitHub ActionsがSTLを自動生成し、`cad-verified-stl` Artifactに出力する。STLをgitに含めない。

**実機履歴と最新版の区別：** 旧C01-V5は実物良好（#42、#60）。現行C01-V6は走路・スタッドなし構造を変えず、E31スリット短縮（#58 B条件）と北外壁の共通刻印（DejaVu Sans Bold、3.0 mm、深さ0.4 mm）を採用した版。CAD成功後も新しい版の床面・嵌合・刻印可読性・転がりは未確認。

**注意：** R16は強い曲率で、CAD上で24.26 mmの球が通ることと、実際に勢いを失わず曲がれることは別。最新版のサポートOFFスライス・複数回の挿抜・球の10回転がりは別途検証する。
