# SB02-V1 — 4×2×2 パッシブ左右分岐スタートボックス

レバーを使わず、上面中央の丸穴からボールを入れるだけで、左右のどちらかに転がる **1パーツ構造**。中央の山形リッジで左右へ分岐するので、投入時のわずかな位置ずれで行き先が変わる（確率的ランダムを保証する機構ではありません）。PR #71 のレバー式SB01とは独立した代替試作です。

## 仕様と配置

- **4×2スタッド、高さ2段**（外形63.8×31.8×38.4mm、突起込み高さ42.9mm）。
- 上面 **壁1／穴2／壁1**：中央に **直径25.74mmの真円投入口**。`BALL_TRACK.opening` と同じ値です。穴の両端に2スタッド列ずつ、合計4個のスタッドを残します。
- 下部 **左右のレール／中央リッジ／左右のレール**：手前から見て左／右に独立した円断面通路。中央リッジは尖り気味の山（平坦な着地面を置かない）。
- 左右の出口は **床高さ6.35mm、断面半径 `BALL_TRACK.radius` ≒12.87mm** で、既存レールのポートと整合。側面の円形出口は開放されています。
- 中央床の高さ14.0mm → 出口6.35mm、左右それぞれ **7.65mmの下り**。4×2×2に収めるため、先行レバー式の落差19.2mmは引き継ぎません。二段高の屋根とボール径を優先したトレードオフです。
- 底面は **E31-05（浅い受け4.75mm、チューブOD13.20mm、PR58 B スリット終端Z3.50mm）**。共通生成器を利用。
- 既存の `brickcad.marking.engrave` で外側面に `SB02-V1` の凹刻印。

### 投入口のクリアランスについて

基準ボールは直径24.26mm、丸穴は25.74mmなので、**直径の差は1.48mm、中心を横へ寄せられる量は理論上わずか0.74mm**（剛体／誤差なしの場合）。ここを広げると既存レール穴とは異なるため、初版では同寸を優先しています。実印刷の縮み、バリで入れづらい可能性があるので、穴径は実測して評価してください。

## 生成・印刷

```bash
python -m unittest parts.passive_split_box.test -v
python -m parts.passive_split_box.design --out build/passive-split-box
```

`brick.stl` / `brick.step` / `report.json` を出力します。STLは単体でZ=0底面をベッドに置く向き。以前のPR同様、配布STLはGitHub Actionsの `cad-verified-stl` Artifact（14日保持）から取得し、STLをGitへコミットしません。

**注意：**中央の円形穴と左右の横穴は内部でつながりますが、トンネルの上部は円弧なので、Bambu Studio / A1 mini のサポートOFFスライス、ブリッジ長、積層時の天井の垂れは実物未確認です。球通路の幾何干渉がなくても、速度・摩擦・重心や印刷バリによる停止は排除できません。

## 物理的な検証項目

1. 直径24.26mm程度のボールが上穴から引っかからず入るか。
2. 中央・少し左・少し右に投入し、それぞれ左右への分岐を各10回程度確認（偏りは記録）。
3. 左右出口が既存レールへスムーズにつながり、境目で停止・跳ね返りがないか。
4. サポートOFFで内部の上側アーチが崩れないか、糸引き・バリがないか。
5. 純正凸×印刷凹、印刷凸×純正凹、印刷同士の挿抜・保持、特に4×2大型嵌合が硬すぎないか。

**CAD検証は実機での安全性の証明ではありません。** 印刷物を幼児へ渡す前に大人がバリ・破損片・嵌合・強度を確認してください。
