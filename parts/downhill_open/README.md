# D02-V4 — 直線・緩坂・開放レール

Issue #37 の直線2×4・落差1段（19.2mm）のレール。Issue #60 の横断標準を適用する。

- 16mmピッチ、ボール径24.26mm、落差19.2mm。
- 開放型のため天井・スタッド・高い側壁は不要。片側のみで左右の別形状はない。
- **下面支持:** 外形で支持部を切断し、完全チューブに限ってE31-05のビード・4分割スリットを付ける。#58のB条件を採用し、スリット終端中心Z3.50mm＋R0.65mm＝上端4.15mmとして、下面天井Z4.75mmとの間に0.60mmを残す。補強リブなし。
- **刻印:** 完成後の可視外壁（-Y側面、X=-16mm、Z=12mm）に最後に凹刻印。共有 `brickcad.marking.engrave()` の既定値、DejaVu Sans Bold／文字高3.0mm／深さ0.4mm。入口の接続面に埋もれない位置。
- **CAD検証:** 連続球掃引、走路床支持、STL閉鎖性、STEP往復、標準文字の実切削、短縮スリット上部の床保持をチェックする。球掃引は静的な通過可能性であり、重力による自然転がりの証明ではない。
- **未検証:** 最新D02-V4のBambu StudioサポートOFFスライス、実機の床面・刻印可読性・転がり・次レール接続・純正／印刷同士の嵌合・耐久。#58の小型試験片Bが良好でも、この大型形状の実物合格を意味しない。

生成: `python -m parts.downhill_open.design --out build/downhill_open`。
Actionsの `cad-verified-stl` ArtifactにSTL/STEP/検証レポートを保存する。Artifactに付属する `report.json` の版番号とSTL SHA256を必ず照合する。
