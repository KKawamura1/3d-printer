# GC01-V5 — 水平・緩カーブ・開放レール

Issue #37の水平R48・90°カーブ（4×4×高さ1）。Issue #60の横断標準を反映したCAD候補。

- 16mmピッチ、名目高さ19.2mm、球径24.26mm、落差0mm。
- 天井なしの開放レール。上面にスタッドや高い衝突ガードを増設しない。
- 下面の完全チューブのみE31-05ビード／4分割スリット。**スリット終端中心Z3.50mm**（#58条件B・#59）、補強リブなし。輪郭で切れた部分チューブは支持に使い、E31加工は適用しない。
- **標準凹刻印**: `brickcad.marking.engrave_west()`の既定値（DejaVu Sans Bold、文字高3.0mm、深さ0.4mm）。入口側の可視西外壁、走路床より下のZ5.10mmに、全形状の構築後に切削する。テストでは文字カッター全体の収まりと実際の除去体積を検証する。
- 入口／出口を入れ替えて置くことで右・左を共用する形状。**逆方向の実機転がりは未検証**であり、独立した左右別STLは現時点で作らない。
- CADレポートの「連続球通過」は折れ線経路の球掃引であり、自然転がりを保証しない。

## 版履歴

- GC01-V3: 連続掃引、オーバーサイズ球干渉と走行床支持のCAD検証。
- GC01-V4: #58の2×2床面試験を根拠にE31下面スリット終端をZ4.40→3.50mmに短縮。
- **GC01-V5**: #60の3.0mm／0.4mm標準刻印に統一し、切削・文字全体の収まり・版番号の回帰テストを追加。走路形状はV4から変更しない。

## 生成・検証

`python -m parts.gentle_curve_open.design --out build/gentle_curve_open`。GitHub Actionsの `cad-verified-stl` にSTL/STEP/検証レポートを保存する。**GC01-V5の新しい成功Artifactの有無はActionsで確認すること**。以前のV3/V4の成功記録では代用しない。

**未検証**：Bambu StudioサポートOFFでのスライス、実物の床面、刻印可読性、左右両方向の転がり各10回、純正・印刷品との嵌合／繰り返し着脱。CAD合格は実機合格ではない。
