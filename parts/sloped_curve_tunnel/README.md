# SC02-V4 — 緩い坂 × 緩い右カーブ × トンネル

[Issue #37](https://github.com/KKawamura1/3d-printer/issues/37) の M31-05 に対応。4×4、R48、右90°、西の高入口から北の低出口へ19.2 mm下降。

## V4: 端を切った接続部と水平な上面
- **上面は水平な高さ57.6 mm（DUPLO 3段）**。入口の球が通る空間のため、通常の2段=38.4 mmでは成立しない。スタッドは4×4位置に生成し、カーブ輪郭で端を切る。中空スタッドが残るのは10位置（残り6位置は輪郭外）。テストは中心の空洞ではなくスタッドの円筒壁を確認。
- **下面**は完全な3本の保持チューブに加え、曲線輪郭で切った4本の部分チューブを復活。残る2本は不要な領域か、極薄の切れ端なので生成しない。
- 以前のS01-V1の教訓に従い、切断チューブの縦角へのR0.70は追加しない（Bambu Studioの「浮動片持ち梁」警告につながった処理）。部分チューブは直線的に切っており、スライス時の実確認が必要。
- E31-05の保持ビード・4スリットは**完全な3本のみに適用**。切断チューブにはビードを追加しない。
- 走行面はS01-V2由来。高い円形入口から内部は涙滴形に移行するトンネル。上面のスタッドも切断されるため、嵌合・保持の実物確認が必要。
- 上面高さ変更後の凹刻印は SC02-V4。

実行: `python -m parts.sloped_curve_tunnel.design --out build/sloped_curve_tunnel`

テスト: `python -m unittest parts.sloped_curve_tunnel.test -v`

STL/STEP/プレビューは push 時の GitHub Actions で差分生成。成果物は `cad-verified-stl` Artifacts から取得。
