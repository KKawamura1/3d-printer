# SC02-V11 — 緩い坂 × 緩い右カーブ × トンネル

[Issue #37](https://github.com/KKawamura1/3d-printer/issues/37) の M31-05 に対応。4×4、R48、右90°、西の高入口から北の低出口へ19.2 mm下降。

## V5: 凹刻印の復旧（V4の形状を継承）
- **上面は水平な高さ57.6 mm（DUPLO 3段）**。入口の球が通る空間のため、通常の2段=38.4 mmでは成立しない。スタッドは4×4位置に生成し、カーブ輪郭で端を切る。中空スタッドが残るのは10位置（残り6位置は輪郭外）。テストは中心の空洞ではなくスタッドの円筒壁を確認。
- **下面**は完全な3本の保持チューブに加え、曲線輪郭で切った4本の部分チューブを復活。残る2本は不要な領域か、極薄の切れ端なので生成しない。
- 以前のS01-V1の教訓に従い、切断チューブの縦角へのR0.70は追加しない（Bambu Studioの「浮動片持ち梁」警告につながった処理）。部分チューブは直線的に切っており、スライス時の実確認が必要。
- E31-05の保持ビード・4スリットは**完全な3本のみに適用**。切断チューブにはビードを追加しない。
- 走行面はS01-V2由来。高い円形入口から内部は涙滴形に移行するトンネル。上面のスタッドも切断されるため、嵌合・保持の実物確認が必要。
- 刻印 `SC02-V11` は西側の外壁（高入口より下、z=12mm）に深さ0.4mmで刻む。開放レールに先に刻印すると後から重ねるトンネル外壁で埋まるため、外壁・受け・スタッドの合成をすべて終えた最後に刻印する。STL/STEP上で文字の切削空間が残ることを回帰テストで確認する。

実行: `python -m parts.sloped_curve_tunnel.design --out build/sloped_curve_tunnel`

テスト: `python -m unittest parts.sloped_curve_tunnel.test -v`

STL/STEP/プレビューは push 時の GitHub Actions で差分生成。成果物は `cad-verified-stl` Artifacts から取得。

**未検証**：Bambu Studio (A1 mini、0.20mm積層、サポートOFF) の浮動片持ち梁、天井ブリッジ、接続部着脱、落下・右カーブ通過、物理的安全性。CAD球サンプルは転がり保証ではない。


## PR58 改善適用（SC02-V11）

E31-05下面のスリット終端中心をZ4.40→Z3.50mm（R0.65mmを維持し上端Z4.15mm）。PR58 B試験片では床面合格・嵌合感に違和感なし。補強リブは追加せず、走路・刻印の位置を維持。今回の複雑なパーツの実印刷・保持力・耐久は未検証。

## Issue #60 適合（SC02-V11 / SC02L-V5）

- 共有の無刻印R48右走路＋トンネル・切断スタッド／切断下面支持を作り、左版はXZ面で鏡面反転してから独立した可読刻印 `SC02L-V5` を西面に入れる。右版は `SC02-V11`。左右とも**このPR #40**で生成する。
- 刻印は全CAD合成後にDejaVu Sans Bold／3.0mm／深さ0.4mm。素の壁の切削量と完成体内の残留文字カッター体積を比較する回帰テスト付き。
- 入口・出口それぞれの16方向の円形クリアランス／円形縁と、E31-05スリット端Z=3.50mm・R0.65mm（天井まで0.60mm）の検証を追加。
- 既存SC02-V5の実機評価は版不明の旧品。新右V7／左V1はCADの評価と印刷評価を分ける。A1 miniサポートOFFでの床面・天井・スタッドと印刷保持力、ボール10回通過、口の見栄え、刻印可読性は未検証。

## STEP往復検証の数値許容範囲（SC02-V11）

PR #61の`brickcad.verify.precise_volume()`を使用してSTEP再読込後の体積を適応積分で比較する。許容閾値はmainのPR61と同じ**体積差の絶対値1e-4mm³未満**（緩和しない）。加えて**有効な単一ソリッド**および**外形寸法差0.02mm未満**を必須とする。以前左版で観測された3.20e-6の差は通常のOCC体積積分の数値誤差であり、PR61の共通高精度計算で対処する。形状・スリット・走路の変更ではない。実印刷は未検証。

### SC02-V11のSTL再生成

前バージョンのSTL成果物とCADソース指紋の食い違いを避けるため、識別子を更新して再生成。STEP往復はPR61標準の適応積分による絶対誤差（1e-4mm³未満）を使い、閉鎖STL・有効な単一ソリッド・外形寸法の回帰検査を維持する。
