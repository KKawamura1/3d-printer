# C02-V7 2×2×高さ2 急カーブトンネル（右90°）

## 2026-11-01 実物結果

- **C02-V2**：当初、球が内部で停止。ただし内部の**造形バリを除去した後はスムーズに転がった**。バリが原因だった可能性が高いが、10回連続試験や再印刷での再現は未確認。
- **C02-V4**：通過自体は可能だが、転がすと拡張した箱状の転回室に安定して止まり、横出口から出ない。現物NG。
- **C02R-V1**：通過し横に出るが、奥に衝突して勢いがほぼ失われる。現物NG。
- **C01-V5（開放）**：実物良好。変更しない。

## V5でV2形状へ復元（履歴）

[元のC02-V2の設計](https://github.com/KKawamura1/3d-printer/blob/230efc253ab6528e12665d0a89e1f706bb4d2494/parts/sharp_curve_tunnel/design.py) を復元し、上面4スタッド、E31-05受け、円形の西入口→南出口、R16の連続案内溝、中央の既存天井ドームを維持。広い水平床の転回室も、追加の大きな球面逃げも**設けない**。北側面の刻印のみ C02-V5 へ変更。C01のカーブ切削形状はV2当時と同一で、現行C01-V5に依存する。

V4で空洞化された中央側壁2点がV5では固体のまま、というCAD回帰テストを追加。ボールを単に通す空間ではなく、出口方向への案内を保護するためのテスト。

## 印刷後の検証

印刷品の内側のブリッジ、垂れ、糸引き、バリを大人が確認し、尖った箇所・脱落し得る破片を安全に除去。V2の改善はこの作業後に観察されており、必ず同じ結果になる保証ではない。

新品のV5について、**バリ除去前後それぞれ10回**、同じ球・入口条件で、通過数、停止位置、出口勢いを比較する。バリ除去済みV2も対照にする。CADチェック合格だけでは実物動作の検証済みとは扱わない。

```sh
python -m parts.sharp_curve_tunnel.design --out build/sharp-curve-tunnel
python -m unittest parts.sharp_curve_tunnel.test -v
```

`cad-build.json` は現行 **C02-V7 / auto:true**（依存元 C01-V6）。Actionsの `cad-verified-stl` Artifact 内 `parts/sharp_curve_tunnel/C02-V7/brick.stl` が生成対象。生成成功とスライサーでの安全な造形を確認してから印刷する。STLはGitには格納しない。


## PR58 改善適用（C02-V6）

E31-05下面のスリット終端中心をZ4.40→Z3.50mm（R0.65mmを維持し上端Z4.15mm）。PR58 B試験片では床面合格・嵌合感に違和感なし。補強リブは追加せず、走路・刻印の位置を維持。今回の複雑なパーツの実印刷・保持力・耐久は未検証。

## Issue #60 横断診断（C02-V7）

- 走路はバリ除去後にスムーズに転がった旧V2のR16連続案内溝を**維持**。V4/C02Rの大きな転回室には戻さない。
- #58 B条件に従い、下面E31-05スリット終端Z3.50mm・R0.65mm、受け天井Z4.75mmまでの余裕0.60mm。補強リブなし。完全中央チューブのみE31加工。矩形2×2で下面チューブは切断されず、切断チューブの追加は不要。
- 4スタッドは屋根に支持された完全形状。開放型C01は設計どおりスタッドなし。輪郭切断支持は輪郭に実際に交差する形状で適用する。
- 右向きの**無刻印形状を反転して走路を確定し、屋根・スタッド形成後**に北外壁へ共有 `brickcad.marking.engrave()` の標準3.0mm / 0.4mm / DejaVu Sans Boldで刻印。別左版は現時点で不要（入口・出口逆向きの走行は別途確認）。
- CAD側は円形口の12方向、刻印の切削、下面スリットの余裕を回帰テスト。実機サポートOFFスライス・床面品質・文字可読性・10回転がり・純正/印刷相手の嵌合と耐久は**未確認**。旧C02-V5のGoodを最新版の合格と混同しない。
