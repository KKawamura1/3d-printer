# C02-V1 2×2×高さ2 急カーブトンネル（右90°）

PR36 の C01-V2 開放カーブと同じ西進入→南退出・中心線 R16mm。高さ2段（本体31.8×31.8×38.4mm／スタッド込み42.9mm）で天井を加えた独立パーツ。

- ボール径24.26mm、床6.35mm、トンネルの出入口は既存レールに合わせた**円形断面**（半径 BALL_TRACK.radius ≈ 12.87mm）。
- 入口と出口の開口を曲げた**円形トーラス通路**。この初版では高天井化の移行部を設けない。天井の最小厚さは約6.3mm。
- 高さ2段の屋根に **上面スタッド4個**をすべて残す。C01-V2の開放レールでは干渉のため3個を省いている。
- 下面はE31-05（中央チューブOD13.20mm、R0.20ビード、4スリット）を採用。試験片からの転用で実物嵌合は未確認。
- 北側面に `C02-V1` を刻印。
- C01-V2 の半径・球通路をそのまま使用するため、ソース依存先を `C01-V2` にピン留め。

## 生成・検査

```sh
python -m parts.sharp_curve_tunnel.design --out build/sharp-curve-tunnel
python -m unittest parts.sharp_curve_tunnel.test -v
```

`cad-build.json` は auto:true。pushするとこの新規バージョンが自動選択され、STLは GitHub Actions の `cad-verified-stl` Artifact に入る。リポジトリにはSTLをcommitしない。

**未検証**：R16の曲率で球が十分な勢いを維持するか／スライサーでサポートなし印刷できるか／E31-05保持力。幾何チェックは実物の転がりの証明ではない。
