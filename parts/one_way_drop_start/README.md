# SB03-V1 — 2×2×2 一方向・上面投入レール

**PR #72 の SB02-V1（4×2×2 左右分岐）とは独立して生成する、可動部のない1パーツ完結の試作品です。**

- **外形:** デュプロ 2×2スタッド、2段高（31.8×31.8×38.4 mm、スタッドなし）
- **投入口:** 天面中央の **真円 Ø25.74 mm**。既存レールの `BALL_TRACK.opening` と同一寸法。球の基準径は Ø24.26 mm
- **出口:** **東（+X）側に1口のみ**。既存レールと同じ円形断面（`BALL_TRACK.radius`）かつ床高 **Z=6.35 mm**。反対（西）側は閉じた壁
- **内部:** 中央下の受け床から東出口へ **0.15 mm/mm（約8.5°）** の一方向下り。ボールを上から落として勢いを得て転がす
- **下面:** E31-05（浅い4.75mm受け、チューブ径13.20mm、スリット終端Z3.50mm）。標準 `brickcad` と `parts.tunnel.e31_fit` を使用
- **上面スタッド:** ありません。2×2の全スタッド位置が中央の丸穴と重なるため、欠けた半端なスタッドは作らない設計です
- **刻印:** 側面 `SB03-V1`（標準3.0mm字、深さ0.4mm）

## 生成

```sh
python -m unittest parts.one_way_drop_start.test -v
python -m parts.one_way_drop_start.design --out build/one-way-drop-start
```

GitHub Actions は `parts/one_way_drop_start/cad-build.json` を自動認識して **SB03-V1** の `brick.stl` / `brick.step` / `report.json` / プレビューを生成します。既存 **SB02-V1** も同じ PR #72 の独立した別バージョンとして維持します。STLはGitにコミットせず、成功runの `cad-verified-stl` Artifactから取得してください。

## 重要な検証対象

1. Bambu Studio（A1 mini、PLA、サポートOFF）で円形天井のオーバーハング・上面丸穴の継ぎ目・下面の受けに印刷崩れがないか。**CADメッシュが閉じていてもサポート不要の保証ではありません**。
2. ボールを中心・中心から少しずらした位置から10回ずつ落として、**西壁側に跳ね返って停止しないこと**、東出口から毎回排出されること。
3. 既存レールに接続し、**段差・バリ・速度不足**がないこと。接続口は一致するが実物の受け渡しは未検証。
4. 純正×印刷と印刷×印刷の挿抜力を別々に検証。大型パーツのきつい嵌合結果を自動流用しない。
5. 印刷前後の欠け・鋭利なバリを成人が確認し、乳幼児の誤飲などの危険がないことを確認してください。

静的な球の干渉検査は行いますが、**現時点で転がり・摩擦・リバウンド・印刷性を実物確認したわけではありません**。必要に応じて天井を滴形化、もしくは出口までのガイド勾配を調整してください。
