# SB03-V2 — 2×2×2 上面投入・縦R16カーブ・一方向レール

PR #72 の SB02-V1（4×2×2 左右分岐）とは独立した、可動部なし・一体印刷のレールです。SB03-V1の「真下に落とし、平面の約8.5°の坂を転がす」構造を、**垂直から水平へ90°曲がるR16流路**に変更しました。

## 寸法・接続

- 外形：デュプロ **2×2×2**、31.8×31.8×38.4mm、上面スタッドなし
- 上面丸穴：**Ø25.74mm**（既存の `BALL_TRACK.opening` と同じ）。基準球径 Ø24.26mm
- 曲面：既存C01急カーブと同じ **R16の中心線**を縦のXZ面に配置。上面側は鉛直、出口側は水平に接線接続
- 出口：**東（+X）側1口のみ**。円弧断面 `BALL_TRACK.radius`、床高 **Z=6.35mm** で既存レール規格に一致。西側は閉鎖
- 下面：E31-05（深さ4.75mm、チューブ外径13.20mm、PR58 B短スリット）。側面に `SB03-V2` 凹刻印

## なぜ滑らかなLoftなのか

平坦急カーブC01のR16を縦へ回転させた中心軌道に沿って、円断面を連続補間して1個の通路切削形状を作ります。入口縦穴と90°トーラス、出口直線を別々に切削・結合する方法ではSTLに非閉鎖エッジが発生したため、**入口・曲面・出口を単一の連続Loftに変更**しました。C01の未マージPRを直接importしないため、PR #72のみで生成できます。

曲面で落下方向を受け流す構造なので、V1の直接的な床衝突より反発損失が小さい可能性があります。ただし、**速度・転がり・詰まりは実物未検証**です。


成果物：`brick.stl`, `brick.step`, `report.json`。版は `SB03-V2`。SB02-V1のソースと生成版は変更していません。

## 印刷で確認すること

1. Bambu Studio / A1 mini / PLA / サポートOFFで、**内側カーブの天井**と丸穴縁に印刷崩れがないか
2. 10球以上を上から落とし、毎回一方向に排出できるか、跳ね返り・詰まりがないか
3. 既存レールに接続し、出口床面に段差やバリがないか、SB03-V1より勢いが良いか
4. 純正×印刷、印刷×印刷の保持・挿抜・耐久性を個別に確認する

**CAD球干渉・閉メッシュは動作保証ではありません。** 小児に渡す前に大人が造形強度、脱落、鋭利な部分を確認してください。
