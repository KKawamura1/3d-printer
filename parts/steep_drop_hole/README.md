# S01-V1 — 2×2×高さ2 急な坂（穴）

2×2ポッチの設置面積（本体31.8×31.8 mm）、高さ2段（38.4 mm）の試作版です。
高い西側の入口（床Z25.55 mm）からボールを入れ、直径26.3 mmの縦穴で落下させ、
低い東側（床Z6.35 mm）へ出す仕組みです。落差は1段＝19.2 mm。

## 構造上の重要な制約

- 通常の密閉トンネルではありません。高い入口の球上端は本体上面より約12.89 mm上に出るため、上面は開口させます。
- 上面の穴とスタッドが干渉するため、上面スタッドはありません。下面はE31-05移植のチューブ／ビード／4スリットを備え、デュプロ2×2に載せられます。上にブロックを積める形状ではありません。
- 内部の球通路は、高い横入口→大きな縦穴→低い横出口が連結したCSGです。曲面の連続した滑り台ではなく、落下後に出口へ進むことを狙う構造です。出口まで自動的に転がることは物理未検証で、穴底で止まる可能性があります。
- 上面の長い開口縁はR0.30 mm、外部縦角R0.8 mm。口の断面・後処理バリ等を含む子供向け安全性は未確認。
- S01-V1を南側外壁に凹刻印。下面E31-05嵌合もこの形状では未実測です。

## Bambu A1 miniでの実物確認

- PLA Basic・積層0.20 mmを想定し、Bambu Studioで上面穴を上にしてスライス。内部横穴の天井ブリッジと縦穴を積層プレビューで確認。サポートOFF成功は未確認です。
- ボールを高い入口から入れ、穴底で止まらず出口まで出るか、落下時に跳ね返るかを試験。必要なら床ガイドを別版で追加。
- E31-05下面と純正凸の着脱感・保持力、子供の手に触れる開口縁、薄肉・割れを大人が確認。
- 転がり・保持・印刷・安全性を通過するまでは子供の遊び用として量産しません。
