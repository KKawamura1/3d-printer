# S01-V4 — 2×2×高さ3 急落下＋出口坂トンネル（試作）

Issue #37 に従い、開放穴のない天井付き形状のみを維持します。外形は31.8×31.8×57.6mm、スタッドを含む全高62.1mmです。

- 西側高入口：床 Z25.55mm、東側低出口：床 Z6.35mm（1段19.2mmの差）。球径24.26mm想定。
- 中央の落下室 X=-2mm で受け止める床を**東方向へ下る1:4の坂（約14.0度）**に変更。着地位置から坂の終端X=13mmまで3.75mm下降し、出口前は3mmの水平接続部です。
- 既存の水平出口トンネルだけでは球の上半分が干渉するため、坂に沿う**斜めの円筒空洞**を追加。直径24.26mm球の連続した経路と、上部・側面の逃げをCADで検証します。
- 上面スタッド4本、下面E31-05受け、南側外壁に**S01-V4**の凹刻印。上面開放穴はなく、屋根は先細り円錐状です。
- 出口の床高さ、入口と出口の位置、2×2×高さ3の外形、基準球径は変更しません。

## 設計上の注意

これは「落ちた球が床で停滞する」問題に対して、**重力で出口方向へ転がる走行面**を与える改善です。CAD上の球クリアランスを通っても、衝突・回転・速度・摩擦による現実の走行は保証できません。出口前に水平3mmの区間も残ります。

スライサーでサポートOFFの天井、斜めボアのオーバーハング、底面のブリッジと壁厚を確認する必要があります。PLA Basic・積層0.20mmを想定しますが、未印刷・未走行・未嵌合の試作段階です。子供向け完成品とは扱いません。

## 生成・検証

```bash
python -m parts.steep_drop_hole.design --out build/steep-drop-hole
python -m unittest parts.steep_drop_hole.test -v
```

設定は `parts/steep_drop_hole/cad-build.json`（**S01-V4**）。自動生成したSTLは GitHub Actions の `cad-verified-stl` Artifact 内の `parts/steep_drop_hole/S01-V4/brick.stl` を使用してください。

### 印刷後の確認
1. サポートOFFでスライスし、屋根・斜め通路・坂床・下面をレイヤー単位で確認。
2. 高入口から球を10回転がし、出口へ自然に出る割合、止まり・逆流・詰まりを確認。
3. 既存レールとの段差、純正品／印刷品との上下面の着脱・保持、割れや尖りを確認。
